# 弦圖與完美消除序列（MCS / Lex-BFS / ω·χ·α）

`solution.py`（Python 3 標準庫）與 `solution.cpp`（C++17）行為完全一致：
有 stdin 走 IO 模式，沒有 stdin 就跑內置斷言並輸出 `all tests passed`。

---

## 題意

給一張 n 點 m 邊的**無向簡單圖**，回答若干詢問：

| mode | 輸出 |
|---|---|
| 1 | 這張圖是不是**弦圖**（chordal）？`1` / `0` |
| 2 | MCS（Maximum Cardinality Search）的訪問順序 |
| 3 | **完美消除序列** PEO（= MCS 順序的反序） |
| 4 | ω：最大團的大小 |
| 5 | χ：染色數，以及每個點的顏色（`chi c1 c2 ... cn`，顏色 0 起算） |
| 6 | α：最大獨立集的大小，以及一組最大獨立集（點號升序） |
| 7 | PEO 中每個位置的「後續鄰居數」`d_i`（ω = 1 + max d_i） |

## 輸入格式

```
n m                  點數、邊數（0 ≤ n ≤ 60，0 ≤ m ≤ 1200）
u v                  m 行，每行一條邊（1-based）
q                    詢問數（0 ≤ q ≤ 20）
mode                 q 行，每行一個 mode
```

自環、編號越界、重複邊一律丟棄。mode 不在 1..7 時輸出 `error`。

## 輸出格式

```
每個詢問一行
```

## 輸入輸出示例

輸入（路徑 1-2-3-4）：

```
4 3
1 2
2 3
3 4
7
2
3
1
4
5
6
7
```

輸出：

```
1 2 3 4
4 3 2 1
1
2
2 0 1 0 1
2 2 4
1 1 1 0
```

說明：MCS 順序是 `1 2 3 4`，**反過來** `4 3 2 1` 才是 PEO；
這張圖是弦圖（樹一定是弦圖）；ω = 2；χ = 2（染色 `0 1 0 1`）；
α = 2（取 `{2, 4}`）；每個 PEO 位置的後續鄰居數是 `1 1 1 0`，
所以 ω = 1 + 1 = 2。

再看一個**非弦圖**的例子（4-迴圈 1-2-3-4-1）：mode 1 得到 `0`，
mode 4 得到 `3` —— 這個 3 **不是**真正的最大團（真值是 2），
因為非弦圖時 PEO 根本不存在，後續鄰居集合並不是團。
這正是本題想凸顯的重點：**ω 的 PEO 公式只在弦圖上成立**。

## 思路

### 1. 什麼是弦圖

「長度 ≥ 4 的迴圈都**有弦**（有一條邊直接連起迴圈上兩個不相鄰的點）」，
等價說法是「不存在 induced cycle of length ≥ 4」。樹、區間圖、分裂圖都是弦圖。

弦圖最強的性質是它**有完美消除序列（PEO）**：
一個排列 `v1..vn`，使得每個 `v_i` 在「後面」（`v_{i+1}..v_n`）的鄰居**構成一個團**。

### 2. 兩個產生 PEO 的演算法（互相對拍）

- **MCS**：每次選「已訪問鄰居數最多」的未訪問點（平手取編號最小）。
- **Lex-BFS**：維護一個「集合序列」，每次取第一個集合的第一個點，
  再把每個集合依「是否與該點相鄰」切成兩半（**相鄰的在前**，因為標籤較大）。

兩者的**反序**都是 PEO —— 但前提是圖真的是弦圖。
所以「把候選順序拿去驗 PEO」本身就是一個**弦圖辨識演算法**：

```
G 是弦圖  ⟺  reverse(MCS order) 是 PEO
```

### 3. Lex-BFS 的切分方向（最常寫反的地方）

被挑中的點是 v，接下來對每個集合切成 `S ∩ N(v)` 與 `S \ N(v)` 時，
**相鄰的那一半要放前面**。因為 Lex-BFS 的「標籤」是把 v 的編號 append 到
v 的鄰居身上，標籤越長字典序越大，而演算法每次取的是**字典序最大**的頂點。
寫反的話，連一條 4 個點的路徑都會辨識失敗。

### 4. 弦圖上三個 NP-hard 問題全部變線性

一般圖上求 ω（最大團）、χ（最小染色）、α（最大獨立集）都是 NP-hard，
但拿到 PEO 之後：

```
ω = 1 + max_i |{v_i 在 PEO 中後面的鄰居}|      （那個集合本身就是團）
χ：依 PEO 的「反序」貪心染色（每次選最小的可用顏色）→ 恰好 ω 種顏色
α：依 PEO 的「正序」貪心（與已選集合不相鄰就選）→ 最大獨立集
```

因為弦圖是**完美圖**（perfect graph），χ = ω；而 α = θ（最小團覆蓋數）。
本題把 χ 與 ω 的相等性當成一條不變式來檢查。

### 5. 驗證方式（三層）

1. **MCS vs Lex-BFS**：兩套完全不同的演算法必須給出相同的「是否弦圖」。
2. **2^n 暴力**（n ≤ 11）：枚舉所有點子集，找 induced cycle。
3. **2^n 暴力**（n ≤ 14）：位元遮罩枚舉最大團與最大獨立集。
   弦圖時 assert `ω == 暴力ω`、`α == 暴力α`、`χ == 暴力ω`；
   非弦圖時只 assert `α ≤ 暴力α`（α 永遠是合法獨立集）、
   `χ ≥ 暴力ω`（任何合法染色都要 ≥ 團數）與「染色合法」。

## 複雜度

| 項目 | 複雜度 |
|---|---|
| MCS / Lex-BFS（本題樸素實作） | O(n²) |
| PEO 驗證 | O(n + m) |
| ω / χ / α | O(n + m) |
| 暴力對拍（n ≤ 14 / n ≤ 11） | O(2^n · n) |
| 空間 | O(n + m) |

## 應用場景

- 稀疏矩陣 Cholesky 分解：弦圖 = 完美消除順序 = 分解時不產生新的非零元（fill-in）
- 貝氏網路 / 概率圖模型：junction tree 演算法必須先把圖「三角化」成弦圖
- 資料庫：acyclic hypergraph（α-acyclic）與 join tree，等價於弦圖性質
- 約束滿足與排程：區間圖（弦圖的子類）上的教室排課、頻道分配是多項式時間
- 電腦圖學：三角化多邊形（polygon triangulation）本質上就是弦圖
