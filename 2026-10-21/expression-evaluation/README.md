# 表達式求值（調度場算法 / 三種表示法互轉 / 精確有理數）

`solution.py`（Python 3 標準庫）與 `solution.cpp`（C++17）行為完全一致：
有 stdin 走 IO 模式，沒有 stdin 就跑內置斷言並輸出 `all tests passed`。

---

## 題意

給定若干變數的值，再給 q 個詢問，每個詢問是一種「表達式表示法」的運算：

| mode | 輸入 | 輸出 |
|---|---|---|
| 1 | 中綴 | 求值（走調度場算法） |
| 2 | 中綴 | 轉成後綴（逆波蘭式 RPN） |
| 3 | 中綴 | 轉成前綴（波蘭式 PN） |
| 4 | 後綴 | 後綴求值 |
| 5 | 前綴 | 前綴求值 |
| 6 | 中綴 | 「完全括號化」的中綴（表達式樹的形狀） |

規則：

- 運算子：`+` `-` `*` `/` `^`（**右結合**）與括號 `(` `)`
- 支援**一元負號**，在後綴／前綴裡以 `~` 表示（一元正號直接省略）
- 運算元：**非負整數**或**單一小寫字母變數**（只有被賦值過的變數可用）
- 一律用**精確有理數**運算，輸出最簡分數 `p/q`（q = 1 時只印 p）
- 任何錯誤（語法錯、除以零、未定義變數、指數非法、溢位）輸出 `error`

## 輸入格式

```
m                    變數個數（0 ≤ m ≤ 26）
name value           m 行，每行一個變數（單一小寫字母）與其值
q                    詢問數（0 ≤ q ≤ 200）
mode tokens...       q 行，每行 mode + 以空白分隔的表達式 token
```

數值會被夾到 `[-10^9, 10^9]`；單一表達式最多 60 個 token（超出截斷）。

## 輸出格式

```
每個詢問一行
```

## 輸入輸出示例

輸入：

```
3
a 6
b 3
c 0
10
1 a + b * 2
2 a + b * 2
3 a + b * 2
6 ( a + b ) * 2
1 2 ^ 3 ^ 2
1 - b ^ 2
1 a ^ - b
1 b / a
1 1 / 3 + 1 / 6
4 a b 2 * +
```

輸出：

```
12
a b 2 * +
+ a * b 2
( ( a + b ) * 2 )
512
-9
error
1/2
1/2
12
```

說明：`2^3^2` 是右結合所以是 `2^(3^2) = 512`；`-b^2` 是 `-(b^2) = -9`；
`a ^ -b` 的指數是負數（-3），不在允許的 `[0, 60]` 內 → `error`；
`b/a = 3/6 = 1/2`；`1/3 + 1/6 = 1/2`。

## 思路

### 1. 調度場算法（Shunting-yard）

一邊掃描中綴 token、一邊用一個**運算子棧**決定輸出順序：

```
運算元   → 直接輸出
`(`      → 推入棧
`)`      → 一直彈出到遇到 `(`（沒遇到就是括號不匹配）
運算子 o1 → 先把棧頂「優先序更高、或同階但左結合」的 o2 彈出，再推入 o1
```

掃完後把棧彈空；若中途看到 `(` 就是括號沒閉合。

### 2. 一元負號的優先序（最容易寫錯的地方）

數學與 Python 的慣例是 `-a^b == -(a^b)`，也就是 `^` 綁得比一元負號**緊**。
所以優先序定成：

| 運算子 | 優先序 | 結合性 |
|---|---|---|
| `^` | 4 | 右 |
| `~`（一元負號） | 3 | 前綴 |
| `*` `/` | 2 | 左 |
| `+` `-` | 1 | 左 |

而且**一元（前綴）運算子推入時一律不彈棧** —— 它只作用於緊接在後面的運算元，
彈出別人反而會把 `a ^ -b` 算成 `(a^b) 取負`。

### 3. 為什麼要有第二套實作

本題除了調度場，還另外寫了一套**遞歸下降 + 優先序爬升**（precedence climbing）
的剖析器。兩套演算法思路完全不同，卻必須得到同一個值 ——
這是抓「結合性寫反」「一元優先序錯」這類 bug 最有效的手段。
再加上「中綴求值 == 後綴求值 == 前綴求值 == 括號化後再求值」四路交叉驗證。

### 4. 精確有理數，不用浮點

分數以 `(num, den)` 表示，強制 `den > 0`、每次運算後用 gcd 約分。
這樣 Python 與 C++ 的輸出才可能**逐位元組一致**（浮點做不到）。
為了避免 C++ 的 int64 溢位，統一訂一個上限 `LIMIT = 10^9`：
約分後的分子或分母一旦超過就視為 `error`（兩個語言同一條規則）。
指數運算要求指數是 `[0, 60]` 內的整數，`0^0` 定義為 1。

### 5. 前綴求值的小技巧

前綴要**從右往左**掃：遇到運算元推棧，遇到運算子就取棧頂兩個。
因為前綴的左運算元離運算子比較近，會先被掃到，所以取出的順序是「先左後右」。

| 空間 | O(m) |

## 應用場景

- 試算表 / 計算機：Excel 公式、SQL 計算欄位、金融報價的運算式引擎
- 編譯器前端：中綴 → AST → 三地址碼，本題的表達式樹就是 AST 的雛形
- 設定檔與規則引擎：促銷折扣公式、風控規則
- 符號計算：CAS（如 SymPy）底層同樣走精確有理數，避免 `0.1 + 0.2 != 0.3`
- 早期 Fortran / BASIC 編譯器、HP 計算機的 RPN 輸入法
