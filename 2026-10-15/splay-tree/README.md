# 伸展樹（Splay Tree）

`2026-10-15/splay-tree`

## 題意

維護一個**可重複元素**的有序集合，支援七種操作：

| op | 參數 | 含義 |
|---|---|---|
| 1 | `x` | `insert(x)` 插入 |
| 2 | `x` | `erase(x)` 刪除一個（不存在則無動作） |
| 3 | `x` | `contains(x)` → `1 / 0` |
| 4 | `k` | `kth(k)` 第 k 小（1-indexed），越界輸出 `-1` |
| 5 | `x` | `rank(x)` 嚴格小於 `x` 的元素個數 |
| 6 | `x` | `predecessor(x)` 嚴格小於 `x` 的最大值，不存在輸出 `-1` |
| 7 | `x` | `successor(x)` 嚴格大於 `x` 的最小值，不存在輸出 `-1` |

所有操作都靠**伸展（splay）**把被訪問的節點一路旋轉到根。
另外用一個「有序陣列 + 二分搜尋」的參考實作逐項對拍，驗證 splay 的結果正確。

## 思路

### 核心想法：把剛訪問過的節點搬到根

伸展樹**不維護任何平衡資訊**（沒有 AVL 的高度、沒有紅黑樹的顏色），它只遵守一條規則：
每次訪問一個節點，就把它旋轉到根。靠均攤分析（access lemma / 勢能法）可證
`m` 次操作的總代價是 `O((n + m) log n)`，也就是**均攤 O(log n)**。

代價是單次操作可能退化成 O(n)；好處是常數小、程式短，而且自帶**快取效應** ——
最近被訪問的元素永遠在根附近，對有局部性（locality）的存取序列特別快。這才是它真正的價值。

### 三種旋轉情況

設 `x` 是要伸展的節點，`f = fa[x]`，`g = fa[f]`：

- **zig**（`g` 為空）：只轉一次 `x`
- **zig-zig**（`x` 與 `f` 同側，都是左兒子或都是右兒子）：**先轉 `f` 再轉 `x`**
- **zig-zag**（`x` 與 `f` 異側）：**轉兩次 `x`**

zig-zig 與 zig-zag 的差別是伸展樹的精髓：zig-zig 先轉父親會把整條路徑「折半」、把樹壓扁。
如果這裡也寫成「轉兩次 `x`」，均攤複雜度就會退化（競爭比掉到 Ω(n)）。

### 刪除：伸展後靠前驅頂替

先把目標 splay 到根：

- 計數 > 1：直接減一（本題每個節點帶 `cnt`，支援重複元素）
- 沒有兒子 / 只有一個兒子：讓那個兒子當根
- 兩個兒子都在：取左子樹的最大值（前驅），把它在左子樹裡 splay 到根，
  再把右子樹接成它的右兒子

這跟普通 BST 的「中序後繼頂替」是同一套思路，差別在於 splay 版順便把前驅送到根，讓下次存取更快。

### 與 Treap / 紅黑樹的比較

| 結構 | 平衡依據 | 單次操作 | 特色 |
|---|---|---|---|
| Treap | 隨機優先級 | 期望 O(log n) | 程式短、可持久化 |
| 紅黑樹 | 顏色規則 | 最壞 O(log n) | 常數大、程式長 |
| **Splay** | 無（自調整） | 均攤 O(log n) | 局部性加速、區間操作、LCT 基礎 |

## 複雜度

| 操作 | 均攤 | 最壞 |
|---|---|---|
| 插入 / 刪除 / 查詢 / 第 k 小 / 排名 / 前驅 / 後繼 | O(log n) | O(n) |
| 中序遍歷 | O(n) | O(n) |
| 空間 | O(n) | — |

## 輸入格式（stdin，全部以空白分隔的整數）

```
n                      初始元素個數
v_1 ... v_n            初始元素
q                      操作數
接下來 q 組，每組 2 個整數 `op a`
```

- 非數字 token 一律視為「輸入到此為止」；讀不滿的那一組直接丟棄
- `n`、`q` 截斷到 `[0, 3000]`；數值截斷到 `[-10^12, 10^12]`；`op` 截斷到 `[0, 7]`

## 輸出格式（4 行）

```
第 1 行  集合大小
第 2 行  中序遍歷（升序，空格分隔；含重複元素）
第 3 行  op = 3..7 的查詢結果（依執行順序，空格分隔）
第 4 行  1 = splay 結果與有序陣列參考實作逐項一致，且中序遍歷非遞減
```

## 範例

### 輸入

```
5
5 1 9 3 7
7
3 7
5 7
4 2
6 7
7 7
2 5
3 5
```

### 輸出

```
4
1 3 7 9
1 3 3 5 9 0
1
```

說明：初始 `{1,3,5,7,9}`；`contains(7)=1`、`rank(7)=3`、`kth(2)=3`、`predecessor(7)=5`、
`successor(7)=9`；刪除 `5` 後集合為 `{1,3,7,9}`，最後 `contains(5)=0`。

## 邊界情況

- 空輸入 / `n = 0`：集合為空，`kth`、前驅、後繼一律輸出 `-1`
- 重複元素：用 `cnt` 計數，中序遍歷會出現相鄰的相同值（BST 檢查用「非遞減」）
- `kth` 的 `k` 超出 `[1, size]`：輸出 `-1`
- `op` 為 0 或 8（越界）：無動作（不產生輸出）
- 輸入中途出現非數字 token：其後的內容全部忽略
