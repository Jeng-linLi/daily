# Z 函數（Z Algorithm）與擴展 KMP

`2026-10-15/z-function`

## 題意

給定兩個只含小寫字母的字串 `s`（文本）與 `p`（模式串），輸出：

1. `s` 的 **Z 陣列**：`z[i]` = `s` 與 `s[i:]` 的最長公共前綴長度（約定 `z[0] = |s|`）
2. `p` 的 Z 陣列
3. `p` 在 `s` 中**所有出現的起始位置**（0-indexed，遞增）
4. **擴展 KMP** 的 `ext` 陣列：`ext[i]` = `p` 與 `s[i:]` 的最長公共前綴長度
5. `s` 的**最短週期**：最小的 `k` 使 `s` 恰好由長度 `k` 的塊重複整數次構成
6. 一致性旗標 `1/0`：以上五項的線性演算法是否與 O(n²) 暴力逐項相同

## 思路

### Z 函數：用已經算過的區間當跳板

維護一個「Z-box」`[l, r]` —— 當前已知最靠右的匹配區間，滿足 `s[l..r] == s[0..r-l]`。計算 `z[i]` 時：

- 若 `i > r`：Z-box 蓋不到 `i`，只能從 0 開始老實比（`while` 迴圈）。
- 若 `i ≤ r`：`s[i..r]` 已經等於 `s[0..r-i]`，可以**直接複製**先前算過的 `z[i-l]`，
  但最多只能複製到 `r` 為止 → 取 `min(r - i + 1, z[i - l])`，再從這個起點繼續往後比。

關鍵是**每個字元最多被 `while` 迴圈比對一次**：一旦匹配超過 `r` 就把 Z-box 的右端推進到新位置，
而 `r` 只增不減。故總複雜度 O(n)。

Z 函數與 KMP 的 prefix function 是**對偶的兩套方法**：KMP 預處理模式串、掃描時指標不回頭；
Z 函數則把「自己和自己的每個後綴」一次算完，寫起來更不容易出錯。

### 擴展 KMP：一次 Z 搞定所有後綴

要求 `p` 與 `s` 的每個後綴 `s[i:]` 的 LCP，只要在 `p + '#' + s` 上跑一次 Z 函數：
位置 `|p| + 1 + i` 對應 `s[i:]`，取其 z 值再跟 `|p|` 取 `min` 即可（哨兵 `#` 會自然擋住越界）。
這比「對每個 `i` 都跑一次 KMP」快得多，是 `O(|p| + |s|)`。

### 最短週期

若 `s` 有週期 `k`（且 `k | n`），則 `s[k:] == s[:n-k]`，也就是 `z[k] == n - k`；反過來也成立。
所以枚舉 `n` 的因數 `k`，取第一個滿足 `z[k] == n - k` 的就是答案；`k = n` 恆為週期，當作兜底。

## 複雜度

| 項目 | 時間 | 空間 |
|---|---|---|
| Z 陣列 | O(n) | O(n) |
| 擴展 KMP（所有後綴 LCP） | O(\|p\| + \|s\|) | O(\|p\| + \|s\|) |
| 模式匹配（所有出現位置） | O(\|p\| + \|s\| + 出現次數) | O(\|p\| + \|s\|) |
| 最短週期 | O(n) | O(n) |

## 輸入格式

以空白分隔的 token，前兩個分別是 `s` 與 `p`：

- 只接受純小寫字母（`^[a-z]+$`）；不合規的 token 視為空字串
- 長度截斷到 2000；多餘的 token 忽略；不足的視為空字串

```
s
p
```

## 輸出格式（6 行）

```
第 1 行  s 的 Z 陣列（空格分隔）
第 2 行  p 的 Z 陣列
第 3 行  p 在 s 中的所有出現位置（0-indexed）
第 4 行  ext 陣列（長度 |s|）
第 5 行  s 的最短週期
第 6 行  1 = 演算法與暴力一致
```

## 範例

### 輸入

```
abababab
abab
```

### 輸出

```
8 0 6 0 4 0 2 0
4 0 2 0
0 2 4
4 0 4 0 4 0 2 0
2
1
```

說明：`s = "abababab"` 的 `z[2] = 6`（`s[2:] = "ababab"` 與 `s` 的前綴匹配 6 個字元）；
`"abab"` 出現在 0 / 2 / 4；`ext = [4,0,4,0,4,0,2,0]`，其中等於 4 的位置正是 0 / 2 / 4；
最短週期是 2（`"ab"` 重複 4 次）。

### 輸入

```
aaaaa
aa
```

### 輸出

```
5 4 3 2 1
2 1
0 1 2 3
2 2 2 2 1
1
1
```

## 邊界情況

- 空輸入 / 缺 `p`：兩者都視為空字串，輸出空的 Z 陣列與空的 `ext`
- `p` 為空字串：約定它在 `0 .. |s|` 共 `|s|+1` 個位置「出現」
- `p` 比 `s` 長：出現位置為空
- `s` 為空：Z 陣列、`ext`、出現位置皆為空，最短週期為 0
- 非小寫字母的 token（含數字、符號）：視為空字串
