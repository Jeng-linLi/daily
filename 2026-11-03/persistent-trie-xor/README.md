# 可持久化 01-Trie Persistent Trie（區間最大異或）

## 題意

給定長度為 n 的數列 a[1..n]（0 ≤ a_i < 2^20）與 q 筆查詢 `l r x`，求

```
max{ a_i XOR x : l ≤ i ≤ r }
```

```
輸入：              輸出：
3 2                 3
1 2 3               4
1 3 0
1 3 7
```

（[1,2,3] 與 0 的最大異或 = 1^2 = 3；與 7 的最大異或 = 3^7 = 4）

## 思路

**1. 為什麼要可持久化。** 全域最大異或用普通 01-Trie 即可：x 按位從高到低，每步貪心走「與 x 該位相反」的孩子。但限制了**區間** [l, r] 後，單棵 Trie 無法知道哪些數落在區間裡。

**2. 前綴版本。** 版本 i 的 Trie = 依次插入 a_1..a_i 後的 Trie（版本 0 為空樹）。插入時只複製被修改路徑上的節點，其餘孩子直接共享舊版本指針，每個版本只多 O(B) 個節點（B = 20），總節點數 O(nB)。每個節點維護 cnt：子樹中被插入過的數的個數。

**3. 版本差 = 區間。** 「值在 a[l..r] 中的數」= 版本 r 減版本 l−1。查詢時兩個版本同步向下走：想走的方向 d（與 x 該位相反）若 `cntR[d] − cntOld[d] > 0`，說明區間內存在帶該前綴的數 → 走 d 並把答案該位置 1；否則只能走 x 該位的方向。每筆查詢 O(B)。

**4. 邊界。** l = 1 時舊版本是空樹（cnt 全 0），邏輯自然成立；區間內至少一個數，貪心一定有落點。

**對拍**：與 O(r−l+1) 直接枚舉的暴力比對（小值域 200 組 × 10 查詢 + 大值域 60 組 × 8 查詢，自製 LCG 保證兩語言同一隨機序列）。

## 複雜度

| 項目 | 複雜度 |
|---|---|
| 建樹 | O(n·B)，B = 20 |
| 單筆查詢 | O(B) |
| 空間 | O(n·B) |

## 應用場景

- **區間異或查詢**：遊戲數值對比、訊號 / 校驗碼比對中「差異最大」的樣本
- **離線日誌分析**：時間視窗 [l, r] 內找與給定指紋差異最大的記錄
- **安全**：時間段內找與已知簽名漢明距離最遠（異或最大）的特徵
- **資料庫**：位圖索引上的範圍 + 異或組合查詢
