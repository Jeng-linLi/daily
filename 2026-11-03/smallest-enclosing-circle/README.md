# 最小圓覆蓋 Smallest Enclosing Circle（Welzl / Move-to-Front）

## 題意

給定平面上 n 個整數點（|x|, |y| ≤ 10^4），求覆蓋所有點的半徑最小的圓，輸出圓心座標與半徑（四捨五入到小數點後 2 位，採「遠離零」規則；−0.00 正規化為 0.00）。

```
輸入：              輸出：
4                   0.50 0.50 0.71
0 0
1 1
0 1
1 0
```

（正方形四個頂點，最小覆蓋圓以外接圓為準）

## 思路

**1. 三個幾何事實。** 最小覆蓋圓唯一，且由至多 3 個點決定：

- 1 個點：半徑 0
- 2 個點：以兩點為直徑的圓
- 3 個點：銳角 / 直角三角形的外接圓

**2. Welzl 增量算法（move-to-front 隨機化版本）。** 把點隨機打亂後逐個加入：

- 當前圓已包含新點 → 什麼都不做
- 否則新點 p 一定在最終圓的**邊界**上 → 帶著「p 在邊界上」的約束對前面的點再做一遍增量（一層遞迴）
- 又遇到不被包含的點 q → p、q 都在邊界上，帶雙約束再掃一遍；此時每個不被包含的點 s 按叉積分側，只考慮能包住 p、q、s 的外接圓中半徑最小者

迭代三層循環實現（行為等價於樸素遞迴，但無遞迴深度問題），期望 O(n)。

**3. 數值細節。** 洗牌用自製 LCG，Python 與 C++ 產生**完全相同**的點序，兩語言輸出逐位元組一致；外接圓計算先把座標平移到點集範圍中心再算，提升精度；三點共線（叉積行列式為 0）沒有外接圓，由上層跳過。

**4. 對拍。** 固定用例（單點、兩點、直角三角形外接圓、正方形、共線、重複點）+ O(n^4) 暴力：枚舉所有點對（直徑圓）與點三元組（外接圓），取「包含全部點的半徑最小者」比對。

## 複雜度

| 項目 | 複雜度 |
|---|---|
| 時間 | 期望 O(n)（隨機化增量），最壞 O(n³)（幾乎不會發生） |
| 空間 | O(n) |

## 應用場景

- **地理圍欄 / 配送半徑**：一批送貨點的最小服務半徑與調度中心選址
- **蜂窩網路**：覆蓋所有用戶的最小基站覆蓋半徑
- **製造業公差檢測**：一批孔位 / 銷釘的最小包絡圓 = 定位誤差上界
- **電腦圖學**：包圍球（bounding sphere）預計算，加速視錐剔除與碰撞檢測
