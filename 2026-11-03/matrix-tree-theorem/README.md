# 矩陣樹定理 Matrix-Tree Theorem（帶權生成樹計數）

## 題意

給定 n 個點、m 條邊的無向帶權圖（允許重邊、不允許自環；權值可為 0，權 0 的邊等價於不存在）。一棵生成樹的權值定義為樹上所有邊權的**乘積**，求所有生成樹的權值**總和**，對 998244353 取模。圖不連通（不存在生成樹）時答案為 0。

無權圖取所有 w = 1，即退化成生成樹**個數**（Cayley 公式：K_n 有 n^(n-2) 棵生成樹）。

```
輸入：              輸出：
3 3                 31
1 2 2
2 3 3
1 3 5
```

（三角形去掉一條邊剩兩條：2×3 + 2×5 + 3×5 = 31）

## 思路

**1. Kirchhoff 拉普拉斯矩陣。** 度數矩陣 D（對角線 = 與該點相連的邊權之和）、鄰接矩陣 A（重邊累加），L = D − A。去掉 L 的任意一行一列（約定第 0 行第 0 列）得 n−1 階子式 M，帶權矩陣樹定理：

```
det(M) = Σ_T Π_{e∈T} w(e)    （T 遍歷所有生成樹）
```

**2. 模質數下的行列式。** 在模 p（p = 998244353，質數）下高斯消元：

- 每列在當前行以下找非零主元；找不到 → det = 0（恰好對應圖不連通）
- 交換兩行，行列式變號
- det 乘主元，再用主元逆元消去下方各行

全程整數（模 p）運算，沒有捨入誤差——實數消元在 n 稍大時就會失真，這正是選模質數的原因。

**3. 對拍。** 內建測試用 O(2^m · m · α) 暴力：枚舉所有邊子集中大小為 n−1 者，並查集驗證是否構成生成樹，累加邊權乘積，與 Kirchhoff 行列式比對（300 組隨機 + 7 個固定用例）。

## 複雜度

| 項目 | 複雜度 |
|---|---|
| 建矩陣 | O(n + m) |
| 行列式消元 | O(n³) |
| 空間 | O(n²) |

## 應用場景

- **網路可靠性**：通訊網的生成樹數量 = 連通骨架的冗餘度（可靠性多項式）
- **電路分析**：Kirchhoff 矩陣主子式給出等效電阻（電網、晶片電源網）
- **圖論計數**：驗證 Cayley 公式、找出「拆掉哪些邊會讓網路失去備援」
- **馬爾可夫鏈**：Markov chain tree theorem（平穩分佈與生成樹計數）
