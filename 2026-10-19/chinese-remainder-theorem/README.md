# 中國剩餘定理（CRT）與擴展中國剩餘定理（exCRT）

`solution.py`（Python 3 標準庫）與 `solution.cpp`（C++17）行為完全一致：
有 stdin 走 IO 模式，沒有 stdin 就跑內置斷言並輸出 `all tests passed`。

---

## 題意

一口氣解三組同餘問題（外加一組還原驗證），每組都同時給出「高效演算法」
與「獨立實作的暴力版本」互相對拍。

**A. 同餘方程組**：給 n 組 `(a_i, m_i)`，求所有滿足 `x ≡ a_i (mod m_i)` 的 x。
分別用「互質版 CRT」（乘積 + 逆元）與「一般版 exCRT」（兩兩合併）各解一次。

**B. 線性同餘方程** `a·x ≡ b (mod m)`：求 gcd、解的個數、最小非負解。

**C. CRT 還原**：給定 `x` 與兩個模數 `p`、`q`，先取 `(x mod p, x mod q)`，
再用 exCRT 還原出 `x mod lcm(p, q)`，跟直接算的結果比對。

## 輸入格式

```
n                    同餘方程組的條數（0 ≤ n ≤ 12）
a_1 m_1              第 i 條：x ≡ a_i (mod m_i)
...
a_n m_n
A B M                線性同餘：A·x ≡ B (mod M)
X P Q                還原：給定 X，用模數 P 與 Q
```

全部 token 以空白分隔；遇到非整數 token 就當成「輸入到此為止」，缺值補預設。
`m_i`、`M`、`P`、`Q` 至少為 1；數值會被夾到上限（見程式內常數）。

## 輸出格式（共 5 行）

```
第 1 行：exCRT 的解  r M          （x ≡ r (mod M)）
第 2 行：互質版 CRT  r2 M2
第 3 行：線性同餘    g cnt xmin
第 4 行：還原        recon modulus
第 5 行：ok 旗標
```

特殊值：

- 第 1 行 `-1 -1` = **無解**；`-2 -2` = **溢位**（合併模數超過 10^18）
- 第 2 行 `-1 -1` = 模數**不兩兩互質**，互質版不適用（exCRT 仍可能有解）；`-2 -2` = 溢位
- 第 3 行 `cnt = 0`、`xmin = -1` = 線性同餘**無解**
- 第 4 行 `-2 -2` = 溢位

## 輸入輸出示例

輸入（孫子定理原題 + 6x≡4 (mod 10) + 還原）：

```
3
2 3
3 5
2 7
6 4 10
123456789 97 1000
```

輸出：

```
23 105
23 105
2 2 4
72789 97000
1
```

逐步解釋：

| 行 | 值 | 說明 |
|---|---|---|
| 1 | `23 105` | `x ≡ 2 (mod 3)`、`≡ 3 (mod 5)`、`≡ 2 (mod 7)` ⟹ `x ≡ 23 (mod 105)` |
| 2 | `23 105` | 3、5、7 兩兩互質，互質版給出同一個答案 |
| 3 | `2 2 4` | `6x ≡ 4 (mod 10)`：`g = 2`，在 [0,10) 有 2 個解，最小是 4（次小是 9） |
| 4 | `72789 97000` | `123456789 mod 97000 = 72789`，還原值與直接取模相同 |
| 5 | `1` | 所有對拍通過 |

再看兩個對照組：

```
輸入 "2\n2 4\n4 6\n1 1 1\n0 1 1"
輸出:
10 12        ← exCRT：模數不互質也能解，x ≡ 10 (mod 12)
-1 -1        ← 互質版：gcd(4, 6) = 2 ≠ 1，不適用
1 1 0
0 1
1

輸入 "2\n1 4\n2 6\n1 1 1\n0 1 1"
輸出:
-1 -1        ← exCRT：無解（4 與 6 的 gcd 是 2，但 2 - 1 = 1 不是 2 的倍數）
-1 -1
1 1 0
0 1
1
```

邊界輸入：

```
輸入 ""  → 輸出 "0 1\n0 1\n1 1 0\n0 1\n1\n"   （空方程組：x ≡ 0 (mod 1)）
輸入 "0" → 同上
```

## 思路

### 1. 擴展歐幾里得（exgcd）

迭代版即可：維護 `(r, s, t)` 使 `r = a·s + b·t`，不斷做帶餘除法直到 `r = 0`。

限制輸入為**非負**，就完全避開「Python 的 `//` 是 floor、C++ 的 `/` 是 truncate」
在負數上會分歧的老坑（這是浮點 / 整數除法跨語言對拍最常踩的雷之一）。

### 2. 合併兩個同餘式（exCRT 的核心）

要同時滿足 `x ≡ a₁ (mod m₁)` 與 `x ≡ a₂ (mod m₂)`，寫 `x = a₁ + m₁·t`：

```
m₁·t ≡ a₂ - a₁   (mod m₂)
```

令 `g = gcd(m₁, m₂)`：

- 若 `(a₂ - a₁)` 不能被 `g` 整除 → **無解**
- 否則整個式子同除以 `g`：`(m₁/g)·t ≡ (a₂-a₁)/g  (mod m₂/g)`

此時 `m₁/g` 與 `m₂/g` 互質，逆元存在，直接得到 `t`，再回代：

```
x₀ = (a₁ + m₁·t)  mod  lcm(m₁, m₂)
```

逐條合併下去就是 exCRT，**模數不需要互質**。

### 3. 互質版 CRT（孫子定理的標準形式）

`M = ∏ m_i`，對每個 i 令 `M_i = M / m_i`、`inv_i = M_i^{-1} mod m_i`，則

```
x = Σ a_i · M_i · inv_i   (mod M)
```

因為 `M_i · inv_i ≡ 1 (mod m_i)` 且 `≡ 0 (mod m_j, j ≠ i)`，
每一項「只在自己那一維生效」，加起來就同時滿足所有條件。
這個形式漂亮，但**只在模數兩兩互質時成立**；非互質必須回到第 2 步。

### 4. 線性同餘 `a·x ≡ b (mod m)`

令 `g = gcd(a, m)`：

- `b` 不是 `g` 的倍數 → **無解**
- 否則同除以 `g` 後 `a/g` 在模 `m/g` 下可逆：
  `x₀ = (b/g) · (a/g)^{-1}  (mod m/g)`
- 在 `[0, m)` 裡恰好有 **g 個**解：`x₀, x₀ + m/g, x₀ + 2·m/g, …`

### 5. 溢位處理（跨語言一致）

Python 是無限精度、C++ 的 int64 會繞回，兩邊必須用同一套截斷規則：

- 合併模數時先做**除法檢查**：`M > LIMIT / (m/g)` 就判定溢位（回傳 `-2 -2`），
  避免真的乘出一個繞回的數；
- 需要乘法的地方，C++ 用 `__int128` 承接（最大 1.7×10^38，本題的 10^18 × 10^18 綽綽有餘）。

`LIMIT` 定為 10^18。

### 6. 暴力對拍

- 當所有模數的 lcm 不超過 200000 時，從 0 枚舉到 lcm - 1 找最小解；
- 線性同餘則在 `m ≤ 200000` 時枚舉 `[0, m)`。

這能抓出「公式對、但正規化（取模 / 負數處理）錯」的 bug。

## 複雜度

| 項目 | 時間 | 空間 |
|---|---|---|
| exgcd / 乘法逆元 | O(log min(a, b)) | O(1) |
| exCRT 合併 n 條 | O(n log M) | O(1) |
| 互質版 CRT（n 條） | O(n log M) | O(1) |
| 線性同餘 | O(log m) | O(1) |
| 暴力對拍 | O(lcm) 或 O(m) | O(1) |

## 應用場景

- **RSA 的 CRT 加速**：分別在模 p 與模 q 下做解密（指數短一半），最後用 CRT 合併，
  整體速度約 4 倍；也是對抗計時旁通道攻擊時要特別處理的地方
- **大數運算 / NTT 多模合併**：把一個巨大整數拆成幾個小模數（如 998244353、
  1004535809、469762049）下的運算，最後 CRT 還原出真值
- **秘密共享（Asmuth-Bloom 門限方案）**：每個人拿到一個不同模數下的餘數，
  湊齊足夠多人才能用 CRT 還原祕密，少一個都不行
- **排程 / 週期對齊**：「每 3 天一次、每 5 天一次、每 7 天一次」何時同時發生
- 競賽題裡的「韓信點兵」、以及模數不互質的計數 / 構造題

## 怎麼跑

```bash
# Python（無 stdin → 跑內置斷言）
python solution.py

# Python（有 stdin → IO 模式）
printf '3\n2 3\n3 5\n2 7\n6 4 10\n123456789 97 1000\n' | python solution.py

# C++
g++ -std=c++17 -O2 solution.cpp -o crt && ./crt
```

> Windows / MinGW 下不要把編譯產物輸出到 `/tmp`（鏈接器會報 No such file or directory），
> 輸出到當前目錄或 `_build/` 即可。
