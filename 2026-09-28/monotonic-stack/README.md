# 单调栈（下一个更大元素 / 每日温度 / 柱状图最大矩形）

| 语言 | 文件 |
|---|---|
| Python 3 | [`solution.py`](solution.py) |
| C++17 | [`solution.cpp`](solution.cpp) |

## 题意

给定一个长度为 `n` 的**非负整数**数组 `a`（允许重复、允许为空），在同一个数组上回答三个经典问题：

1. **下一个更大元素**：对每个位置 `i`，找右边第一个**严格大于** `a[i]` 的元素下标，没有则 `-1`；
2. **每日温度**：与 (1) 同一件事，但输出的是「距离」（下标差），没有则 `0`；
3. **柱状图最大矩形**：把 `a` 视为柱状图的柱高，求其中最大的矩形面积（LeetCode 84）。

## 思路

单调栈解决的是一类「为每个元素找左/右边第一个满足某种大小关系的元素」的问题。核心只有一句话：**栈里始终保持一个单调序列，新元素入栈前先把被它"破坏"单调性的元素弹出去，而那些被弹出的元素，答案恰好就是当前这个新元素。**

| 问题 | 栈的单调性 | 弹栈条件 | 弹栈时记录的答案 |
|---|---|---|---|
| 下一个更大元素 | 值**单调递减** | `a[top] < a[i]` | `ans[top] = i`（下标） |
| 每日温度 | 值**单调递减** | `a[top] < a[i]` | `ans[top] = i - top`（距离） |
| 柱状图最大矩形 | 值**单调递增** | `h[top] > cur` | 以 `h[top]` 为高、宽 `i - 新栈顶 - 1` 的矩形面积 |

每个下标入栈一次、出栈一次，所以总复杂度是 **O(n)**，而不是暴力枚举的 O(n²)。

两个细节最容易写错：

- **比较是严格还是非严格**：「下一个更大元素」用 `<`（相等不算更大），所以相等的元素会一起留在栈里；柱状图用 `>`（相等高度不弹），这样最左边那根相等柱子会负责算出跨越整段的最大矩形，不会漏解。
- **柱状图的哨兵**：扫描到 `i == n` 时补一个高度 `0`，强制把栈清空，否则栈里剩下的柱子永远不会被结算。

| 操作 | 时间复杂度 | 空间复杂度 |

| 三个对照用暴力解 | O(n²) | O(1) / O(n) |

## 输入输出

```text
输入：              输出：
5                   3 2 3 -1 -1   <- 下一个更大元素的下标
2 1 2 4 3           3 1 1 0 0     <- 每日温度（距离）
                    6             <- 柱状图最大矩形面积
```

- 输入全部按空白分隔：`n`、数组（`n = 0` 时整行省略）。
- 输出三行：下一个更大元素下标、每日温度、最大矩形面积。`n = 0` 时前两行输出空行、第三行输出 `0`。
- Python 与 C++ 版本的输入输出格式完全一致，同一输入的输出逐字节相同。
- 无 stdin 输入时，两个版本都会运行内置断言测试并输出 `all tests passed`。

再看一组（LeetCode 84 官方用例）：

```text
输入：              输出：
6                   2 2 3 -1 5 -1
2 1 5 6 2 3         2 1 1 0 1 0
                    10
```

## 测试覆盖

固定用例：`[2, 1, 2, 4, 3]`（含相等元素被跳过的情形）、LeetCode 739 的温度用例 `[73,74,75,71,69,72,76,73]`、LeetCode 84 官方用例 `[2,1,5,6,2,3] → 10`、两根柱子、全 1、单元素、全 0；三种极端形态（严格递减 / 严格递增 / 全相同，其中全相同时「下一个更大」全为 `-1`）；空数组。另有一组自洽性检查：两个函数的答案必须指向同一个位置，且中间不存在更大的元素。

随机对拍：500 组长度 0–40、值域 `[0, 12]` 的随机数组（值域小 → 大量重复，专门考验严格/非严格比较的边界），三个函数全部与 O(n²) 暴力解逐位比对，并校验最大矩形面积落在 `[max(h), max(h)·n]` 之间。
