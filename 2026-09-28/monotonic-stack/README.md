# 單調棧（下一個更大元素 / 每日溫度 / 柱狀圖最大矩形）

| 語言 | 文件 |
|---|---|
| Python 3 | [`solution.py`](solution.py) |
| C++17 | [`solution.cpp`](solution.cpp) |

## 題意

給定一個長度爲 `n` 的**非負整數**數組 `a`（允許重複、允許爲空），在同一個數組上回答三個經典問題：

1. **下一個更大元素**：對每個位置 `i`，找右邊第一個**嚴格大於** `a[i]` 的元素下標，沒有則 `-1`；
2. **每日溫度**：與 (1) 同一件事，但輸出的是「距離」（下標差），沒有則 `0`；
3. **柱狀圖最大矩形**：把 `a` 視爲柱狀圖的柱高，求其中最大的矩形面積（LeetCode 84）。

## 思路

單調棧解決的是一類「爲每個元素找左/右邊第一個滿足某種大小關係的元素」的問題。核心只有一句話：**棧裏始終保持一個單調序列，新元素入棧前先把被它"破壞"單調性的元素彈出去，而那些被彈出的元素，答案恰好就是當前這個新元素。**

| 問題 | 棧的單調性 | 彈棧條件 | 彈棧時記錄的答案 |
|---|---|---|---|
| 下一個更大元素 | 值**單調遞減** | `a[top] < a[i]` | `ans[top] = i`（下標） |
| 每日溫度 | 值**單調遞減** | `a[top] < a[i]` | `ans[top] = i - top`（距離） |
| 柱狀圖最大矩形 | 值**單調遞增** | `h[top] > cur` | 以 `h[top]` 爲高、寬 `i - 新棧頂 - 1` 的矩形面積 |

每個下標入棧一次、出棧一次，所以總複雜度是 **O(n)**，而不是暴力枚舉的 O(n²)。

兩個細節最容易寫錯：

- **比較是嚴格還是非嚴格**：「下一個更大元素」用 `<`（相等不算更大），所以相等的元素會一起留在棧裏；柱狀圖用 `>`（相等高度不彈），這樣最左邊那根相等柱子會負責算出跨越整段的最大矩形，不會漏解。
- **柱狀圖的哨兵**：掃描到 `i == n` 時補一個高度 `0`，強制把棧清空，否則棧裏剩下的柱子永遠不會被結算。

## 輸入輸出

```text
輸入：              輸出：
5                   3 2 3 -1 -1   <- 下一個更大元素的下標
2 1 2 4 3           3 1 1 0 0     <- 每日溫度（距離）
                    6             <- 柱狀圖最大矩形面積
```

- 輸入全部按空白分隔：`n`、數組（`n = 0` 時整行省略）。
- 輸出三行：下一個更大元素下標、每日溫度、最大矩形面積。`n = 0` 時前兩行輸出空行、第三行輸出 `0`。
- Python 與 C++ 版本的輸入輸出格式完全一致，同一輸入的輸出逐字節相同。
- 無 stdin 輸入時，兩個版本都會運行內置斷言測試並輸出 `all tests passed`。

再看一組（LeetCode 84 官方用例）：

```text
輸入：              輸出：
6                   2 2 3 -1 5 -1
2 1 5 6 2 3         2 1 1 0 1 0
                    10
```

## 測試覆蓋

固定用例：`[2, 1, 2, 4, 3]`（含相等元素被跳過的情形）、LeetCode 739 的溫度用例 `[73,74,75,71,69,72,76,73]`、LeetCode 84 官方用例 `[2,1,5,6,2,3] → 10`、兩根柱子、全 1、單元素、全 0；三種極端形態（嚴格遞減 / 嚴格遞增 / 全相同，其中全相同時「下一個更大」全爲 `-1`）；空數組。另有一組自洽性檢查：兩個函數的答案必須指向同一個位置，且中間不存在更大的元素。

隨機對拍：500 組長度 0–40、值域 `[0, 12]` 的隨機數組（值域小 → 大量重複，專門考驗嚴格/非嚴格比較的邊界），三個函數全部與 O(n²) 暴力解逐位比對，並校驗最大矩形面積落在 `[max(h), max(h)·n]` 之間。
