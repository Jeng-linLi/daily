# 快速排序与快速选择（随机化 pivot + 三路分区）

| 语言 | 文件 |
|---|---|
| Python 3 | [`solution.py`](solution.py) |
| C++17 | [`solution.cpp`](solution.cpp) |

## 题意

给定 `n` 个整数（允许重复、允许负数、允许为空），要求：

1. 输出**升序排序**结果；
2. 输出**第 k 小元素**（`k` 为 1-based，越界时输出 `-1`）。

## 思路

快排是「分治 + 原地分区」：每轮挑一个 `pivot`，把区间切成「`< pivot`」「`== pivot`」「`> pivot`」三段，然后只对左右两段递归。

| 变体 | 做法 | 特点 |
|---|---|---|
| Lomuto 分区 | 维护指针 `i`，把 `< pivot` 的元素换到左边，`pivot` 取 `a[hi]` | 写法最直观；重复元素多时两段严重不平衡，全部相等时退化成 O(n²) |
| **三路分区**（荷兰国旗） | 维护 `lt / i / gt` 三个指针，`a[lo:lt] < pivot`，`a[lt:i] == pivot`，`a[i:gt+1]` 待定，`a[gt+1:hi+1] > pivot` | 相等元素一次整段归位，**全部相等时是 O(n)** |
| **随机化 pivot** | `pivot` 从区间里随机挑 | 固定挑首/尾元素时，已排序输入会退化成 O(n²)；随机化后任何分布的期望都是 O(n log n) |
| Quickselect | 分区后看 `k` 落在哪一段，只递归那一段 | 平均 O(n) 拿到第 k 小，不必全排序 |

两个工程细节：

- **小区间改插入排序**：长度 `<= 16` 时快排的递归常数反而更大，插入排序更快。
- **先递归短半边、循环处理长半边**：栈深度被压到 O(log n)，最坏情况不会爆栈。

> 三路分区与 Lomuto 分区**只差一个「相等时怎么办」的分支**：Lomuto 把相等元素全丢到右半边，三路分区把它们单独切出来直接归位。这是「大量重复元素」场景下两者差距的根源。

## 复杂度

| 操作 | 时间复杂度 | 空间复杂度 |
|---|---|---|
| `quick_sort`（三路快排） | 平均 O(n log n)，最坏 O(n²)，**全部相等 O(n)** | O(log n) 递归栈（原地） |
| `quick_sort_lomuto` | 平均 O(n log n)，最坏 O(n²) | O(log n) 递归栈（原地） |
| `quick_select` / `kth_smallest` | 平均 O(n)，最坏 O(n²) | O(1)（`kth_smallest` 额外拷贝 O(n)） |
| `insertion_sort`（长度 m） | O(m²) | O(1) |
| `lomuto_partition` / `partition3` | O(m) | O(1) |

## 输入输出

```text
输入：                输出：
7                     1 3 3 3 5 8 9     <- 升序排序结果
5 3 8 3 1 9 3         3                 <- 第 3 小 = 3
3
```

- 输入全部按空白分隔：`n`、数组（`n = 0` 时整行省略）、`k`。
- 输出第 1 行为升序排序结果（空格分隔，`n = 0` 时输出空行）；第 2 行为第 `k` 小元素的值，`k` 越界或 `n = 0` 时输出 `-1`。
- Python 与 C++ 版本的输入输出格式完全一致，同一输入的输出逐字节相同。
- 无 stdin 输入时，两个版本都会运行内置断言测试并输出 `all tests passed`。

## 测试覆盖

固定用例：含重复元素的 `[5, 3, 8, 3, 1, 9, 3]`（排序 + 各 `k` + `k` 越界）、空数组、单元素、已排序、逆序、全相同（20 个 7）、全负数、含 0 的数组；分区函数自洽性（Lomuto 的 pivot 左侧全 `<`、右侧全 `>=`；三路分区三段严格 `<` / `==` / `>`）；长度 0–39 逐一验证（覆盖插入排序与快排的分界点 16）。

随机对拍：

1. 500 组长度 0–60、值域 `[-9, 9]` 的随机数组（值域小 → 大量重复元素，专门考验三路分区），与 Python `sorted()` / C++ `std::sort` 比对排序结果，并对所有 `k ∈ [1, n]` 比对该位置的期望值。
2. 20000 个元素的随机大数组，验证不爆栈、不退化，且 `kth_smallest` 与全排序结果一致。
