# 快速排序與快速選擇（隨機化 pivot + 三路分區）

| 語言 | 文件 |
|---|---|
| Python 3 | [`solution.py`](solution.py) |
| C++17 | [`solution.cpp`](solution.cpp) |

## 題意

給定 `n` 個整數（允許重複、允許負數、允許爲空），要求：

1. 輸出**升序排序**結果；
2. 輸出**第 k 小元素**（`k` 爲 1-based，越界時輸出 `-1`）。

## 思路

快排是「分治 + 原地分區」：每輪挑一個 `pivot`，把區間切成「`< pivot`」「`== pivot`」「`> pivot`」三段，然後只對左右兩段遞歸。

| 變體 | 做法 | 特點 |
|---|---|---|
| Lomuto 分區 | 維護指針 `i`，把 `< pivot` 的元素換到左邊，`pivot` 取 `a[hi]` | 寫法最直觀；重複元素多時兩段嚴重不平衡，全部相等時退化成 O(n²) |
| **三路分區**（荷蘭國旗） | 維護 `lt / i / gt` 三個指針，`a[lo:lt] < pivot`，`a[lt:i] == pivot`，`a[i:gt+1]` 待定，`a[gt+1:hi+1] > pivot` | 相等元素一次整段歸位，**全部相等時是 O(n)** |
| **隨機化 pivot** | `pivot` 從區間裡隨機挑 | 固定挑首/尾元素時，已排序輸入會退化成 O(n²)；隨機化後任何分布的期望都是 O(n log n) |
| Quickselect | 分區後看 `k` 落在哪一段，只遞歸那一段 | 平均 O(n) 拿到第 k 小，不必全排序 |

兩個工程細節：

- **小區間改插入排序**：長度 `<= 16` 時快排的遞歸常數反而更大，插入排序更快。
- **先遞歸短半邊、循環處理長半邊**：棧深度被壓到 O(log n)，最壞情況不會爆棧。

> 三路分區與 Lomuto 分區**只差一個「相等時怎麼辦」的分支**：Lomuto 把相等元素全丟到右半邊，三路分區把它們單獨切出來直接歸位。這是「大量重複元素」場景下兩者差距的根源。

## 複雜度

| 操作 | 時間複雜度 | 空間複雜度 |
|---|---|---|
| `quick_sort`（三路快排） | 平均 O(n log n)，最壞 O(n²)，**全部相等 O(n)** | O(log n) 遞歸棧（原地） |
| `quick_sort_lomuto` | 平均 O(n log n)，最壞 O(n²) | O(log n) 遞歸棧（原地） |
| `quick_select` / `kth_smallest` | 平均 O(n)，最壞 O(n²) | O(1)（`kth_smallest` 額外拷貝 O(n)） |
| `insertion_sort`（長度 m） | O(m²) | O(1) |
| `lomuto_partition` / `partition3` | O(m) | O(1) |

## 輸入輸出

```text
輸入：                輸出：
7                     1 3 3 3 5 8 9     <- 升序排序結果
5 3 8 3 1 9 3         3                 <- 第 3 小 = 3
3
```

- 輸入全部按空白分隔：`n`、數組（`n = 0` 時整行省略）、`k`。
- 輸出第 1 行爲升序排序結果（空格分隔，`n = 0` 時輸出空行）；第 2 行爲第 `k` 小元素的值，`k` 越界或 `n = 0` 時輸出 `-1`。
- Python 與 C++ 版本的輸入輸出格式完全一致，同一輸入的輸出逐字節相同。
- 無 stdin 輸入時，兩個版本都會運行內置斷言測試並輸出 `all tests passed`。

## 測試覆蓋

固定用例：含重複元素的 `[5, 3, 8, 3, 1, 9, 3]`（排序 + 各 `k` + `k` 越界）、空數組、單元素、已排序、逆序、全相同（20 個 7）、全負數、含 0 的數組；分區函數自洽性（Lomuto 的 pivot 左側全 `<`、右側全 `>=`；三路分區三段嚴格 `<` / `==` / `>`）；長度 0–39 逐一驗證（覆蓋插入排序與快排的分界點 16）。

隨機對拍：

1. 500 組長度 0–60、值域 `[-9, 9]` 的隨機數組（值域小 → 大量重複元素，專門考驗三路分區），與 Python `sorted()` / C++ `std::sort` 比對排序結果，並對所有 `k ∈ [1, n]` 比對該位置的期望值。
2. 20000 個元素的隨機大數組，驗證不爆棧、不退化，且 `kth_smallest` 與全排序結果一致。
