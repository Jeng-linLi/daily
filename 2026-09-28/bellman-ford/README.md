# Bellman-Ford 單源最短路（負權邊 + 負環檢測）

| 語言 | 文件 |
|---|---|
| Python 3 | [`solution.py`](solution.py) |
| C++17 | [`solution.cpp`](solution.cpp) |

## 題意

給定一張 `n` 個點、`m` 條邊的**帶權有向圖**（邊權可以爲負）以及源點 `s`：

1. 判斷從 `s` 出發**是否能到達某個負權環**（環上邊權之和 `< 0`）；
2. 若不存在這樣的負環，輸出 `s` 到每個點的最短距離，不可達輸出 `INF`。

## 思路

Dijkstra 依賴「已經出隊的點距離不再變小」這個貪心性質，一旦有負權邊就不成立。Bellman-Ford 的出發點是一個樸素事實：

> **一條最短路最多經過 n-1 條邊**。再多就一定繞了環；正環/零環可以從路徑裏刪掉，負環則根本不存在「最短路」。

於是算法非常簡單：把所有邊**整體鬆弛** `n-1` 輪。第 `k` 輪結束後，所有「不超過 `k` 條邊」的最短路徑都已經求出。

再做第 `n` 輪：如果還有邊能被鬆弛，說明存在一條含 `n` 條邊還能不斷變短的路徑，也就是繞了負環 —— 這就是**負環檢測**，也是 Bellman-Ford 相比 Dijkstra 的核心能力。

| 要點 | 說明 |
|---|---|
| 只鬆弛有限的邊 | `dist[u] == INF` 時不能用來鬆弛，`INF + w` 會污染結果 |
| 提前退出 | 某一輪一條邊都沒鬆弛就可以 `break`，實際運行遠快於 n 輪 |
| 路徑還原 | 記錄前驅 `pre[v]`；無負環時前驅構成一棵最短路樹 |
| 隊列優化（SPFA） | 只有上一輪被更新過的點，其出邊才可能繼續鬆弛。負環判據換成「某點入隊次數 > n」 |

> **檢測範圍**：負環必須是**從 `s` 可達**的才會被檢測到。圖另一頭的負環與 `s` 無關，不影響 `s` 到其他點的最短路（文件裏有專門的用例驗證這一點）。

## 複雜度

| 操作 | 時間複雜度 | 空間複雜度 |
|---|---|---|
| `bellman_ford` | O(n·m)，提前退出通常遠小於此 | O(n) |
| `spfa`（隊列優化） | 期望約 O(k·m)，最壞仍 O(n·m) | O(n + m) |
| `build_path` | O(路徑長度) | O(路徑長度) |
| `dijkstra`（非負權對照，O(n²) 版） | O(n² + m) | O(n + m) |
| `floyd_warshall`（全源對照） | O(n³) | O(n²) |

## 輸入輸出

```text
輸入：              輸出：
5 7 0              0            <- 0 = 不存在 s 可達的負環
0 1 4              0 -1 2 1 3   <- dist[0..4]
0 2 2
2 1 -3
1 3 2
2 3 5
3 4 2
4 1 1
```

- 輸入全部按空白分隔：`n m s`，接着 `m` 行 `u v w`（下標 0-based，邊權可爲負）。
- 輸出第 1 行爲 `1`（存在 `s` 可達的負環）或 `0`；**僅當第 1 行爲 `0` 時**輸出第 2 行：`dist[0] … dist[n-1]`，空格分隔，不可達爲 `INF`。
- Python 與 C++ 版本的輸入輸出格式完全一致，同一輸入的輸出逐字節相同。
- 無 stdin 輸入時，兩個版本都會運行內置斷言測試並輸出 `all tests passed`。

另兩組：

```text
輸入：              輸出：        輸入：              輸出：
3 3 0              1             4 3 0              0
0 1 1              （無第 2 行）  0 1 1              0 1 INF INF
1 2 -3                           2 3 -5             <- 2→3→2 是負環，但
2 1 1                            3 2 2                 從 0 不可達，不影響
<- 負環 1→2→1 = -2
```

## 測試覆蓋

固定用例：含負權邊但無負環的 7 邊圖（`0→2→1` 使 `dist[1] = -1`，並驗證還原出的路徑就是 `[0, 2, 1]`）、可達負環 `1→2→1`（和 `-2`）、**不可達負環**（`2⇄3` 是負環但 `s = 0` 到不了，檢測結果必須是「無」且距離爲 `0 1 INF INF`）、自環三種（負權 = 負環；零權/正權 = 不是負環）、單點無邊、無邊圖、空圖、重邊取最小、鏈狀圖的路徑還原與不可達時返回空路徑。

隨機對拍：

1. **非負權**圖 400 組（n ≤ 8），與 O(n²) Dijkstra 逐位比對距離。
2. **允許負權**圖 400 組（n ≤ 7，邊權 `[-6, 9]`）：Bellman-Ford 與 SPFA 的負環判據必須一致；無負環時兩版距離必須一致，並額外驗證三個性質 —— 三角不等式（不存在還能鬆弛的邊）、源點距離爲 0、每個可達點的距離都對應一條真實存在且權重相等的前驅路徑；最後再與 Floyd-Warshall 交叉驗證（僅當整張圖都無負環時）。
