# Bellman-Ford 单源最短路（负权边 + 负环检测）

| 语言 | 文件 |
|---|---|
| Python 3 | [`solution.py`](solution.py) |
| C++17 | [`solution.cpp`](solution.cpp) |

## 题意

给定一张 `n` 个点、`m` 条边的**带权有向图**（边权可以为负）以及源点 `s`：

1. 判断从 `s` 出发**是否能到达某个负权环**（环上边权之和 `< 0`）；
2. 若不存在这样的负环，输出 `s` 到每个点的最短距离，不可达输出 `INF`。

## 思路

Dijkstra 依赖「已经出队的点距离不再变小」这个贪心性质，一旦有负权边就不成立。Bellman-Ford 的出发点是一个朴素事实：

> **一条最短路最多经过 n-1 条边**。再多就一定绕了环；正环/零环可以从路径里删掉，负环则根本不存在「最短路」。

于是算法非常简单：把所有边**整体松弛** `n-1` 轮。第 `k` 轮结束后，所有「不超过 `k` 条边」的最短路径都已经求出。

再做第 `n` 轮：如果还有边能被松弛，说明存在一条含 `n` 条边还能不断变短的路径，也就是绕了负环 —— 这就是**负环检测**，也是 Bellman-Ford 相比 Dijkstra 的核心能力。

| 要点 | 说明 |
|---|---|
| 只松弛有限的边 | `dist[u] == INF` 时不能用来松弛，`INF + w` 会污染结果 |
| 提前退出 | 某一轮一条边都没松弛就可以 `break`，实际运行远快于 n 轮 |
| 路径还原 | 记录前驱 `pre[v]`；无负环时前驱构成一棵最短路树 |
| 队列优化（SPFA） | 只有上一轮被更新过的点，其出边才可能继续松弛。负环判据换成「某点入队次数 > n」 |

> **检测范围**：负环必须是**从 `s` 可达**的才会被检测到。图另一头的负环与 `s` 无关，不影响 `s` 到其他点的最短路（文件里有专门的用例验证这一点）。

## 复杂度

| 操作 | 时间复杂度 | 空间复杂度 |
|---|---|---|
| `bellman_ford` | O(n·m)，提前退出通常远小于此 | O(n) |
| `spfa`（队列优化） | 期望约 O(k·m)，最坏仍 O(n·m) | O(n + m) |
| `build_path` | O(路径长度) | O(路径长度) |
| `dijkstra`（非负权对照，O(n²) 版） | O(n² + m) | O(n + m) |
| `floyd_warshall`（全源对照） | O(n³) | O(n²) |

## 输入输出

```text
输入：              输出：
5 7 0              0            <- 0 = 不存在 s 可达的负环
0 1 4              0 -1 2 1 3   <- dist[0..4]
0 2 2
2 1 -3
1 3 2
2 3 5
3 4 2
4 1 1
```

- 输入全部按空白分隔：`n m s`，接着 `m` 行 `u v w`（下标 0-based，边权可为负）。
- 输出第 1 行为 `1`（存在 `s` 可达的负环）或 `0`；**仅当第 1 行为 `0` 时**输出第 2 行：`dist[0] … dist[n-1]`，空格分隔，不可达为 `INF`。
- Python 与 C++ 版本的输入输出格式完全一致，同一输入的输出逐字节相同。
- 无 stdin 输入时，两个版本都会运行内置断言测试并输出 `all tests passed`。

另两组：

```text
输入：              输出：        输入：              输出：
3 3 0              1             4 3 0              0
0 1 1              （无第 2 行）  0 1 1              0 1 INF INF
1 2 -3                           2 3 -5             <- 2→3→2 是负环，但
2 1 1                            3 2 2                 从 0 不可达，不影响
<- 负环 1→2→1 = -2
```

## 测试覆盖

固定用例：含负权边但无负环的 7 边图（`0→2→1` 使 `dist[1] = -1`，并验证还原出的路径就是 `[0, 2, 1]`）、可达负环 `1→2→1`（和 `-2`）、**不可达负环**（`2⇄3` 是负环但 `s = 0` 到不了，检测结果必须是「无」且距离为 `0 1 INF INF`）、自环三种（负权 = 负环；零权/正权 = 不是负环）、单点无边、无边图、空图、重边取最小、链状图的路径还原与不可达时返回空路径。

随机对拍：

1. **非负权**图 400 组（n ≤ 8），与 O(n²) Dijkstra 逐位比对距离。
2. **允许负权**图 400 组（n ≤ 7，边权 `[-6, 9]`）：Bellman-Ford 与 SPFA 的负环判据必须一致；无负环时两版距离必须一致，并额外验证三个性质 —— 三角不等式（不存在还能松弛的边）、源点距离为 0、每个可达点的距离都对应一条真实存在且权重相等的前驱路径；最后再与 Floyd-Warshall 交叉验证（仅当整张图都无负环时）。
