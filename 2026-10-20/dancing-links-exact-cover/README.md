# Dancing Links（DLX）與精確覆蓋

`solution.py`（Python 3 標準庫）與 `solution.cpp`（C++17）行為完全一致：
有 stdin 走 IO 模式，沒有 stdin 就跑內置斷言並輸出 `all tests passed`。

---

## 題意

給一個 0/1 矩陣，**精確覆蓋（Exact Cover）**要選出若干列（row），
使得每一欄（column）恰好被一個被選到的列覆蓋一次。

本程式用 Knuth 的 **Algorithm X + Dancing Links（DLX）**求解，提供兩種模式：

| mode | 說明 |
|---|---|
| 1 | 一般精確覆蓋：輸出找到的解數（上限 k）與字典序最小的解，並與 2^n 暴力枚舉對拍 |
| 2 | 數獨求解：把數獨轉成精確覆蓋，輸出填完的盤面 |

## 輸入格式

### mode 1

```
1                    模式
n m                  矩陣列數、欄數（0 ≤ n, m ≤ 40）
a[i][0..m-1]         n 行，每行 m 個 0/1
k                    解數上限（1 ≤ k ≤ 10；找到 k 個就停）
```

### mode 2

```
2                    模式
B                    宮的邊長（1 ≤ B ≤ 4；B=3 → 9×9 數獨，B=4 → 16×16）
grid                 B² 行，每行 B² 個數字（0 表示空格）
```

全部 token 以空白分隔；遇到非整數 token 就當成「輸入到此為止」，缺值補預設。

## 輸出格式

### mode 1（共 3 行）

```
第 1 行：<找到的解數> <字典序最小的解的列號，升序>；無解只印 0
第 2 行：2^n 暴力枚舉的解數（n ≤ 14 時）；n > 14 時輸出 -1
第 3 行：ok 旗標（1 = 兩者一致；n > 14 時為 -1）
```

### mode 2

```
解出的盤面：B² 行，每行 B² 個數字以空格分隔
無解時輸出一行 no solution
```


| 3 | A, D |
| 4 | B, G |

## 思路

### 1. Algorithm X：遞迴 + 回溯

- 選一個「還沒被覆蓋」的欄 c。啟發式（**S-heuristic**）：選**剩餘候選列最少**的那一欄，
  這能把分支因子壓到最小——候選越少，要試的列越少。
- 枚舉所有在 c 欄為 1 的列 r：選 r，把 r 覆蓋到的所有欄都從矩陣中刪掉，遞迴；
  回溯時再把它們放回去。

### 2. Dancing Links：O(1) 的刪除與還原

樸素做法是每次複製一份矩陣，代價 O(nm)。Knuth 的巧思是把每個 1 做成一個節點，
用**雙向環狀串列**橫向（同一列）與縱向（同一欄）串起來，加上「欄表頭」，
再串成一條含 root 的環。刪除一個欄只要四行：

```c
R[L[c]] = R[c];  L[R[c]] = L[c];      // 從欄表頭環上摘掉
// 再把這個欄裡每一列的其他節點，從各自的欄串列上摘掉
```

而**還原**只需要反向做一次：

```c
R[L[c]] = c;     L[R[c]] = c;
```

關鍵洞察是：被摘掉的節點指標**根本沒被清掉**，它還記得左右的鄰居是誰。
所以只要把指標指回來，串列就復原了——這就是 "dancing links"（舞動的鏈結）名字的由來。

這讓「覆蓋 / 取消覆蓋」的代價是 O(該欄目前的列數)，而不是 O(nm)。
實務上 9×9 數獨（324 欄、729 列、2916 個 1）能在毫秒級解完。

### 3. 確定性：兩語言必須長出一模一樣的結構

要讓 Python 與 C++ 的輸出能逐位元組對拍，三件事必須寫死：

1. **節點插入順序**：逐列（row id 遞增）逐欄加入，
   所以同一欄內的 D 串列就是 row id 遞增的順序。
2. **選欄平手規則**：從左往右掃，**只有嚴格小於才更新**，因此平手時取欄編號最小者。
3. **欄表頭環的順序**：因為 `uncover` 是 `cover` 的精確逆運算，
   回溯後環的左右順序完全復原，所以「從左往右掃」的結果可重現。

### 4. 數獨怎麼轉成精確覆蓋

N = B²，盤面 N×N。對每個 `(r, c, d)` 建一列（共 N³ 列），約束欄分四組各 N² 個：

| 約束組 | 意義 | 欄編號範圍 |
|---|---|---|
| 1 | 格子 (r, c) 必須填剛好一個數字 | `r·N + c` |
| 2 | 第 r 列必須有數字 d | `N² + r·N + d` |
| 3 | 第 c 行必須有數字 d | `2N² + c·N + d` |
| 4 | 第 b 個宮必須有數字 d | `3N² + b·N + d` |

每一列恰好有 4 個 1。已填的格子只保留對應的 d 那一列，其餘候選直接不建。
精確覆蓋的一組解 ⟺ 一組合法的數獨填法（四條規則同時被滿足）。

> 欄編號是 **1..4N²**，節點 0 被 root 佔用。
> 這是開發時踩到的第一個坑：若用 0 起算，欄 A 會被當成 root，整棵結構全錯。

### 5. 全 0 的列要事先剔除

一個全 0 的列覆蓋不到任何欄，選它或不選它都不影響「每欄恰好一次」，
會讓解的數量白白乘以 2（而且遞迴時選了它什麼欄都沒刪掉，會造成無窮遞迴）。
兩個版本都在建結構時**跳過全 0 的列**，暴力對拍也一樣略過，兩邊語義才一致。

## 複雜度

| 項目 | 複雜度 | 說明 |
|---|---|---|
| 建結構 | O(1 的個數) | 每個 1 一個節點，橫豎各插一次 |
| `cover` / `uncover` 一個欄 | O(該欄目前的列數) | Dancing Links 的核心優勢 |
| Algorithm X 搜尋 | 指數級 | 精確覆蓋是 NP-complete；S-heuristic 在實務上極快 |
| 空間 | O(1 的個數 + m) | 每個節點 5 個整數 |

## 應用場景

- **數獨 / KenKen / Star Battle / Hidato 等謎題求解器**：DLX 是數獨的標準解法，
  也是多數「數獨生成 + 難度評分」工具的底層
- **N 皇后**：轉成精確覆蓋後可瞬間數出全部解
- **多聯骨牌（Pentomino）**：把 12 塊五格骨牌鋪進 6×10 棋盤，經典的 DLX 展示題
- **排班問題**：護士輪班、機組指派、會議室分配，本質都是「集合劃分」
- **VLSI 測試向量最小化、覆蓋陣列（covering array）生成**
- 把 NP 問題建模成精確覆蓋後，用 DLX 當作一個小而快的組合搜尋引擎
