# 回文自動機 Palindromic Tree（Eertree）

## 題意

給定字串 `s`，統計其所有回文子字串：

1. 相異回文子字串個數 `k`（經典結論：`k ≤ |s|`）；
2. 每個相異回文子字串的出現次數（按出現位置計，可重疊）；
3. 每個相異回文子字串首次出現的起始下標。

## 思路

回文自動機每個節點代表一個相異回文子字串，另有兩個根：節點 0 是「虛根」
（`len = -1`），節點 1 是「空串根」（`len = 0`）。

- 每次加入一個字元 `s[i]`，以 `i` 結尾的相異回文中**最長的那個**若不存在，
  就新建一個節點——因此每加一個字元至多新增一個相異回文，總節點數 `≤ |s| + 2`。
- 以 `i` 結尾的其餘回文都是該最長回文的真回文後綴，沿 `fail`（後綴連結）鏈
  逐步可達，所以不新增節點、只把對應節點的出現次數 `+1`。
- 建完後沿 fail 樹自葉向根累加 `cnt`，每個節點的 `cnt` 即該回文的實際出現次數。
- 節點建立時記錄結束下標，`首次起始下標 = 結束下標 - len + 1`。

實作細節：長度 1 的回文 `fail` 必須特判指向空串根——若照一般流程走
`get_link(link[cur])` 會指回節點自己。

## 複雜度

- 建樹 `O(n · Σ)`（Σ = 字元集大小，轉移用雜湊/陣列；均攤 fail 跳躍 `O(n)`）。
- 統計與排序 `O(k log k)`，`k ≤ n`。

## IO 示例

輸入：

```
banana
```

輸出（第一行 k；第二行總出現次數；之後每行 `len start count`，按 `(len, start)` 升冪）：

```
6
10
1 0 1
1 1 3
1 2 2
3 1 2
3 2 1
5 1 1
```

輸入：

```
abacaba
```

輸出：

```
7
12
1 0 4
1 1 2
1 3 1
3 0 2
3 2 1
5 1 1
7 0 1
```

## 驗證

- 內建斷言：與 `O(n²)` 枚舉全部子字串的暴力對拍（15 個固定用例 + 300 組隨機）。
- py / cpp IO 對拍 205 組（含空串、純單字元、雙字母小字元集、400 長隨機串）逐位元組一致。
