# 博弈論與 Sprague-Grundy 函數（mex DP / 組合遊戲和）

## 題意

多筆遊戲，每筆有 `k`「堆」，每堆屬於兩種類型之一：

- **type 0 取石遊戲**：一次可從該堆取 1..3 顆（取完即消失）；
- **type 1 拆分遊戲**：一次可把大小 `x` 的堆拆成 `i` 與 `x-i`（`1 ≤ i < x`）兩堆。

每回合選一堆走一步，不能走者輸。求先手是否必勝，並輸出每堆的 SG 值。

## 思路

- **mex 定義**：`SG(局面) = mex{ 後繼局面的 SG }`，`mex` 是集合中未出現的
  最小非負整數。
- **取石遊戲**有閉式解 `g(x) = x mod 4`；本題仍用通用 mex DP 求出並與公式互驗。
- **拆分遊戲**：走一步把一堆換成兩堆，後繼局面的 SG 是 `g(i) xor g(x-i)`
  （組合遊戲和定理），所以 `g(x) = mex{ g(i) ^ g(x-i) : 1 ≤ i < x }`。
  實跑規律：`g` 呈 0/1 交替——偶數堆任何拆法都是「奇+偶」或「偶+偶」、
  xor 恆為 0，得 `g = mex{0} = 1`；奇數堆任何拆法都是「奇+偶」、
  xor 恆為 1，得 `g = mex{1} = 0`。
- **組合遊戲和**：多堆各自獨立走，整體 SG = 各堆 SG 的 XOR；
  `XOR ≠ 0 ⟺ 先手必勝`。

## 複雜度

- 兩張 SG 表：`O(X²)`（X = 最大堆大小，本題 ≤ 3000；取石部分 `O(X)`）。
- 每筆詢問 `O(k)`。

## IO 示例

輸入：

```
2
4
0 3
1 4
0 5
1 1
3
0 1
1 2
0 0
```

輸出（每筆第一行為 k 個 SG 值，第二行 first / second）：

```
3 1 1 0
first
1 1 0
second
```

說明：第二筆 `1 ⊕ 1 ⊕ 0 = 0`，後手必勝。

## 驗證

- 內建斷言：
  1. 取石 `g(x) = x mod 4` 與通用 mex DP 全域互驗；
  2. 拆分遊戲 0/1 交替規律全域驗證；
  3. 400 組雙類型混合隨機小局面（總石數 ≤ 30），「XOR ≠ 0 ⟺ 先手必勝」
     與**記憶化搜索的極小極大暴力**（真實枚舉所有走法）逐局對拍。
- py / cpp IO 對拍 65 組（含 t=0、x=0、x=3000 上界）逐位元組一致。
