# 左偏樹 Leftist Heap（可合併堆 Mergeable Heap）

## 題意

維護 10 個（編號 0..9）可合併的小根堆，支援五種操作：

| 操作 | 說明 |
|---|---|
| `1 h x` | 把值 `x` 插入堆 `h` |
| `2 h` | 彈出堆 `h` 的最小值並輸出；空堆輸出 `-1` |
| `3 h` | 詢問堆 `h` 的最小值（不彈出）；空堆輸出 `-1` |
| `4 a b` | 把堆 `b` 併入堆 `a`（之後 `b` 為空；`a == b` 視為無操作） |
| `5 h` | 輸出堆 `h` 的元素個數 |

## 思路

左偏樹是一棵帶 `dist` 欄位的二叉堆：`dist(空) = -1`、葉子 `dist = 0`、
`dist(x) = dist(右子) + 1`。

- **左偏性質**：左兒子的 `dist ≥` 右兒子的 `dist`。這保證右子樹每往下走一層
  `dist` 至少減 1 ⟹ 從根沿右鏈走到空節點只要 `O(log n)` 步。
- **merge(a, b)**：值大的根掛到值小的根的**右子樹**上遞歸合併；回溯時若
  違反左偏性質則交換左右兒子，再重算 `dist`。複雜度 `O(log n)`。
- `push(x) = merge(根, 單節點)`；`pop = merge(左, 右)`。
- 相比二叉堆，左偏樹的核心賣點是 **O(log n) 合併**——`heapq` 的合併是
  `O(n)` 的。

## 複雜度

- `push` / `pop` / `top` / `merge` 均 `O(log n)`；空間 `O(n)`。

## IO 示例

輸入：

```
13
1 0 5
1 0 2
1 0 8
3 0
2 0
5 0
1 1 7
4 0 1
5 0
5 1
2 0
2 0
2 0
```

輸出（每個 2/3/5 操作一行）：

```
2
2
2
3
0
5
7
8
```

說明：前六步在堆 0 依次得 top=2、pop=2、size=2；合併後堆 0 大小 3、堆 1 為空；
最後三次彈出 5、7、8。

     **堆序性 + 左偏性 + dist 欄位一致 + 節點數 == size**。
