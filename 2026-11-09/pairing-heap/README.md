# 配對堆 Pairing Heap（two-pass combine / 支援 decrease-key）

## 題意

維護 10 個（編號 0..9）**可合併的小根堆**，支援六種操作：

| 操作 | 說明 |
|------|------|
| `1 h x` | 把值 x 插入堆 h |
| `2 h` | 彈出堆 h 的最小值並輸出；空堆輸出 -1 |
| `3 h` | 詢問堆 h 的最小值（不彈出）；空堆輸出 -1 |
| `4 a b` | 把堆 b 併入堆 a（之後 b 為空；a == b 視為無操作） |
| `5 h` | 輸出堆 h 的元素個數 |
| `6 h x y` | 把堆 h 中的值 x 改為 y（decrease-key，無輸出）；x 不在堆 h、y 已存在或 x == y 時視為無操作 |

值域 `|x| ≤ 10⁹`；測試保證同一時刻全域值互異（decrease-key 靠值定位節點）。

## 思路

配對堆用**左兒子-右兄弟表示**：節點只存 `child`（第一個兒子）與 `sib`（下一個兄弟），另加 `par` 指針方便摘除。

- **meld(a, b)**：值大的根作為值小根的第一個兒子，O(1)。掛新兒子時舊兒子的 `par` 仍指向父親，無需改動。
- **delete-min**：把根的所有兒子先**兩兩配對**合併（第一遍），再把結果**從右往左依序合併**（第二遍），均攤 O(log n)。兩遍合併的順序是均攤分析的關鍵。
- **decrease-key（本題的特色操作）**：從父親的兒子鏈上**摘下**目標節點、改值後 meld 回根。注意本題允許**任意改值（含調大）**：
  - 調大時（y > x），被改節點的兒子都 ≥ 舊值 x 卻可能 < 新值 y，子樹內部堆序被破壞 ⟹ 摘下後要把**兒子鏈 two-pass 重組**再與自身 meld；
  - 調小時重組無害，統一走同一條路徑即可。

## 複雜度

- meld：O(1)；pop / decrease-key：均攤 O(log n)；top / size：O(1)
- 空間：O(n)

## IO 示例

```
輸入：          輸出：
8               2
1 0 5           1
1 0 2           0
1 0 8
3 0
6 0 8 1
3 0
4 0 1
5 1
```

插入 `{5,2,8}` 後堆頂是 2；把 8 改成 1 後堆頂變 1；把 h1（含 7）併入 h0 後 h1 大小為 0。

## 驗證

- 無 stdin 時跑內建斷言：與有序陣列參考實作對拍（固定情境 + 自製 LCG 隨機 120 組），並對每個堆實走檢查**堆序（父 ≤ 子）、par 一致、節點數 == size** 不變量。
- Python 與 C++ 的 stdin/stdout 對拍 85 組（含 q=0、空堆操作、自併、截斷輸入、非法 token、±10⁹ 大值）逐字節一致。
