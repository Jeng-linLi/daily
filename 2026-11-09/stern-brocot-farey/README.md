# Stern-Brocot 樹與 Farey 數列

## 題意

實作三個經典有理數結構的查詢：

1. **Farey 數列** `farey n`：輸出 F_n = 所有分母 ≤ n 的既約分數（含 0/1 與 1/1），升冪排列。
   例：`farey 5` → `0/1 1/5 1/4 1/3 2/5 1/2 3/5 2/3 3/4 4/5 1/1`。
2. **Stern-Brocot 路徑** `path p q`：輸出從根 mediant 1/1 走到 p/q 的左右子樹路徑，
   連續同名步壓縮輸出。例：`path 5 3` → `R1 L1 R1`（1/1 →R 2/1 →L 3/2 →R 5/3）。
3. **精確比較** `cmp a b c d`：比較 a/b 與 c/d，輸出 −1 / 0 / 1。例：`cmp 22 7 3 1` → `1`。

## 思路

### Farey 數列：相鄰項遞推（O(|F_n|)）

不排序、不枚舉全部分數。設當前項 a/b、它的前一項 c/d，則後繼為：

```
k = floor((n + d) / b)
後繼 = (k·a − c) / (k·b − d)
```

初始兩項 `0/1, 1/n`，遞推到 `1/1` 為止。整個數列一次線性掃描生成。

**鄰域性質**：相鄰兩項 a/b < c/d 恆滿足 `b·c − a·d = 1`（既約分數在 Farey 數列中必相鄰的刻畫），
這也是遞推正確性的核心恆等式。

**計數公式**：`|F_n| = 1 + Σ_{m=1..n} φ(m)`（0/1 計為那個 1）。

### Stern-Brocot walk：整數比較 + 步數上界 p+q

維護區間 `[a/b, c/d]`，從哨兵 `0/1`（下界）與 `1/0`（上界 = 無窮）出發：

- mediant = `(a+c)/(b+d)`，恆介於 a/b 與 c/d 之間且唯一落點；
- `p·(b+d) < q·(a+c)` → p/q 偏小，走 **L**（右端更新為 mediant）；
- `>` 走 **R**（左端更新為 mediant）；`=` 到達終點。

每次走動後 mediant 分母**嚴格遞增**（新 mediant 分母 = 舊 mediant 分母 + 區間另一端分母 > 舊值），
故步數 ≤ 約簡後的 p+q。全程用 `long long` 交叉相乘比較，精確無浮點誤差。
p=0 / q=0 為哨兵、p/q = 1/1 為根本身，路徑均為空。

### 精確比較：交叉相乘

`a/b vs c/d` ⟺ `a·d vs b·c`（b, c > 0 時；`1/0 = +∞` 哨兵也自然成立，因 a·d > 0 = b·c）。

## 複雜度

| 操作 | 時間 | 空間 |
|---|---|---|
| farey n | O(\|F_n\|) ≈ O(n²) | O(\|F_n\|) |
| path p q | O(p + q) | O(p + q) |
| cmp | O(1) | O(1) |

## 示例

```text
輸入：
farey 5
path 5 3
path 3 5
cmp 2 4 1 2
cmp 22 7 3 1

輸出：
0/1 1/5 1/4 1/3 2/5 1/2 3/5 2/3 3/4 4/5 1/1
R1 L1 R1
L1 R1 L1
0
1
```
