# NTT 快速數論變換：模 998244353 的多項式乘法

## 題意

給定兩個係數在模 998244353 意義下的多項式 f、g，求卷積
`h(x) = f(x) * g(x) mod 998244353`。

## 思路（NTT）

`998244353 = 119 * 2^23 + 1` 是質數，原根 `g = 3` 的階恰為 `p - 1`，含足夠長的 2 的冪次單位根，可做快速數論變換（精確無浮點誤差）：

1. 補零到 `len >= n + m - 1` 的 2 的冪；
2. 位反轉置換 + 蝶形迭代做正變換（自底向上，塊長 1 → 2 → 4 → … → len，旋轉因子 `w_len = 3^((p-1)/len)`）；
3. 點值逐點相乘；
4. 用 `n^{-1} (mod p)` 縮放做逆變換。

複雜度：時間 `O((n + m) log(n + m))`，空間 `O(n + m)`。相比樸素卷積的 `O(n·m)`，在 10^5 量級多項式上有數量級優勢。

## 輸入輸出格式

```
n m                    （兩多項式的項數，即次數 + 1）
n 個整數：f 的係數     （低次到高次，0 <= 係數 < 998244353）
m 個整數：g 的係數
```

輸出一行 `n + m - 1` 個整數：h 的係數（低次到高次）。

## 示例

`(1 + 2x + 3x^2) * (5 + 6x + 7x^2 + 8x^3)`：

```
輸入：                 輸出：
3 4                    5 16 34 40 37 24
1 2 3
5 6 7 8
```

邊界：`998244352 * 998244352 ≡ (-1)^2 ≡ 1 (mod p)`：

```
輸入：                 輸出：
1 1                    1
998244352
998244352
```
