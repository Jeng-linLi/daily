# 雙連通分量：邊雙（e-DCC）、點雙（v-DCC）、橋、割點

## 題意

給定一張簡單無向圖（n 點 m 邊，無自環、無重邊），求：

1. **橋**：刪掉後圖不連通的邊；
2. **割點**：刪掉後剩餘點連通分量數增加的點（孤立點刪去後分量數反而減一，不算割點）；
3. **邊雙連通分量**（e-DCC）：刪去所有橋後的連通分量，孤立點各自成一個分量；
4. **點雙連通分量**（v-DCC）：極大的「刪去任一點後仍連通」的點集；橋的兩端構成大小 2 的 v-DCC，割點可屬於多個 v-DCC，孤立點自成一個 v-DCC。

## 思路（Tarjan，迭代版避免深遞迴棧溢出）

- **橋**：一次 DFS 求 `low/disc`，樹邊 `(p, u)` 是橋 iff `low[u] > disc[p]`。
- **割點**：`u` 非根時，存在子樹 `c` 使 `low[c] >= disc[u]` 即為割點；根看 DFS 子樹數是否 `>= 2`。
- **邊雙**：刪橋後 DFS 劃分分量（含孤立點），分量按「最小點編號」重新編號——與 DFS 順序無關，保證跨語言輸出一致。
- **點雙**：維護點棧，child 完成時若 `low[c] >= disc[u]`，把棧中 `c` 以上的點連同 `u` 彈出成一個分量；根若無子樹分量則自成單點分量。

複雜度：時間 `O(n + m)`，空間 `O(n + m)`。

## 輸入輸出格式

```
n m
m 行：u v
```

輸出（依序）：

```
行 1：邊雙分量數 e
行 2：n 個整數，每點的邊雙編號（按分量最小點升序編號）
行 3：點雙分量數 v
行 4..：v 行，每行「大小 + 升序點列」（分量按字典序升序）
行：橋數 b；接著 b 行「u v」（端點升序、橋之間字典序升序）
行：割點數 a；接著 1 行割點升序點列（a = 0 時為空行）
```

## 示例

兩個三角形由一條橋 (2,3) 相連：

```
輸入：        輸出：
6 7           2
0 1           0 0 0 1 1 1
1 2           3
2 0           3 0 1 2
3 4           2 2 3
4 5           3 3 4 5
5 3           1
2 3           2 3
              2
              2 3
```

含義：兩個邊雙 `{0,1,2}`、`{3,4,5}`；三個點雙 `{0,1,2}`、`{2,3}`、`{3,4,5}`（橋的兩端構成大小 2 的 v-DCC）；唯一橋 `(2,3)`；兩個割點 `2` 和 `3`（橋的任一端刪去後其餘點不再連通）。

三個全孤立點（橋數 0、割點數 0）：

```
輸入：        輸出：
3 0           3
              0 1 2
              3
              1 0
              1 1
              1 2
              0
              0
```
