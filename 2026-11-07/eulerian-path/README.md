# 歐拉路徑 / 歐拉迴路（Hierholzer 演算法）

## 題意

給定一張圖（可帶自環與重邊），求一條經過**每一條邊恰好一次**的走訪（歐拉路徑）；若起點與終點相同則為歐拉迴路。不存在輸出 `-1`。

## 判定條件

- **無向圖**：度數為奇數的點恰為 0 個（迴路）或 2 個（路徑），且所有度數 > 0 的點在同一連通分量內。
- **有向圖**：每點 `out - in ∈ {-1, 0, 1}`，且 +1 與 -1 的點各至多一個（全 0 為迴路；有 +1 必有 -1 為路徑），且所有 `out + in > 0` 的點弱連通。

## 思路（Hierholzer，迭代版）

沿未走過的邊不斷深入，走不動就把當前點彈進答案棧；最後把棧倒序即為歐拉路徑。

- 無向圖用「邊編號 ×2 / ×2+1」技巧標記每條邊的兩個方向，避免重邊漏走。
- 有向圖直接按鄰接表指針推進。
- 起點選擇：無向圖選第一個奇度點（無奇度點則任一度 > 0 的點）；有向圖選 `out - in = +1` 的點（無則任一度 > 0 的點）。

複雜度：時間 `O(n + m)`，空間 `O(n + m)`。

## 輸入輸出格式

```
T           （1 = 無向圖，2 = 有向圖）
n m
m 行：u v   （0-based，允許自環與重邊）
```

存在則輸出一行 `m+1` 個點（空格分隔，`m == 0` 時輸出單點 `0`），否則輸出 `-1`。

## 示例

無向圖（5 點 6 邊，兩個環共用點 2）：

```
輸入：            輸出：
1                 0 1 2 3 4 2 0
5 6
0 1
1 2
2 0
2 3
3 4
4 2
```

有向圖（3 點 3 邊的有向環）：

```
輸入：            輸出：
2                 0 1 2 0
3 3
0 1
1 2
2 0
```

不連通（無歐拉路徑）：

```
輸入：            輸出：
1                 -1
4 2
0 1
2 3
```

## 實現細節

- `solution.py`：迭代 Hierholzer；內建測試與指數回溯暴力對拍存在性（250 組隨機小圖 + 20 組環冒煙），並用 `validate_path` 逐邊驗證路徑合法性。

- 兩版本 IO 行為完全一致。
