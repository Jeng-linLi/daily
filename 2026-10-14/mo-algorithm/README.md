# 莫隊算法：區間查詢（普通莫隊 + 奇偶優化）與帶修莫隊

`solution.py`（Python 3 標準庫）・`solution.cpp`（C++17）

## 題意

維護一個整數陣列 `a`（長度 `n`）與兩組操作：

**A. `q` 個靜態區間查詢 `[l, r]`**，輸出該區間內

1. **不同數的個數**（distinct）
2. **區間和**（sum）
3. **眾數的出現次數**（mode，出現最多次的那個數字出現了幾次）

**B. `m` 個帶修改的操作**

| 操作 | 說明 |
|---|---|
| `1 l r` | 查詢 `[l, r]`，在「執行到這裡為止的陣列」上回答 |
| `2 p x` | 把 `a[p]` 改成 `x` |

對每個查詢輸出同樣的三個量。

A 用普通莫隊（塊排序 + 奇偶優化），B 用帶修莫隊（三維排序），
並與「每次 `O(n)` 從頭掃一遍」的暴力對拍。

## 思路

### 莫隊的核心：把「區間查詢」變成「指標在陣列上走路」

如果知道區間 `[L, R]` 的答案，而且能 `O(1)` 地

- 在右邊加一個元素 / 在右邊刪一個元素
- 在左邊加一個元素 / 在左邊刪一個元素

就可以 `O(|Δ|)` 地移動到任意相鄰區間。本題三個統計量都滿足這個條件：

| 統計量 | 維護方式 |
|---|---|
| `sum` | `add` 就 `+= v`，`remove` 就 `-= v` |
| `distinct` | `cnt[v]` 記出現次數，`0 → 1` 時 `+1`、`1 → 0` 時 `-1` |
| `mode` | 再用一層「出現次數的出現次數」`freqCnt[c]` = 有幾個不同的值恰好出現 `c` 次 |

`mode` 的細節：加入時 `cnt[v]` 增加，若超過當前最大值就更新；
刪除時若最大值那一層被清空就把最大值往下退：

```
while maxc > 0 and freqCnt[maxc] == 0:
    maxc -= 1
```

這是「眾數出現次數」的經典 `O(1)` 維護法。

### 排序策略決定總移動量

把所有查詢排序。最樸素是按 `l` 排序，`r` 可能每次都從頭跑到尾 → `O(n·q)`。
莫隊的做法是**分塊**：塊長 `B ≈ √n`，排序鍵為

```
(l 所在塊, r)     且奇數塊的 r 用**降序**（奇偶優化）
```

這樣：

- 同一塊內 `r` 單調移動 → 每塊 `r` 總共走 `O(n)`，共 `O(n^1.5)`；
- 換塊時 `r` 最多跳回 `n`，共 `O(√n)` 次 → `O(n^1.5)`；
- `l` 在塊內每次最多走 `B` → 每次查詢 `O(√n)`，共 `O(q·√n)`。

奇偶優化讓 `r` 在塊與塊之間「來回掃」而不是每次都跳回起點，常數減半。

### 帶修莫隊：多一維「時間」

現在陣列還會被修改。把每個查詢看成三維點 `(l 塊, r 塊, t)`，
其中 `t` 是「這個查詢之前發生過幾次修改」。塊長取 `B ≈ n^(2/3)`，
排序鍵 `(l 塊, r 塊, t)`。

移動時除了動 `L`、`R`，還要把時間從 `curT` 推向 `t`：

- 時間往前：套用修改（若被改的位置在當前區間內，要先 `remove` 舊值、`add` 新值）；
- 時間往後：撤銷修改（同理）。

複雜度 `O(n^(5/3))`。

### 為什麼兩個語言能逐位元組一致

塊長用**整數平方根 / 整數立方根**（二分找最大的 `b`）算，不用浮點；
排序鍵是純整數、並以查詢編號做最終 tie-break，因此排序結果唯一。
而答案與處理順序無關，所以兩邊必然一致。

## 複雜度

| 項目 | 複雜度 |
|---|---|
| 普通莫隊（塊長 `√n`） | `O((n + q)·√n)` |
| 帶修莫隊（塊長 `n^(2/3)`） | `O(n^(5/3))` |
| 暴力對拍 | `O(n·q)` |
| 空間 | `O(n + q)` |

## 輸入格式

```
n
a_1 ... a_n                 初始陣列
q                           靜態查詢個數
l_1 r_1                     q 組，1-indexed 閉區間
...
m                           帶修改操作數
op x y                      m 組（1 l r 查詢 / 2 p x 修改，1-indexed）
```

非數字 token 一律視為「輸入到此為止」；讀不滿的那一組直接丟棄。
`n`、`q`、`m` 截斷到 `[0, 3000]`；數值截斷到 `[-10^9, 10^9]`。
靜態查詢的 `l`、`r` 會先截斷到 `[1, n]` 再排序（`n = 0` 時得到空區間）。

## 輸出格式

```
q                          靜態查詢個數
distinct sum mode          q 行
...
q2                         帶修查詢個數
distinct sum mode          q2 行
...
```

## 範例

輸入：

```
6
1 2 1 3 2 1
3
1 3
2 5
1 6
5
1 1 6
2 3 9
1 1 6
2 1 9
1 2 4
```

輸出：

```
3
2 4 2
3 8 2
3 10 3
3
3 10 3
4 18 2
3 14 1
```

解讀（靜態部分，`a = [1,2,1,3,2,1]`）：

- `[1,3] = [1,2,1]` → distinct 2、sum 4、mode 2
- `[2,5] = [2,1,3,2]` → distinct 3、sum 8、mode 2
- `[1,6]` 全部 → distinct 3、sum 10、mode 3

帶修部分：

- 第 1 個查詢（尚未修改）→ `3 10 3`
- `a[3] = 9` 後查 `[1,6] = [1,2,9,3,2,1]` → distinct 4、sum 18、mode 2
- `a[1] = 9` 後查 `[2,4] = [2,9,3]` → distinct 3、sum 14、mode 1

## 怎麼跑

```bash
python solution.py          # 無 stdin → 跑內置斷言，輸出 all tests passed
g++ -std=c++17 -O2 -Wall solution.cpp -o solution && ./solution
```

> Windows / MinGW 下不要把編譯產物輸出到 `/tmp`（鏈接器會報 No such file or directory）。

## 應用場景

- 靜態陣列的大量區間查詢：顏色計數、區間眾數、區間不同數、
  「區間內有多少對 `(i,j)` 滿足 `a_i = a_j`」、區間 mex
- 帶修改版本：日誌回放分析、資料庫在「某個時間點」的區間統計
- 變體：樹上莫隊（歐拉序把路徑轉成區間）、回滾莫隊（只加不刪，
  處理「區間最大值」這類需要 `O(1)` 撤銷的問題）、二維莫隊
