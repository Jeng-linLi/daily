# CDQ 分治：逆序對計數 / 三維偏序（陌上花開）/ 分治優化 DP

`solution.py`（Python 3 標準庫）・`solution.cpp`（C++17）

## 題意

給定三個長度為 `n` 的整數陣列 `a`、`b`、`c`（第 `i` 個三元組為 `(a_i, b_i, c_i)`）
以及權重陣列 `w`，輸出四項結果：

1. 陣列 `b` 的**逆序對個數**；
2. 對每個 `i`，三元組偏序計數
   `f(i) = #{ j ≠ i : a_j ≤ a_i, b_j ≤ b_i, c_j ≤ c_i }`；
3. 分治優化 DP：`dp[i] = w_i + max{ dp[j] : j < i 且 a_j ≤ a_i }`
   （沒有合法的 `j` 時 `dp[i] = w_i`）；
4. `max(dp)`（`n = 0` 時為 `0`）。

以上全部用 CDQ 分治完成，並與 `O(n²)` 暴力對拍。

## 思路

### CDQ 分治在做什麼

普通分治是「切兩半 → 各自遞迴 → **合併**」。CDQ 分治多了一步：
**統計「跨左右兩半」的貢獻**——有多少對 `(u, v)` 滿足 `u` 在左半、`v` 在右半且滿足某個條件。

只要每一對 `(u, v)` 在遞迴樹上恰好在「它們分開的那一層」被統計一次，
全部跨半貢獻加起來就是全體配對的答案。
這就是把一個 `O(n²)` 的配對統計降到 `O(n log n)`（或 `O(n log² n)`）的關鍵。

### ① 逆序對（一維 CDQ）

求 `#{(i, j) : i < j 且 b_i > b_j}`。
左右兩半都已經「依 `b` 排序」，歸併時右半元素 `b_j` 讓左半指標停下來時，
左半剩下的每一個都比它大 → 一次加一整段。
這其實就是「合併排序數逆序對」，只是從 CDQ 的視角看它。

### ② 三維偏序（CDQ + 樹狀陣列）

先依 `(a, b, c)` 字典序排序。因為已依 `a` 升序，對任意「左半位置 `u` < 右半位置 `v`」
必有 `a_u ≤ a_v`——`a` 這一維**自動滿足**，只剩下 `b`、`c` 兩維要處理。

CDQ 的不變量是「遞迴返回後，區段內依 `b` 排序」，於是可以：

- 兩個指標掃描（左半依 `b`、右半依 `b`）；
- 左半走過的元素把它的 `c` 加到樹狀陣列（`c` 需離散化）；
- 右半每個 `v` 查詢「`c ≤ c_v` 的個數」，就是左半對它的貢獻。

跨半統計 `O(n log n)`，遞迴 `log n` 層 → 總共 `O(n log² n)`。

**相同三元組要特別處理**：CDQ 只數到「排序後位置 `u < v`」的配對，題意卻要求 `j ≠ i` 的全部。
若相同三元組佔排序後位置 `p .. p+s-1`，那麼對位置 `v` 的元素，組內還有 `s-1-(v-p)` 個
排在它後面、沒被 CDQ 數到的同伴。補上這一項就與暴力完全一致。

> 實作陷阱：分組資訊必須以**原始下標**為鍵保存。
> CDQ 返回時陣列已依 `b` 排序，位置 `v` 早已換成別的元素了。

### ③ 分治優化 DP

遞推 `dp[i] = w_i + max{ dp[j] : j < i 且 a_j ≤ a_i }`，
可以看成「二維偏序上的最大值」（第一維是下標、第二維是 `a`）。

`CDQ(l, r)` 的**順序**（這是最容易寫錯的地方）：

1. 遞迴左半 `cdq(l, m)`：左半的 `dp` 全部算完，且左半**依 `a` 排序**；
2. 跨半更新：左半預處理「`dp` 前綴最大值」，右半每個 `i` 用二分找到
   「`a ≤ a_i` 的最後一個位置」，`O(log n)` 拿到 `max{dp[j]}`
   （右半此時仍是原始下標順序，正好符合 `j < i` 的要求）；
3. 再遞迴右半 `cdq(m, r)`：右半用左半更新後的 `dp` 繼續算；
4. 依 `a` 歸併，維持不變量。

第 2 步必須在第 3 步之前。

> 另一個陷阱：「沒有合法 `j`」與「有一個 `dp[j] = 0` 的合法 `j`」語義不同
> （後者的 `dp[j]` 可能是負數），所以不能讓 `w_i` 直接參與 `max`，
> 必須用 `NEG_INF` 哨兵把「沒有」和「有」區分開。

## 複雜度

| 項目 | 複雜度 |
|---|---|
| 逆序對（一維 CDQ） | `O(n log n)` |
| 三維偏序（CDQ + BIT） | `O(n log² n)` |
| 分治優化 DP | `O(n log n)` |
| 暴力對拍 | `O(n²)` |
| 空間 | `O(n)` |

## 輸入格式

```
n
a_1 ... a_n
b_1 ... b_n
c_1 ... c_n
w_1 ... w_n
```

非數字 token 一律視為「輸入到此為止」；讀不滿的那一列直接丟棄，
四列會統統截斷到最短長度。`n` 截斷到 `[0, 3000]`，數值截斷到 `[-10^12, 10^12]`。

## 輸出格式（4 行）

```
逆序對個數（陣列 b）
f(1) ... f(n)
dp_1 ... dp_n
max(dp)          # n = 0 時為 0
```

## 範例

輸入：

```
4
1 2 1 3
1 2 1 2
1 1 2 1
5 1 3 2
```

輸出：

```
1
0 1 1 2
5 6 8 10
10
```

解讀：

- 三元組為 `(1,1,1) (2,2,1) (1,1,2) (3,2,1)`。
  `b = [1,2,1,2]` 的逆序對只有 `(2,1)` 一對 → `1`。
- `f(0) = 0`；`f(1) = 1`（被第 0 個支配）；`f(2) = 1`（被第 0 個支配）；
  `f(3) = 2`（被第 0、1 個支配；第 2 個的 `c = 2 > 1`）。
- `dp`：第 0 個無前驅 → `5`；第 1 個接第 0 個 → `1 + 5 = 6`；
  第 2 個接第 0 個 → `3 + 5 = 8`；第 3 個接第 2 個 → `2 + 8 = 10`。最大值 `10`。

## 應用場景

- 逆序對：排序代價、推薦系統的「偏好一致性」度量（Kendall tau 距離）
- 三維偏序：多維支配關係統計（「各方面都不比我差的人有多少」）、資料庫的 skyline / 支配計數、
  遊戲戰力排行榜
- 分治優化 DP：一維 DP 加上偏序約束時（帶權 LIS、嵌套矩形、多條件最長鏈），
  把 `O(n²)` 降到 `O(n log n)`
- 進階：CDQ 分治 + FFT（多項式卷積）、CDQ 套 CDQ（四維偏序）
