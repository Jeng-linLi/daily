# 樹形 DP 與換根 DP（最大獨立集 / 直徑 / 重心 / 距離統計）

| 語言 | 檔案 |
|---|---|
| Python 3 | [`solution.py`](solution.py) |
| C++17 | [`solution.cpp`](solution.cpp) |

## 題意

給定一棵樹（或森林，無向無環圖，n 個點 m 條邊），求：

1. **最大獨立集**：最大的點集，使集合中任意兩點之間沒有邊；
2. **樹的直徑**：最長路徑的長度（邊數）與具體路徑；
3. **樹的重心**：刪掉該點後，剩下的最大連通塊大小 ≤ n/2 的點（可能 1 或 2 個）；
4. **換根 DP 之 `maxdist`**：對每個點 u，求 u 到「所在連通分量內最遠點」的距離；
5. **換根 DP 之 `sumdist`**：對每個點 u，求 u 到「所在連通分量內所有點」的距離之和。

## 思路

### 樹形 DP 的基本套路

任取一點為根，把「無根樹」轉成「有根樹」，於是可以自底向上（後序）做 DP：每個點 u 的狀態只依賴它的子節點，`dp[u] = 合併(所有子節點 v 的 dp[v])`。複雜度通常是 O(n)，因為每條邊只被處理常數次。

### 最大獨立集

每個點有「選 / 不選」兩種狀態：

```
dp1[u] = 1 + Σ dp0[v]            （選 u ⟹ 所有子節點都不能選）
dp0[u] = Σ max(dp0[v], dp1[v])   （不選 u ⟹ 子節點隨意）
```

答案 `max(dp0[root], dp1[root])`。這是「樹上狀態機 DP」最簡單的一例。
方案重建：父節點被選則子節點強制不選；否則取 `dp1 ≥ dp0` 者（平手優先選）。

### 樹的直徑（兩次 BFS）

從任意點 s 出發走到最遠的點 a，再從 a 出發走到最遠的點 b，則 a–b 必定是一條直徑。對森林則對每個連通分量各做一次並取最大。

> 這個性質只對**樹**成立；一般圖不成立（一般圖要用 Floyd 或 Johnson）。

### 樹的重心

以任意點為根，記 `sz[u]` 為 u 的子樹大小。刪掉 u 後會分成若干塊：每個子節點 v 對應一塊大小 `sz[v]`，父親方向對應一塊大小 `compSize − sz[u]`。取這些塊的最大值，若 `≤ compSize/2` 則 u 是重心。重心必存在且最多 2 個。

> ⚠️ **森林要逐分量判定**：只統計與 u **同分量**的塊，且與 `comp[root[u]]` 比較。
> 若把其它分量也算進來，塊大小會被無關的分量撐大，定義就錯了（本題第一版就踩了這個坑）。

### 換根 DP（本題重點）

上面那些量若「以每個點為根各算一次」是 O(n²)。換根 DP 把它降到 O(n)：先做一次自底向上（bottom-up）拿到「向下」的資訊，再做一次自頂向下（top-down）把「向上」的資訊補給每個子節點，於是每個點都同時擁有「往下看」和「往上看」的視角。

**maxdist**：對每個 u 維護向下最長的兩條路徑 `best1 / best2`（並記下 `best1` 是從哪個子節點來的）。對子節點 v：

```
up[v] = 1 + max( up[u], best_excluding_v[u] )
maxdist[u] = max(best1[u], up[u])
```

其中 `best_excluding_v[u]` 是「不從 v 這個分支走」的最佳值（`who1[u] == v` 時取 `best2`，否則取 `best1`）。記「兩條最長」而不是「一條最長」，正是為了能在 O(1) 內排除掉 v 自己的貢獻。

**sumdist**：記 `sz[u]` 與 `sub[u]`（u 到子樹內所有點的距離和）。把根從 u 換到子節點 v 時，v 這一側的 `sz[v]` 個點距離各減 1，其餘 `compSize − sz[v]` 個點距離各加 1：

```
sumdist[v] = sumdist[u] − sz[v] + (compSize − sz[v])
```

O(1) 轉移，一趟 top-down 全部算完。

## 應用場景

社交網路中「影響力最大」的節點（`sumdist` 最小 = 最接近所有人的點）、
伺服器 / 倉庫選址（樹上最小化最大延遲 = 直徑中心、也是 `maxdist` 最小的點）、
依賴樹上的任務調度（最大獨立集 = 互不衝突的最大任務集）、
文件目錄樹與組織架構的聚合統計。

## 複雜度

| 項目 | 時間 | 空間 |
|---|---|---|
| 最大獨立集 / 重心 / 換根 DP | O(n) | O(n) |
| 直徑（兩次 BFS，對每個分量） | O(n) | O(n) |
| 暴力基準（從每個點 BFS） | O(n·(n+m)) | O(n) |

## 輸入輸出

輸入（stdin，全部以空白分隔）：

```
n m
m 行：u v        （0-indexed 無向邊；重邊與自環會被忽略；越界邊忽略）
```

`n = 0` 或輸入不足時視為空圖；遇到非整數 token 視為輸入結束。

輸出（stdout）：

```
第 1 行：最大獨立集大小
第 2 行：獨立集節點（升序，空格分隔）
第 3 行：直徑長度（邊數；空圖為 0）
第 4 行：直徑路徑（空格分隔；空圖輸出空行）
第 5 行：重心個數
第 6 行：重心（升序，空格分隔）
第 7 行：maxdist[0..n-1]（空格分隔）
第 8 行：sumdist[0..n-1]（空格分隔）
```

無 stdin 輸入時運行內置斷言測試並輸出 `all tests passed`。

### 範例

輸入（7 個點的滿二元樹：0 為根，1/2 為孩子，3/4 掛在 1，5/6 掛在 2）：

```
7 6
0 1
0 2
1 3
1 4
2 5
2 6
```

輸出：

```
5
0 3 4 5 6
4
5 2 0 1 3
1
0
2 3 3 4 4 4 4
10 11 11 16 16 16 16
```

說明：

- **最大獨立集** = 5，取 `0, 3, 4, 5, 6`（根 + 四個葉子），是最優的「隔層取點」方案。
- **直徑** = 4 條邊，路徑 `5 → 2 → 0 → 1 → 3`（葉到葉）。
- **重心** 只有 `0`：刪掉 0 後剩下兩個大小 3 的塊，`3 ≤ 7/2`，符合定義。
- **maxdist** = `[2,3,3,4,4,4,4]`：0 到最遠的葉子是 2，四個葉子到最遠點都是 4。
- **sumdist** = `[10,11,11,16,16,16,16]`：0 的距離和 `1+1+2+2+2+2 = 10` 最小，
  也就是說 **0 是這棵樹的「距離和中心」**，選址問題會挑它。

## 怎麼跑

```bash
python solution.py          # 無輸入 → 跑內置斷言
printf '7 6\n0 1\n0 2\n1 3\n1 4\n2 5\n2 6\n' | python solution.py

g++ -std=c++17 -O2 solution.cpp -o solution && ./solution
```

> Windows / MinGW 下不要把編譯產物輸出到 `/tmp`（鏈接器會報 No such file or directory），輸出到當前目錄即可。
