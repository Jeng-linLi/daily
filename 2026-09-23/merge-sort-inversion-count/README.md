# 歸併排序與逆序對計數（Merge Sort & Inversion Count）

| 語言 | 文件 |
|---|---|
| Python 3 | [`solution.py`](solution.py) |
| C++17 | [`solution.cpp`](solution.cpp) |

## 題意

給定長度爲 `n` 的整數序列 `a`，求其中「逆序對」的個數，即滿足 `i < j` 且 `a[i] > a[j]` 的二元組 `(i, j)` 的數量，並輸出升序排序後的序列。

## 思路

暴力做法是雙重循環 `O(n²)`。歸併排序能順手把逆序對數出來，是因爲逆序對天生可以按「分治三分類」拆解：對區間 `[lo, hi)` 以 `mid` 切分後，任意一個逆序對 `(i, j)` 恰好屬於下面三類之一，**不重不漏**：

1. `i, j` 都在左半邊 → 遞歸統計
2. `i, j` 都在右半邊 → 遞歸統計
3. `i` 在左半邊、`j` 在右半邊 → **跨中線的逆序對**

關鍵在第 3 類。合併兩個「已各自有序」的子數組時，一旦出現 `arr[i] > arr[j]`，由於左半邊 `arr[i..mid)` 是升序的，`arr[i]` 及其後面所有元素都 `≥ arr[i] > arr[j]`，於是它們與 `arr[j]` 一次性構成 `mid - i` 個逆序對。

```text
左半邊（已升序）:  ... arr[i] arr[i+1] ... arr[mid-1]
右半邊（已升序）:  ... arr[j] ...
若 arr[i] > arr[j]，則 arr[i..mid-1] 全部 > arr[j]  →  一次結算 (mid - i) 個
```

一次比較結算一整段，這就是把 `O(n²)` 壓到 `O(n log n)` 的來源。

### 兩個容易寫錯的點

- **比較要取等號**：必須寫成 `arr[i] <= arr[j]` 才走左半邊。若寫成 `<`，相等元素會被誤判成逆序對，違背「逆序對 = 嚴格大於」的定義。歸併排序是否穩定，也就取決於這個等號的方向。
- **計數要用 64 位**：逆序對的上界是完全逆序時的 `n(n-1)/2`，`n = 65536` 就已超過 `int` 範圍。C++ 側用 `long long`。

### 一個有用的等價視角

逆序對個數 **恰好等於** 「只允許交換相鄰元素」時把序列排好序所需的最少交換次數 —— 也就是冒泡排序的交換次數。因爲一次相鄰交換最多消去一個逆序對，而冒泡排序每次交換都恰好消去一個。

## 複雜度

| 版本 | 時間複雜度 | 空間複雜度 |
|---|---|---|
| 歸併統計 `sortAndCount` | O(n log n) | O(n)（輔助數組） |
| 暴力 `countInversionsBrute` | O(n²) | O(1) |

歸併排序的時間複雜度與輸入數據的有序程度無關，最好/最壞/平均都是 `O(n log n)`（快排在最壞情況下會退化到 `O(n²)`）。

## 輸入輸出

```text
輸入：              輸出：
5                   5
2 3 8 6 1           1 2 3 6 8
```

- 第一行 `n`，第二行 `n` 個整數（可跨行書寫）。
- 輸出第一行：逆序對個數；第二行：升序排序後的序列（空格分隔；`n = 0` 時輸出空行）。
- 上例中 5 個逆序對分別是 `(2,1) (3,1) (8,6) (8,1) (6,1)`。
- Python 與 C++ 版本的輸入輸出格式完全一致。
- 無 stdin 輸入時，兩個版本都會運行內置斷言測試並輸出 `all tests passed`。

## 測試覆蓋

固定用例：空序列、單元素、已升序（0 個）、完全逆序（10 個）、相等元素不算逆序對、負數與零、`n = 2000` 的完全逆序（驗證 `long long` 不溢出）。

隨機對拍：兩版各自用固定種子（20260923）生成 300 組長度 0–40、值域 `[-20, 20]` 的隨機序列，與 `O(n²)` 暴力枚舉對比，同時校驗逆序對數一致、排序結果與標準庫一致、元素個數不變；另外驗證排序不會改動調用方傳入的原數組/列表。
