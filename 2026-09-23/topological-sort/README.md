# 拓撲排序（Topological Sort，Kahn 算法 + DFS 逆後序）

| 語言 | 文件 |
|---|---|
| Python 3 | [`solution.py`](solution.py) |
| C++17 | [`solution.cpp`](solution.cpp) |

## 題意

給定一張 `n` 個點、`m` 條邊的有向圖（點編號 `0..n-1`），求一個**拓撲序**：把所有點排成一列，使得對每條有向邊 `u → v`，`u` 都排在 `v` 之前。若圖中存在環，則不存在拓撲序，報告無解。

## 思路

### 1. Kahn 算法（BFS / 剝洋蔥）

不斷把「入度爲 0 的點」拿掉；拿掉一個點，就把它指向的點的入度減一，於是新的入度爲 0 的點會湧現出來。

- 若最終拿掉了全部 `n` 個點，**拿掉的先後順序**就是一個拓撲序；
- 若中途再也找不到入度爲 0 的點卻還有剩餘，說明剩下的點互相卡住 —— 它們**必定**在環裏（因爲剩餘子圖中每個點都有入邊，沿着入邊一路回溯必然重複訪問某個點，形成環）。

用**最小堆**而不是普通隊列來挑選入度爲 0 的點，就得到**字典序最小**的拓撲序；用普通隊列則只能得到某個（取決於入邊順序的）合法拓撲序。

### 2. DFS 逆後序

對圖做深度優先搜索，在「一個點的所有後繼都訪問完之後」才把它壓入棧，最後把棧倒過來輸出。正確性來自後序的性質：DFS 保證後繼先於前驅完成，反過來就是前驅排在後繼之前。

判環靠**三色標記**：白色（未訪問）、灰色（在當前遞歸棧上）、黑色（已完成）。若 DFS 走到一個灰色點，說明存在回邊，即圖中有環。

### 兩者怎麼選

| | Kahn（BFS） | DFS 逆後序 |
|---|---|---|
| 判環 | 天然支持（剩餘點數 < n） | 需三色標記 |
| 遞歸深度 | 迭代，無爆棧風險 | 樸素遞歸在鏈狀深圖上會爆棧（本實現已改成迭代版） |
| 輸出順序 | 換最小堆即得字典序最小解 | 一般不是字典序最小 |

兩種實現都用**升序鄰接表**驅動，保證結果可復現、兩版可對照。

## 複雜度

| 版本 | 時間複雜度 | 空間複雜度 |
|---|---|---|
| Kahn（最小堆） | O((n + m) log n) | O(n + m) |
| Kahn（普通隊列） | O(n + m) | O(n + m) |
| DFS 逆後序 | O(n + m) | O(n + m) |

`n` 爲點數、`m` 爲邊數。堆的 `log n` 是爲「字典序最小」付出的代價；若只要求任意一個合法拓撲序，換成隊列即可降到線性。

## 輸入輸出

```text
輸入：               輸出：
6 6                  0 1 2 3 5 4
0 1
0 2
1 3
2 3
2 4
5 4
```

- 第一行 `n m`，接下來 `m` 行每行 `u v`（一條有向邊 `u → v`）。
- 輸出一行：拓撲序（字典序最小的那個，空格分隔）；若圖中有環，輸出 `-1`。
- 上例的推演：初始入度 0 的是 `{0, 5}` → 取 `0` → `{1, 2, 5}` → 取 `1` → `{2, 5}` → 取 `2` → `{3, 5}` → 取 `3` → `{5}` → 取 `5` → `{4}` → 取 `4`。
- Python 與 C++ 版本的輸入輸出格式完全一致。
- 無 stdin 輸入時，兩個版本都會運行內置斷言測試並輸出 `all tests passed`。

## 測試覆蓋

固定用例：README 示例、三元環 `0→1→2→0`、自環、空圖、單點、重邊（驗證同一點不會被重複輸出）、鏈 + 孤立點、環與無環混合（有一個環就整體無解）。

隨機對拍：兩版各自用固定種子（20260923）生成 200 組 `n ≤ 6`、邊密度 25% 的隨機有向圖，與**全排列枚舉**的暴力解對比，同時校驗三件事：Kahn 的結果等於字典序最小解、DFS 的結果是合法拓撲序、兩者「有解 / 無解」的判斷一致。

另外用 `n = 20000` 的鏈狀圖驗證迭代版 DFS 不會爆棧（Python 與 C++ 兩版都是迭代實現）。
