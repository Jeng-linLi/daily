# 拓扑排序（Topological Sort，Kahn 算法 + DFS 逆后序）

| 语言 | 文件 |
|---|---|
| Python 3 | [`solution.py`](solution.py) |
| C++17 | [`solution.cpp`](solution.cpp) |

## 题意

给定一张 `n` 个点、`m` 条边的有向图（点编号 `0..n-1`），求一个**拓扑序**：把所有点排成一列，使得对每条有向边 `u → v`，`u` 都排在 `v` 之前。若图中存在环，则不存在拓扑序，报告无解。

## 思路

### 1. Kahn 算法（BFS / 剥洋葱）

不断把「入度为 0 的点」拿掉；拿掉一个点，就把它指向的点的入度减一，于是新的入度为 0 的点会涌现出来。

- 若最终拿掉了全部 `n` 个点，**拿掉的先后顺序**就是一个拓扑序；
- 若中途再也找不到入度为 0 的点却还有剩余，说明剩下的点互相卡住 —— 它们**必定**在环里（因为剩余子图中每个点都有入边，沿着入边一路回溯必然重复访问某个点，形成环）。

用**最小堆**而不是普通队列来挑选入度为 0 的点，就得到**字典序最小**的拓扑序；用普通队列则只能得到某个（取决于入边顺序的）合法拓扑序。

### 2. DFS 逆后序

对图做深度优先搜索，在「一个点的所有后继都访问完之后」才把它压入栈，最后把栈倒过来输出。正确性来自后序的性质：DFS 保证后继先于前驱完成，反过来就是前驱排在后继之前。

判环靠**三色标记**：白色（未访问）、灰色（在当前递归栈上）、黑色（已完成）。若 DFS 走到一个灰色点，说明存在回边，即图中有环。

### 两者怎么选

| | Kahn（BFS） | DFS 逆后序 |
|---|---|---|
| 判环 | 天然支持（剩余点数 < n） | 需三色标记 |
| 递归深度 | 迭代，无爆栈风险 | 朴素递归在链状深图上会爆栈（本实现已改成迭代版） |
| 输出顺序 | 换最小堆即得字典序最小解 | 一般不是字典序最小 |

两种实现都用**升序邻接表**驱动，保证结果可复现、两版可对照。

## 复杂度

| 版本 | 时间复杂度 | 空间复杂度 |
|---|---|---|
| Kahn（最小堆） | O((n + m) log n) | O(n + m) |
| Kahn（普通队列） | O(n + m) | O(n + m) |
| DFS 逆后序 | O(n + m) | O(n + m) |

`n` 为点数、`m` 为边数。堆的 `log n` 是为「字典序最小」付出的代价；若只要求任意一个合法拓扑序，换成队列即可降到线性。

## 输入输出

```text
输入：               输出：
6 6                  0 1 2 3 5 4
0 1
0 2
1 3
2 3
2 4
5 4
```

- 第一行 `n m`，接下来 `m` 行每行 `u v`（一条有向边 `u → v`）。
- 输出一行：拓扑序（字典序最小的那个，空格分隔）；若图中有环，输出 `-1`。
- 上例的推演：初始入度 0 的是 `{0, 5}` → 取 `0` → `{1, 2, 5}` → 取 `1` → `{2, 5}` → 取 `2` → `{3, 5}` → 取 `3` → `{5}` → 取 `5` → `{4}` → 取 `4`。
- Python 与 C++ 版本的输入输出格式完全一致。
- 无 stdin 输入时，两个版本都会运行内置断言测试并输出 `all tests passed`。

## 测试覆盖

固定用例：README 示例、三元环 `0→1→2→0`、自环、空图、单点、重边（验证同一点不会被重复输出）、链 + 孤立点、环与无环混合（有一个环就整体无解）。

随机对拍：两版各自用固定种子（20260923）生成 200 组 `n ≤ 6`、边密度 25% 的随机有向图，与**全排列枚举**的暴力解对比，同时校验三件事：Kahn 的结果等于字典序最小解、DFS 的结果是合法拓扑序、两者「有解 / 无解」的判断一致。

另外用 `n = 20000` 的链状图验证迭代版 DFS 不会爆栈（Python 与 C++ 两版都是迭代实现）。
