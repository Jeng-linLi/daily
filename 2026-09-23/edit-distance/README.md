# 編輯距離（Edit Distance / Levenshtein Distance，動態規劃）

| 語言 | 文件 |
|---|---|
| Python 3 | [`solution.py`](solution.py) |
| C++17 | [`solution.cpp`](solution.cpp) |

## 題意

給定兩個字符串 `a`、`b`，允許三種操作：**插入**一個字符、**刪除**一個字符、把一個字符**替換**成另一個字符。求把 `a` 變成 `b` 所需的最少操作次數，並給出一條達到該次數的操作序列。

## 思路

定義 `dp[i][j]` = 把 `a` 的前 `i` 個字符變成 `b` 的前 `j` 個字符的最少操作數。只看最後一個字符，「最後一步」必定是三者之一：

| 最後一步 | 轉移 | 含義 |
|---|---|---|
| 刪掉 `a[i-1]` | `dp[i-1][j] + 1` | `a` 少一個字符後已能變成 `b` 的前 j 個 |
| 插入 `b[j-1]` | `dp[i][j-1] + 1` | `a` 的前 i 個已能變成 `b` 的前 j-1 個，末尾補上 `b[j-1]` |
| 改 / 保留 `a[i-1]` | `dp[i-1][j-1] + (a[i-1] != b[j-1])` | 字符相同則 0 代價，否則一次替換 |

三者取最小。邊界：`dp[0][j] = j`（全插入）、`dp[i][0] = i`（全刪除）。

### 空間壓縮

`dp` 可壓成一維，掃描第 `i` 行時：

- `dp[j]` 更新前就是上一行的 `dp[i-1][j]`（刪除）；
- `dp[j-1]` 是本行剛算好的 `dp[i][j-1]`（插入）；
- `dp[i-1][j-1]` 已經被覆蓋掉了，所以要用一個 `prev_diag` 變量把左上角的值隨身帶着往前滾。

### 還原操作序列

一維表算得出最優值，但丟了決策軌跡。要輸出方案必須保留二維表，從 `dp[m][n]` 往回走，每步挑一個「能解釋當前 `dp` 值」的前驅。

回溯是**從後往前**生成操作的，因此下標天然遞減。這樣做的好處是：按生成順序依次施加時，每次改動只影響下標 `≥` 當前下標的字符 —— 更靠後的已經處理完不會被挪動，更靠前的還沒動。所以「按下標遞減順序施加」是自洽的，每個下標指的就是**施加這一操作時字符串裏的位置**，無需做下標偏移修正。

> 最短方案通常**不唯一**（`horse → ros` 有多條長度爲 3 的路徑），回溯只保證給出其中一條。測試因此只斷言「操作次數等於最優值」且「照着做一遍確實得到 `b`」，不鎖死具體是哪條路徑。

## 複雜度

| 版本 | 時間複雜度 | 空間複雜度 |
|---|---|---|
| 一維 `editDistance` | O(m·n) | O(min(m, n)) |
| 二維 `editDistanceWithOps` | O(m·n) | O(m·n) |

`m, n` 爲兩串長度。若只允許插入/刪除（不允許替換），問題退化爲「最長公共子序列」：`dist = m + n - 2·LCS(a, b)`。

## 輸入輸出

```text
輸入：               輸出：
horse                3
ros                  delete 4
                     delete 2
                     replace 0 r
```

- 第一行字符串 `a`，第二行字符串 `b`（可以是空行）。
- 輸出第一行：最少操作次數；接下來每行一條操作：
  - `replace <下標> <字符>` —— 把該下標的字符改成給定字符
  - `delete <下標>` —— 刪掉該下標的字符
  - `insert <下標> <字符>` —— 插到該下標**之前**（下標等於串長時表示追加到末尾）
- 下標 0-based，且指的是**施加該操作時**字符串中的位置；兩個串本來就相等時不輸出任何操作行。
- 上例把 `horse` 變成 `ros`：`horse → hors → hos → ros`（從後往前刪掉 `e`、`r`，再把 `h` 換成 `r`）。注意操作是從串尾往串頭生成的，所以下標遞減、無需偏移修正。
- Python 與 C++ 版本的輸入輸出格式完全一致（同一套回溯優先級，輸出逐字節相同）。
- 無 stdin 輸入時，兩個版本都會運行內置斷言測試並輸出 `all tests passed`。

## 測試覆蓋

固定用例：`horse → ros`（3 步）、`intention → execution`（5 步）、`kitten → sitting`（3 步）、完全相同（0 步）、一邊爲空（全插 / 全刪）、單字符替換、大小寫敏感、純插入。

隨機對拍：兩版各自用固定種子（20260923）在字母表 `{a, b, c}` 上生成 200 組長度 0–7 的隨機串，與帶記憶化的暴力搜索對比，同時校驗四件事：一維版 = 二維版 = 暴力版、操作條數等於最優值、`applyOps` 照着做一遍確實得到目標串。另外校驗編輯距離的**對稱性** `d(x, y) == d(y, x)`。
