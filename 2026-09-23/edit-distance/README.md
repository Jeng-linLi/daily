# 编辑距离（Edit Distance / Levenshtein Distance，动态规划）

| 语言 | 文件 |
|---|---|
| Python 3 | [`solution.py`](solution.py) |
| C++17 | [`solution.cpp`](solution.cpp) |

## 题意

给定两个字符串 `a`、`b`，允许三种操作：**插入**一个字符、**删除**一个字符、把一个字符**替换**成另一个字符。求把 `a` 变成 `b` 所需的最少操作次数，并给出一条达到该次数的操作序列。

## 思路

定义 `dp[i][j]` = 把 `a` 的前 `i` 个字符变成 `b` 的前 `j` 个字符的最少操作数。只看最后一个字符，「最后一步」必定是三者之一：

| 最后一步 | 转移 | 含义 |
|---|---|---|
| 删掉 `a[i-1]` | `dp[i-1][j] + 1` | `a` 少一个字符后已能变成 `b` 的前 j 个 |
| 插入 `b[j-1]` | `dp[i][j-1] + 1` | `a` 的前 i 个已能变成 `b` 的前 j-1 个，末尾补上 `b[j-1]` |
| 改 / 保留 `a[i-1]` | `dp[i-1][j-1] + (a[i-1] != b[j-1])` | 字符相同则 0 代价，否则一次替换 |

三者取最小。边界：`dp[0][j] = j`（全插入）、`dp[i][0] = i`（全删除）。

### 空间压缩

`dp` 可压成一维，扫描第 `i` 行时：

- `dp[j]` 更新前就是上一行的 `dp[i-1][j]`（删除）；
- `dp[j-1]` 是本行刚算好的 `dp[i][j-1]`（插入）；
- `dp[i-1][j-1]` 已经被覆盖掉了，所以要用一个 `prev_diag` 变量把左上角的值随身带着往前滚。

### 还原操作序列

一维表算得出最优值，但丢了决策轨迹。要输出方案必须保留二维表，从 `dp[m][n]` 往回走，每步挑一个「能解释当前 `dp` 值」的前驱。

回溯是**从后往前**生成操作的，因此下标天然递减。这样做的好处是：按生成顺序依次施加时，每次改动只影响下标 `≥` 当前下标的字符 —— 更靠后的已经处理完不会被挪动，更靠前的还没动。所以「按下标递减顺序施加」是自洽的，每个下标指的就是**施加这一操作时字符串里的位置**，无需做下标偏移修正。

> 最短方案通常**不唯一**（`horse → ros` 有多条长度为 3 的路径），回溯只保证给出其中一条。测试因此只断言「操作次数等于最优值」且「照着做一遍确实得到 `b`」，不锁死具体是哪条路径。

## 复杂度

| 版本 | 时间复杂度 | 空间复杂度 |
|---|---|---|
| 一维 `editDistance` | O(m·n) | O(min(m, n)) |
| 二维 `editDistanceWithOps` | O(m·n) | O(m·n) |

`m, n` 为两串长度。若只允许插入/删除（不允许替换），问题退化为「最长公共子序列」：`dist = m + n - 2·LCS(a, b)`。

## 输入输出

```text
输入：               输出：
horse                3
ros                  delete 4
                     delete 2
                     replace 0 r
```

- 第一行字符串 `a`，第二行字符串 `b`（可以是空行）。
- 输出第一行：最少操作次数；接下来每行一条操作：
  - `replace <下标> <字符>` —— 把该下标的字符改成给定字符
  - `delete <下标>` —— 删掉该下标的字符
  - `insert <下标> <字符>` —— 插到该下标**之前**（下标等于串长时表示追加到末尾）
- 下标 0-based，且指的是**施加该操作时**字符串中的位置；两个串本来就相等时不输出任何操作行。
- 上例把 `horse` 变成 `ros`：`horse → hors → hos → ros`（从后往前删掉 `e`、`r`，再把 `h` 换成 `r`）。注意操作是从串尾往串头生成的，所以下标递减、无需偏移修正。
- Python 与 C++ 版本的输入输出格式完全一致（同一套回溯优先级，输出逐字节相同）。
- 无 stdin 输入时，两个版本都会运行内置断言测试并输出 `all tests passed`。

## 测试覆盖

固定用例：`horse → ros`（3 步）、`intention → execution`（5 步）、`kitten → sitting`（3 步）、完全相同（0 步）、一边为空（全插 / 全删）、单字符替换、大小写敏感、纯插入。

随机对拍：两版各自用固定种子（20260923）在字母表 `{a, b, c}` 上生成 200 组长度 0–7 的随机串，与带记忆化的暴力搜索对比，同时校验四件事：一维版 = 二维版 = 暴力版、操作条数等于最优值、`applyOps` 照着做一遍确实得到目标串。另外校验编辑距离的**对称性** `d(x, y) == d(y, x)`。
