# 樹雜湊與樹同構判定（AHU 演算法 / 重心為根的典範雜湊）

## 題意

| 命令 | 語義 |
|---|---|
| `iso n1 m1 u1 v1 ... n2 m2 u2 v2 ...` | 判定兩棵**無標號**樹是否同構，同構輸出 `1`，否則 `0` |
| `hash n m u1 v1 ...` | 輸出該樹的典範雜湊（兩個模數下的值） |

樹以邊清單給出（1-based，各 n 個點、n-1 條邊）。

## 思路

- **子樹簽名**：`hash(u)` 由「所有孩子簽名**排序後**」多項式摺疊而得——
  與孩子順序無關，這正是無標號樹同構的本質（AHU 演算法思想）。
- **以重心為根**：普通以 1 號點為根時，鏈狀樹的兩端會算出不同簽名，
  把同一棵樹判成異構。樹的重心至多兩個，對每個重心各算一次取最小即可。
  （重心性質：刪去後最大子樹不超過 ⌊n/2⌋。）
- **雙雜湊**：兩個質數模（2^31−1、2147483629）+ 兩個基底，壓低碰撞機率；
  簽名比較平手一律取字典序最小，保證結果確定。

摺疊式（每個孩子簽名 (a, b) 打包成一個數再混入）：

```
h = (h * B + a * 2^31 + b) mod M
```

## 複雜度

- 求重心：O(n)；子樹簽名（含每層排序）：O(n log n)
- 同構判定：O(n log n)
- 空間：O(n)

## 輸入輸出示例

```
輸入：hash 5 4 1 2 2 3 3 4 4 5
輸出：37345382 651598130        <- 鏈 1-2-3-4-5 的典範雜湊

輸入：iso 3 2 1 2 2 3 3 2 2 1 2 3
輸出：1                          <- 鏈 3 點 vs 星形 3 點，同構

輸入：iso 4 3 1 2 2 3 3 4 4 3 1 2 1 3 1 4
輸出：0                          <- 鏈 4 點 vs 星形 4 點，不同構
```

## 測試

stdin 無內容時跑內建斷言：

1. 邊界與手算例（單點、兩點、鏈 vs 星形、同一條鏈反轉編號必須同構）。
2. 200 組隨機樹隨機重標號（隨機置換），雜湊必須不變。
3. n ≤ 7 時與全置換暴力同構判定交叉驗證（150 組，雜湊相等 ⟺ 同構）。
4. 無標號樹計數：n = 1..7 的全部 Prüfer 序列窮舉後雜湊去重數，
   應等於 OEIS A000055：`1, 1, 1, 2, 3, 6, 11`。
