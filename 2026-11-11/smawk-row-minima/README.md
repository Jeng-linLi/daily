# SMAWK 演算法（完全單調矩陣逐列最小值 / O(n + m)）

## 題意

給定兩個遞增序列 `x[0..n-1]`、`y[0..m-1]`，定義矩陣
`A[i][j] = (x[i] - y[j])^2`。該矩陣滿足**反 Monge 條件**：

```
A[i][j] + A[i+1][j+1] >= A[i][j+1] + A[i+1][j]
```

進而是**完全單調矩陣**（totally monotone）：若 `A[i][j] >= A[i][j']`
（j < j'），則對所有 `i' > i` 也有 `A[i'][j] >= A[i'][j']`。

對每一列 `i` 輸出一行「最小值 argmin」——即對每個 `x[i]` 找出使距離平方
最小的 `y[j]`（最近鄰配對），格式為 `最小值 argmin`。

## 思路

逐列掃全部欄是 O(n·m)；SMAWK 利用完全單調性做到 **O(n + m)** 次取值：

1. **Reduce**：只用奇數編號的列，維護一個候選欄 stack ——
   當前奇數列在 stack 頂欄不優於新欄（`>=` 語義，平手丟舊欄）時彈棧；
   stack 滿了（長度達奇數列數）就丟棄新欄。
   被丟棄的欄對「所有剩下的列」都被某存活欄支配，
   因此每列的最小值一定留在候選欄裡。
2. **遞迴**：對奇數列 + 候選欄遞迴解出 argmin。
3. **Interpolate**：偶數列的 argmin 被相鄰兩個奇數列的 argmin
   上下夾住（argmin 隨列號單調不減），在該視窗內以「相鄰欄比較」二分：
   `A(r, mid) <= A(r, mid+1)` 時往左收（`hi = mid`），否則往右收。

**實作陷阱**：先把 `y` 去重成嚴格遞增序列再跑 SMAWK —— y 有重複時，
`(x-y)^2` 依索引看在下降段會出現平台（如 `16,16,16,9,9,4,4,1`），
不是嚴格單峰，相鄰比較二分會停在平台邊緣而漏掉真正的最小值。
去重後每列嚴格單峰（至多一組對稱平手），結果再映射回原 y 的首次出現索引。

## 複雜度

- SMAWK：**O(n + m)** 次矩陣取值（本題取值 O(1)）
- 暴力對照：O(n·m)
- 空間：O(n + m)

## 輸入輸出示例

```
輸入：minima 3 2 1 4 9 2 7
輸出：
1 0        <- x=1 最近 y=2（距離平方 1）
4 0        <- x=4 最近 y=2（距離平方 4）
4 1        <- x=9 最近 y=7（距離平方 4）

輸入：minima 5 6 1 2 3 4 5 0 1 1 2 3 3
輸出：
0 1
0 3
0 4
1 4
4 4
```
