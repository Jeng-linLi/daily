# 費波那契堆 Fibonacci Heap（可合併堆 / 攤還 O(1) decrease-key）

## 題意

實作一個支援下列操作的**可合併優先佇列**（0 起始的整數 id 追蹤每個元素）：

| 命令 | 語義 | 攤還複雜度 |
|---|---|---|
| `push k` | 插入鍵值 k，輸出分配到的 id | O(1) |
| `popmin` | 彈出最小鍵值並輸出；空堆輸出 `-1` | O(log n) |
| `min` | 查看當前最小鍵值（不彈出）；空堆輸出 `-1` | O(1) |
| `dec id nk` | 把 id 的鍵值降為 nk（僅當 `nk <= 現值` 且 id 仍存活，否則忽略） | O(1) |
| `size` | 輸出當前元素個數 | O(n)（本實作） |

## 思路

結構是一組「根串列」樹 + 每節點 children 串列，`minRoot` 恆指向最小根：

- **push**：新節點直接掛進根串列，必要時更新 `minRoot` —— O(1)。
- **dec**：改鍵後若破壞堆序就 **cut**（剪下丟回根串列）；父節點失去
  第二個孩子時觸發**級聯 cut**（cascading cut，mark 標記機制）—— 攤還 O(1)。
- **popmin**：最小根的孩子全部升為根，然後 **consolidate** ——
  依 degree 合併同度數的樹（鍵小者當根），確保每個度數至多一棵樹，
  使第 k 小的樹至少有 F(k) 個節點 —— 攤還 O(log n)。

**確定性關鍵**：堆序採字典序 `(key, nid)`，父節點嚴格小於孩子。
這樣全域最小節點必為根，且鍵值平手時 popmin 彈出的節點完全確定
（取 id 最小者）——`dec` 之後某個同鍵 id 的死活才不會因平手分岔，
Python / C++ / 暴力參考實作三者才能逐位元組一致。

## 複雜度

- `push` / `min` / `dec`：攤還 **O(1)**
- `popmin`：攤還 **O(log n)**
- 空間：O(n)

## 輸入輸出示例

```
輸入：            輸出：
push 5            0      <- id 0
push 3            1      <- id 1
push 8            2      <- id 2
min               3
size              3
popmin            3
dec 2 1           （無輸出，把 id 2 的 8 降為 1）
min               1
popmin            1
popmin            5
size              0
popmin            -1
```
