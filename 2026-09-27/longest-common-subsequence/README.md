# 最长公共子序列（LCS，动态规划 + 回溯还原）

| 语言 | 文件 |
|---|---|
| Python 3 | [`solution.py`](solution.py) |
| C++17 | [`solution.cpp`](solution.cpp) |

## 题意

给定两个字符串 `a`、`b`，求它们的最长公共子序列的长度，并输出一条达到该长度的子序列。**子序列**不要求连续，只要求保持相对顺序（例如 `ace` 是 `abcde` 的子序列）。

## 思路

定义 `dp[i][j]` = `a` 的前 `i` 个字符与 `b` 的前 `j` 个字符的 LCS 长度。只看最后一对字符 `a[i-1]` 与 `b[j-1]`，只有两种情况：

| 情况 | 转移 | 含义 |
|---|---|---|
| `a[i-1] == b[j-1]` | `dp[i][j] = dp[i-1][j-1] + 1` | 这个字符一定可以接在前缀的 LCS 后面 |
| `a[i-1] != b[j-1]` | `dp[i][j] = max(dp[i-1][j], dp[i][j-1])` | 它俩不可能同时出现在同一个匹配里 |

边界 `dp[0][j] = dp[i][0] = 0`（一边为空，LCS 长度为 0）。填表按 `i`、`j` 从小到大，保证用到的状态都已经算好。

关于「字符相等就一定取」：若某个最优解没用这个字符，把该解的最后一个字符换成它依然合法且长度不变，所以存在取它的最优解，贪心地取不会丢解。

### 空间压缩与方案还原

- **只求长度**：`dp[i][*]` 只依赖 `dp[i-1][*]`，两行滚动即可（甚至一行 + 对角线变量）。
- **要还原方案**：必须保留整张表，再从 `dp[m][n]` 往回走：
  - `a[i-1] == b[j-1]`：这个字符属于 LCS，记下来，`i`、`j` 同时减一；
  - 否则往 `dp` 值大的方向走（相等时优先走 `i`，即丢弃 `a[i-1]`）。

回溯是倒着走的，所以收集到的字符最后要**反转**一次。

> LCS 通常**不唯一**（`abcbdab` 与 `bdcaba` 有多条长度为 4 的解，如 `bdab`、`bcba`），回溯只保证给出其中一条。测试因此断言「长度等于最优值」且「该串确实是两边的公共子序列」，不锁死具体是哪一条。

## 复杂度

| 版本 | 时间复杂度 | 空间复杂度 |
|---|---|---|
| `lcs_length`（两行滚动） | O(m·n) | O(min(m, n)) |
| `lcs_with_string`（完整表 + 回溯） | O(m·n) | O(m·n) |
| `lcs_brute`（记忆化递归，对照用） | O(m·n) | O(m·n) + 递归栈 |

`m, n` 为两串长度。若允许的操作是「只插入/删除」，编辑距离与 LCS 有关系：`dist = m + n - 2·LCS(a, b)`。

## 输入输出

```text
输入：               输出：
abcde                3
ace                  ace
```

- 第一行字符串 `a`，第二行字符串 `b`（可以是空行；输入只有一行时 `b` 视为空串）。
- 输出第一行：LCS 长度；第二行：一条达到该长度的公共子序列（长度为 0 时输出空行）。
- Python 与 C++ 版本的输入输出格式完全一致（同一套回溯优先级，输出逐字节相同）。
- 无 stdin 输入时，两个版本都会运行内置断言测试并输出 `all tests passed`。

## 测试覆盖

固定用例：`abcde / ace → 3`、`abcbdab / bdcaba → 4`（只断言长度与合法性）、完全相同、无公共字符、一边为空、两串皆空、`a` 是 `b` 的子序列、大小写敏感（`Abc` vs `abc` → 2）、重复字符（`aab` vs `aba` → 2）。

随机对拍：两版各自用固定种子（20260927）在字母表 `{a, b, c}` 上生成 300 组长度 0–8 的随机串，验证四件事 —— 两行滚动版 = 完整表版 = 记忆化暴力版、还原出的串长度等于最优值、该串确实是两边的公共子序列、长度落在 `[0, min(m, n)]` 区间内。另加 100 组对称性校验 `LCS(a, b) == LCS(b, a)`。
