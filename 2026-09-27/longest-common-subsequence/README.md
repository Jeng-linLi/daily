# 最長公共子序列（LCS，動態規劃 + 回溯還原）

| 語言 | 文件 |
|---|---|
| Python 3 | [`solution.py`](solution.py) |
| C++17 | [`solution.cpp`](solution.cpp) |

## 題意

給定兩個字符串 `a`、`b`，求它們的最長公共子序列的長度，並輸出一條達到該長度的子序列。**子序列**不要求連續，只要求保持相對順序（例如 `ace` 是 `abcde` 的子序列）。

## 思路

定義 `dp[i][j]` = `a` 的前 `i` 個字符與 `b` 的前 `j` 個字符的 LCS 長度。只看最後一對字符 `a[i-1]` 與 `b[j-1]`，只有兩種情況：

| 情況 | 轉移 | 含義 |
|---|---|---|
| `a[i-1] == b[j-1]` | `dp[i][j] = dp[i-1][j-1] + 1` | 這個字符一定可以接在前綴的 LCS 後面 |
| `a[i-1] != b[j-1]` | `dp[i][j] = max(dp[i-1][j], dp[i][j-1])` | 它倆不可能同時出現在同一個匹配裏 |

邊界 `dp[0][j] = dp[i][0] = 0`（一邊爲空，LCS 長度爲 0）。填表按 `i`、`j` 從小到大，保證用到的狀態都已經算好。

關於「字符相等就一定取」：若某個最優解沒用這個字符，把該解的最後一個字符換成它依然合法且長度不變，所以存在取它的最優解，貪心地取不會丟解。

### 空間壓縮與方案還原

- **只求長度**：`dp[i][*]` 只依賴 `dp[i-1][*]`，兩行滾動即可（甚至一行 + 對角線變量）。
- **要還原方案**：必須保留整張表，再從 `dp[m][n]` 往回走：
  - `a[i-1] == b[j-1]`：這個字符屬於 LCS，記下來，`i`、`j` 同時減一；
  - 否則往 `dp` 值大的方向走（相等時優先走 `i`，即丟棄 `a[i-1]`）。

回溯是倒着走的，所以收集到的字符最後要**反轉**一次。

> LCS 通常**不唯一**（`abcbdab` 與 `bdcaba` 有多條長度爲 4 的解，如 `bdab`、`bcba`），回溯只保證給出其中一條。測試因此斷言「長度等於最優值」且「該串確實是兩邊的公共子序列」，不鎖死具體是哪一條。

## 複雜度

| 版本 | 時間複雜度 | 空間複雜度 |
|---|---|---|
| `lcs_length`（兩行滾動） | O(m·n) | O(min(m, n)) |
| `lcs_with_string`（完整表 + 回溯） | O(m·n) | O(m·n) |
| `lcs_brute`（記憶化遞歸，對照用） | O(m·n) | O(m·n) + 遞歸棧 |

`m, n` 爲兩串長度。若允許的操作是「只插入/刪除」，編輯距離與 LCS 有關係：`dist = m + n - 2·LCS(a, b)`。

## 輸入輸出

```text
輸入：               輸出：
abcde                3
ace                  ace
```

- 第一行字符串 `a`，第二行字符串 `b`（可以是空行；輸入只有一行時 `b` 視爲空串）。
- 輸出第一行：LCS 長度；第二行：一條達到該長度的公共子序列（長度爲 0 時輸出空行）。
- Python 與 C++ 版本的輸入輸出格式完全一致（同一套回溯優先級，輸出逐字節相同）。
- 無 stdin 輸入時，兩個版本都會運行內置斷言測試並輸出 `all tests passed`。

## 測試覆蓋

固定用例：`abcde / ace → 3`、`abcbdab / bdcaba → 4`（只斷言長度與合法性）、完全相同、無公共字符、一邊爲空、兩串皆空、`a` 是 `b` 的子序列、大小寫敏感（`Abc` vs `abc` → 2）、重複字符（`aab` vs `aba` → 2）。

隨機對拍：兩版各自用固定種子（20260927）在字母表 `{a, b, c}` 上生成 300 組長度 0–8 的隨機串，驗證四件事 —— 兩行滾動版 = 完整表版 = 記憶化暴力版、還原出的串長度等於最優值、該串確實是兩邊的公共子序列、長度落在 `[0, min(m, n)]` 區間內。另加 100 組對稱性校驗 `LCS(a, b) == LCS(b, a)`。
