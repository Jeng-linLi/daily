# 二分查找与二分答案（lower_bound / upper_bound / 最小化最大值）

| 语言 | 文件 |
|---|---|
| Python 3 | [`solution.py`](solution.py) |
| C++17 | [`solution.cpp`](solution.cpp) |

## 题意

1. 给定**升序**数组 `a`（允许重复、允许为空），回答 `q` 次查询：对每个 `x` 输出
   - `lower_bound`：第一个 `>= x` 的下标；
   - `upper_bound`：第一个 `> x` 的下标。

   下标为 0-based 的「插入位置」，取值区间是 `[0, n]`，等于 `n` 表示不存在这样的位置。

2. 附带演示**二分答案**：把数组按原顺序切成 `k` 个非空连续段，最小化「最大段的和」（LeetCode 410 Split Array Largest Sum）。这部分在内置断言里验证，不参与 stdin IO。

## 思路

二分查找的本质是**在一个单调的判定函数上找分界点**。把候选位置想成 `[False, False, …, True, True]` 这样的一段，用**左闭右开**区间 `[lo, hi)` 维护「还没确定」的部分，每次取中点 `mid` 把区间砍一半：

| 函数 | 判定 | 比较写法 |
|---|---|---|
| `lower_bound` | `P(i) = (a[i] >= x)` | `if a[mid] < x: lo = mid+1 else: hi = mid` |
| `upper_bound` | `P(i) = (a[i] > x)` | `if a[mid] <= x: lo = mid+1 else: hi = mid` |

`mid` 永远落在 `[lo, hi)` 内，所以既不会死循环也不会越界。两个版本**只差一个比较符号**，这是最容易写错的地方。有了它们之后：

- 精确查找 = `lower_bound` 取出位置后判等，不等就是 `-1`；
- 等于 `x` 的元素个数 = `upper_bound(x) - lower_bound(x)`。

### 二分答案

判定函数换成「给定上限 `limit`，能否把数组切成不超过 `k` 段且每段和都 `<= limit`」。可行性关于 `limit` **单调**（越大越容易），所以能二分出最小的可行 `limit`：

- 下界 `max(a)`：任何一段至少要装下最大的元素；
- 上界 `sum(a)`：全部塞进一段一定可行；
- 判定用贪心：从左到右累加，一旦超过 `limit` 就在当前位置切一刀，段数超过 `k` 则不可行。「能装就装」不会让后面变差，所以贪心是对的。

> 要求数组元素非负，这样可行性对 `limit` 才是单调的。

## 复杂度

| 操作 | 时间复杂度 | 空间复杂度 |
|---|---|---|
| `lower_bound` / `upper_bound` | O(log n) | O(1) |
| `binary_search` / `count_equal` | O(log n) | O(1) |
| `can_split` 单次判定 | O(n) | O(1) |
| `min_max_split`（二分答案） | O(n log S)，`S = sum(a) - max(a)` | O(1) |
| `min_max_split_brute`（对照用 DP） | O(n²·k) | O(n·k) |

## 输入输出

```text
输入：              输出：
6                   1 4      <- x=2：第一个 >=2 在 1，第一个 >2 在 4
1 2 2 2 4 7         4 4      <- x=3：两个边界都落在下标 4
4                   0 0      <- x=0：比所有元素都小
2                   6 6      <- x=9：比所有元素都大
3
0
9
```

- 输入全部按空白分隔：`n`、数组（升序，`n = 0` 时整行省略）、`q`、`q` 个查询值。
- 输出每个查询一行 `<lower> <upper>`。
- Python 与 C++ 版本的输入输出格式完全一致，同一输入的输出逐字节相同。
- 无 stdin 输入时，两个版本都会运行内置断言测试并输出 `all tests passed`。

## 测试覆盖

固定用例：含重复元素的 `[1, 2, 2, 2, 4, 7]` 上 9 个查询点（命中重复段、落在空隙、小于最小值、大于最大值、命中唯一/最大元素）、空数组、单元素数组；二分答案的 LeetCode 410 经典用例 `[7,2,5,10,8] k=2 → 18`、`[1,2,3,4,5] k=2 → 9`、`k >= n → max(a)`、空数组。

随机对拍：

1. 300 组长度 0–12、值域 0–10 的随机升序数组（刻意制造重复），对 `x ∈ [-2, 12]` 逐一与线性扫描比对，并校验 `lower <= upper`、精确查找与计数自洽。
2. 200 组长度 0–8 的随机非负数组，对所有 `k ∈ [1, n]` 与 O(n²·k) 的 DP 暴力解比对最小值，并额外断言「最优值可行、最优值减一不可行」。
