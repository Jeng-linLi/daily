# 二分查找與二分答案（lower_bound / upper_bound / 最小化最大值）

| 語言 | 文件 |
|---|---|
| Python 3 | [`solution.py`](solution.py) |
| C++17 | [`solution.cpp`](solution.cpp) |

## 題意

1. 給定**升序**數組 `a`（允許重複、允許爲空），回答 `q` 次查詢：對每個 `x` 輸出
   - `lower_bound`：第一個 `>= x` 的下標；
   - `upper_bound`：第一個 `> x` 的下標。

   下標爲 0-based 的「插入位置」，取值區間是 `[0, n]`，等於 `n` 表示不存在這樣的位置。

2. 附帶演示**二分答案**：把數組按原順序切成 `k` 個非空連續段，最小化「最大段的和」（LeetCode 410 Split Array Largest Sum）。這部分在內置斷言裡驗證，不參與 stdin IO。

## 思路

二分查找的本質是**在一個單調的判定函數上找分界點**。把候選位置想成 `[False, False, …, True, True]` 這樣的一段，用**左閉右開**區間 `[lo, hi)` 維護「還沒確定」的部分，每次取中點 `mid` 把區間砍一半：

| 函數 | 判定 | 比較寫法 |
|---|---|---|
| `lower_bound` | `P(i) = (a[i] >= x)` | `if a[mid] < x: lo = mid+1 else: hi = mid` |
| `upper_bound` | `P(i) = (a[i] > x)` | `if a[mid] <= x: lo = mid+1 else: hi = mid` |

`mid` 永遠落在 `[lo, hi)` 內，所以既不會死循環也不會越界。兩個版本**只差一個比較符號**，這是最容易寫錯的地方。有了它們之後：

- 精確查找 = `lower_bound` 取出位置後判等，不等就是 `-1`；
- 等於 `x` 的元素個數 = `upper_bound(x) - lower_bound(x)`。

### 二分答案

判定函數換成「給定上限 `limit`，能否把數組切成不超過 `k` 段且每段和都 `<= limit`」。可行性關於 `limit` **單調**（越大越容易），所以能二分出最小的可行 `limit`：

- 下界 `max(a)`：任何一段至少要裝下最大的元素；
- 上界 `sum(a)`：全部塞進一段一定可行；
- 判定用貪心：從左到右累加，一旦超過 `limit` 就在當前位置切一刀，段數超過 `k` 則不可行。「能裝就裝」不會讓後面變差，所以貪心是對的。

> 要求數組元素非負，這樣可行性對 `limit` 才是單調的。

## 複雜度

| 操作 | 時間複雜度 | 空間複雜度 |
|---|---|---|
| `lower_bound` / `upper_bound` | O(log n) | O(1) |
| `binary_search` / `count_equal` | O(log n) | O(1) |
| `can_split` 單次判定 | O(n) | O(1) |
| `min_max_split`（二分答案） | O(n log S)，`S = sum(a) - max(a)` | O(1) |
| `min_max_split_brute`（對照用 DP） | O(n²·k) | O(n·k) |

## 輸入輸出

```text
輸入：              輸出：
6                   1 4      <- x=2：第一個 >=2 在 1，第一個 >2 在 4
1 2 2 2 4 7         4 4      <- x=3：兩個邊界都落在下標 4
4                   0 0      <- x=0：比所有元素都小
2                   6 6      <- x=9：比所有元素都大
3
0
9
```

- 輸入全部按空白分隔：`n`、數組（升序，`n = 0` 時整行省略）、`q`、`q` 個查詢值。
- 輸出每個查詢一行 `<lower> <upper>`。
- Python 與 C++ 版本的輸入輸出格式完全一致，同一輸入的輸出逐字節相同。
- 無 stdin 輸入時，兩個版本都會運行內置斷言測試並輸出 `all tests passed`。

## 測試覆蓋

固定用例：含重複元素的 `[1, 2, 2, 2, 4, 7]` 上 9 個查詢點（命中重複段、落在空隙、小於最小值、大於最大值、命中唯一/最大元素）、空數組、單元素數組；二分答案的 LeetCode 410 經典用例 `[7,2,5,10,8] k=2 → 18`、`[1,2,3,4,5] k=2 → 9`、`k >= n → max(a)`、空數組。

隨機對拍：

1. 300 組長度 0–12、值域 0–10 的隨機升序數組（刻意製造重複），對 `x ∈ [-2, 12]` 逐一與線性掃描比對，並校驗 `lower <= upper`、精確查找與計數自洽。
2. 200 組長度 0–8 的隨機非負數組，對所有 `k ∈ [1, n]` 與 O(n²·k) 的 DP 暴力解比對最小值，並額外斷言「最優值可行、最優值減一不可行」。
