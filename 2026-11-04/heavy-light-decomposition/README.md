# 重鏈剖分 Heavy-Light Decomposition（HLD）

## 題意

給定 `n` 個點的樹（根為 1 號點），每個點有點權，支援 `q` 筆操作：

| 操作 | 含義 |
|---|---|
| `1 u v x` | 把 `u` 到 `v` 路徑上**所有點**的點權加上 `x` |
| `2 u v` | 查詢 `u` 到 `v` 路徑上點權的**最大值** |
| `3 u v` | 查詢 `u` 到 `v` 路徑上點權的**和** |

## 輸入 / 輸出格式

- 第一行 `n q`；第二行 `n` 個整數（點權，1 號點到 n 號點）。
- 接下來 `n-1` 行每行兩個整數表示一條樹邊。
- 最後 `q` 行每行一筆操作；對每筆 `2 / 3` 操作各輸出一行。
- 無 stdin 時執行內建斷言（含暴力對拍），輸出 `all tests passed`。

### 示例

輸入：

```
5 4
1 3 -2 5 4
1 2
1 3
2 4
2 5
3 2 4
1 4 5 2
2 1 5
3 3 3
```

輸出：

```
8
6
-2
```

說明：`3 2 4` 求路徑 2→4 的和 = 3 + 5 = 8；`1 4 5 2` 把節點 4、5 的點權各加 2；
`2 1 5` 求路徑 1→2→5 的最大值 = max(1, 3, 6) = 6；`3 3 3` 是單點和 = -2。

## 思路

### 1. 重輕劃分

對每個點，其子節點中**子樹最大**的那個叫「重兒子」，其餘是「輕兒子」。
重邊連成的極長鏈叫「重鏈」。關鍵性質：從任意點走到根，
經過的**輕邊**不超過 O(log n) 條——每走一條輕邊，所在子樹大小至少翻倍。

### 2. DFS 序上開線段樹

對整棵樹 DFS（**重兒子優先**），給每個點標連續位置 `pos[u]`。
每條重鏈內部位置連續，於是「鏈上區間」=「線段樹上連續區間」，
樹上路徑問題落到序列問題：區間加 / 區間最大值 / 區間和。

### 3. 路徑拆解

求 `u` 到 `v` 的路徑：兩點不在同一條重鏈上時，把「鏈頭較深」的點
跳到其鏈頭的父親（這一段鏈對應線段樹上一段連續區間），
重複直到同鏈，最後處理同鏈上兩點之間的區間。
每次跳一條輕邊，總跳數 O(log n)，每段在線段樹上 O(log n)。

### 4. 對拍

內建測試用暴力：路徑用「較深點逐步上爬到 LCA」逐點收集，
直接對點權數組做加 / max / sum，與 HLD + 線段樹結果比對。

## 複雜度

| 項目 | 複雜度 |
|---|---|
| 預處理 | O(n) |
| 單次操作 | O(log² n) |
| 空間 | O(n) |

## 應用場景（Applications）

- **組織架構 / 匯報鏈**：任意兩人之間的晉升鏈上批量調整、統計
- **網路路由**：兩節點間路徑上的鏈路批量加權 / 找瓶頸（最大值）
- **版本依賴樹**：兩版本間的依賴鏈統計
- HLD 是「樹上問題轉序列問題」的通用框架，可套任何支援區間操作的線段樹
  （區間賦值、矩陣乘、Segment Tree Beats 等）
