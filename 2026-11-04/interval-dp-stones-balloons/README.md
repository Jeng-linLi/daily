# 區間 DP：合併石子與戳氣球

## 題意

兩個經典區間 DP 模型，輸入第一行為任務編號 `T`：

### 任務 1：合併石子（Stone Merge）

`n` 堆石子排成一排，每次只能合併**相鄰**兩堆，代價 = 兩堆石子數之和，
求把所有堆合成一堆的**最小總代價**。

### 任務 2：戳氣球（Burst Balloons）

`n` 個氣球排成一排，戳破第 `i` 個獲得
`nums[left-1] * nums[i] * nums[right+1]` 枚金幣
（`left` / `right` 為與 `i` 相鄰且未被戳破的氣球；越界視為 1），
求能獲得的**最大金幣數**。

## 輸入 / 輸出格式

- 第一行 `T`（1 或 2）；第二行 `n`（0 ≤ n ≤ 300）；第三行 `n` 個非負整數。
- 輸出一個整數。
- 無 stdin 時執行內建斷言（含指數級暴力對拍），輸出 `all tests passed`。

### 示例 1（合併石子）

輸入：

```
1
4
1 3 2 4
```

輸出：

```
20
```

說明：最優合併順序 `(1,3)→4`、`(4,2)→6`、`(6,4)→10`，總代價 4 + 6 + 10 = 20
（對比 `(3,2)→5` 開頭的順序為 21，可見合併順序影響代價）。

### 示例 2（戳氣球）

輸入：

```
2
4
3 1 5 8
```

輸出：

```
167
```

說明：戳 1 → `3*1*5 = 15`；戳 5 → `3*5*8 = 120`；戳 3 → `1*3*8 = 24`；
最後戳 8 → `1*8*1 = 8`；合計 15 + 120 + 24 + 8 = 167。

### 示例 3（邊界）

輸入 `1` / `1` / `7` → 輸出 `0`（一堆石子無需合併）；
輸入 `2` / `0` / 空行 → 輸出 `0`（沒有氣球可戳）。

## 思路

### 1. 合併石子：從「最後一步」倒推

設 `dp[i][j]` = 把第 `i..j` 堆合成一堆的最小代價。
最後一步一定是把「`i..k` 合成的堆」與「`k+1..j` 合成的堆」合併，
這一步的代價固定為 `sum(i..j)`（最終一堆的總石子數）：

```
dp[i][j] = min_k { dp[i][k] + dp[k+1][j] } + sum(i..j)
```

區間長度從小到大枚舉，前綴和 O(1) 求區間和。

### 2. 戳氣球：把「先戳」改成「最後戳」

直接模擬戳的順序，戳掉一個會改變左右鄰居，狀態難維護。
反向思考：定義 `dp[l][r]` = 「開區間 `(l, r)` 內的氣球全部戳破」的最大收益，
並規定**最後一個**戳破的是 `k`（`l < k < r`）：戳破 `k` 時，
區間 `(l, r)` 內其他氣球已經沒了，`k` 的左右鄰居恰好是 `l` 和 `r`
（邊界用補的虛擬氣球 1，不需真的戳破）：

```
dp[l][r] = max_k { dp[l][k] + dp[k][r] + a[l]*a[k]*a[r] }
```

這樣每個子問題的邊界固定，不依賴「外面」被戳掉的歷史。

### 3. 對拍

合併石子用「模擬所有合併順序」的指數級暴力（n ≤ 10）；
戳氣球用「枚舉戳破排列」的指數級暴力（n ≤ 8）。逐一比對。

## 複雜度

| 項目 | 複雜度 |
|---|---|
| 狀態 | O(n²) |
| 轉移 | O(n) |
| 總時間 | O(n³) |
| 空間 | O(n²) |

## 應用場景（Applications）

- **合併類成本**：文件 / 區塊合併的最小 IO 代價、資料庫歸併排序成本、
  供應鏈中相鄰倉庫合併調度
- **戳氣球型收益**：任何「刪除一個元素，收益與當前左右鄰有關」的問題
  （廣告位拆除、任務調度中的窗口收益最大化）
- 矩陣鏈乘法、多邊形三角剖分本質上同構
