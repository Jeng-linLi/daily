# 背包變體：多重背包 / 完全背包 / 最少件數（Complete & Multiple Knapsack）

| 項目 | 內容 |
|---|---|
| 目錄 | `2026-10-02/knapsack-complete-multiple` |
| 語言 | Python 3（標準庫） / C++17 |
| 考點 | 1D 背包遍歷方向、二進制拆分、方案還原 |
| 複雜度 | 完全背包 **O(n·C)**；多重背包二進制拆分 **O(n·C·log c)**（二維 DP 版 **O(n·C·c)**）；最少件數 **O(n·C)**；空間 **O(C)**（二維版 **O(n·C)**） |

## 題意

給定 `n` 種物品（重量 `w`、價值 `v`、數量上限 `c`）與背包容量 `C`，依次回答三問：

1. **多重背包**：每種最多取 `c_i` 個，容量 `C` 內的最大價值，並輸出一組達到最優的選取個數；
2. **完全背包**：每種無限取，容量 `C` 內的最大價值，並輸出一組達到最優的選取個數；
3. **湊齊容量的最少件數**：每種無限取，湊出「恰好總重 `C`」最少要幾件（`-1` 表示無解）。

## 思路

0-1 背包的 1D 寫法是容量**倒序**遍歷：這樣 `dp[cap − w]` 讀到的是上一輪（還沒放過本物品）的值，
保證每件物品只用一次。**把遍歷方向反過來，就得到完全背包**：

```text
0-1  ：for cap from C downto w    → 每件最多一次
完全 ：for cap from w upto C       → 每件可無限次（讀到的是本輪已更新的值）
```

正序時 `dp[cap − w]` 可能已經包含了本物品，於是一次掃描就等價於枚舉「取 0, 1, 2, … 個」。

**多重背包**既不能倒序（退化成 0-1，每件最多只能用 1 個）也不能正序（變成無限取）。
標準解法是**二進制拆分**：把 `c` 拆成 `1, 2, 4, …, 剩餘` 若干個「捆」，
每捆當成一個獨立的 0-1 物品（重量 `k·w`、價值 `k·v`）。
因為 `1..c` 的任意整數都能由這組 2 的冪**唯一表示**，
這些捆的 0-1 組合恰好一一對應「取 0..c 個」的所有情形，
複雜度從 O(n·C·c) 降到 O(n·C·log c)。

**最少件數**是把 `max` 換成 `min`、初值換成 `INF`、`dp[0] = 0`，容量正序即可。

### 還原選取方案

- **多重背包**用**二維 DP**：`dp[i][cap]` 表示只考慮前 `i` 種、總重不超過 `cap` 的最優值。
  從 `i = n` 往回走，對每種物品枚舉取了幾個 `t`，找第一個滿足
  `dp[i][cap] == dp[i−1][cap − t·w] + t·v` 的 `t`（取最小 `t`，保證輸出唯一）。
- **完全背包**用 1D DP 加 `par[cap]`：記錄該容量最後被哪種物品更新，再從 `cap = C` 一路往回減。

> ⚠️ `par` 回溯對 0-1 / 多重**不成立**：回走時可能重複取用同一個「捆」，導致選取個數超出數量上限。
> 它只對「物品可重複使用」的完全背包成立。

約定：重量必須 ≥ 1，`w = 0` 的物品直接忽略（否則價值無界，問題無意義）。

## 輸入格式

```
n C
w1 v1 c1
w2 v2 c2
…… （共 n 行）
```

## 輸出格式

```
第 1 行：多重背包的最大價值
第 2 行：多重背包的選取個數（n 個非負整數，空格分隔；n = 0 時輸出空行）
第 3 行：完全背包的最大價值
第 4 行：完全背包的選取個數（n 個非負整數）
第 5 行：湊出恰好總重 C 的最少件數（無解輸出 -1）
```

## 示例

輸入：

```
3 10
2 3 2
3 4 1
4 5 3
```

輸出：

```
13
1 0 2
15
5 0 0
3
```

解釋：

- 多重背包受限於數量上限（2 / 1 / 3），最優是取 1 個 `(2,3)` + 2 個 `(4,5)`：總重 10、總值 13。
- 完全背包沒有數量上限，全程取性價比最高的 `(2,3)`（1.5/單位重），5 件剛好裝滿：總值 15。
- 湊齊總重 10 的最少件數是 3：`4 + 4 + 2`（單件最重只有 4，兩件最多 8 < 10，所以 2 件不可能）。
