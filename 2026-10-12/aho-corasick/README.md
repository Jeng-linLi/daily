# Aho-Corasick 多模式串匹配

`solution.py`（Python 3，僅標準庫）／`solution.cpp`（C++17）。

KMP 的「多模式」版本：把 k 個模式串建成一棵 Trie，再對整棵樹建失配指針，
**一次掃描**就找出所有模式串的所有出現位置（允許重疊），總時間與 k 無關。

## 題意

給定文字 `text` 與 k 個模式串 `pat[0..k-1]`，輸出：

1. Trie 的狀態數（含根節點）；
2. 總命中次數；
3. 每個模式串各命中幾次（按輸入順序）；
4. 每個模式串命中的起始下標（升序，允許重疊）。

## 思路

### 為什麼不能用 KMP 跑 k 次

k 個模式串各跑一次 KMP 是 `O(k·n + Σ|pat|)`。當詞庫有上萬條（敏感詞、病毒特徵碼）時完全不可行。
Aho-Corasick 的總時間是 `O(Σ|pat| + n + 命中數)`，與 k **無關**。

### 三個部件

| 部件 | 作用 |
|---|---|
| `goto`（Trie） | 按字元走樹 |
| `fail`（失配指針） | 走不下去時跳到「當前已匹配字串的最長真後綴」對應的狀態，等價於 Trie 上的 KMP `next` |
| `out`（輸出表） | 每個狀態掛上「在此結尾」的模式串編號，並沿 fail 鏈合併 |

`fail` 用 BFS 建：根的孩子 `fail = 0`；其餘 `u = goto(v, ch)` 的 `fail[u] = goto(fail[v], ch)`。
建 `fail` 時順便 `out[v] += out[fail[v]]`——這正是「掃到 `aba` 時同時命中 `a` 與 `aba`」的關鍵。

### 完整轉移表（Trie 圖）

匹配時沿 fail 鏈往上爬的總次數是攤還 `O(n)`，但更漂亮的做法是預先算好
`go[v][c]`：

```
go[v][c] = nxt[v][c]          若該邊存在
go[v][c] = go[fail[v]][c]     否則
```

因為 `fail[v]` 的深度一定小於 `v`，按 BFS 序遞推即可。有了轉移表，
匹配就是每字元 `O(1)` 的查表，**完全沒有回退**。

### 確定性

- 狀態編號 = 插入順序；
- 輸出一律按「模式串的輸入順序」，與 Trie 結構無關；
- 命中位置升序輸出；
- 空模式串不進 Trie，視為永不命中。

## 複雜度

設 `S = Σ|pat|`、`A = 字母表大小`、`n = |text|`。

| 步驟 | 時間 | 空間 |
|---|---|---|
| 建 Trie | `O(S)` | `O(S)` |
| 建 fail | `O(S)`（攤還） | `O(S)` |
| 建轉移表 | `O(S · A)` | `O(S · A)` |
| 匹配 | `O(n + 命中數)` | — |

字母表很大（例如 Unicode 全字符集）時，把 `nxt` 換成雜湊表即可維持 `O(S)` 空間。

## 輸入輸出

輸入（stdin，全部以空白分隔）：

```
text    第 1 個 token
k       第 2 個 token（模式串個數）
pat_i   接下來最多 k 個 token
```

輸出（stdout）：

```
第 1 行     Trie 狀態數（含根）
第 2 行     總命中次數
第 3 行     各模式的命中次數（按輸入順序，空格分隔）
第 4 行起   每個模式一行：命中的起始下標（升序；無則空行）
```

### 範例 1

輸入：

```
ababa 3 aba ba a
```

輸出：

```
6
7
2 2 3
0 2
1 3
0 2 4
```

說明：`aba` 命中 0、2；`ba` 命中 1、3；`a` 命中 0、2、4（注意 `a` 與 `aba` 在位置 0、2 重疊命中）。
Trie 有 6 個狀態：根、`a`、`ab`、`aba`、`b`、`ba`。

### 範例 2

輸入：

```
aaaa 2 aa aaa
```

輸出：

```
4
5
3 2
0 1 2
0 1
```

### 範例 3（沒有模式串）

輸入：

```
abc 0
```

輸出：

```
1
0

```

## 怎麼跑

```bash
python solution.py                 # 跑內置斷言，輸出 all tests passed
echo "ababa 3 aba ba a" | python solution.py

g++ -std=c++17 -O2 -Wall solution.cpp -o solution && ./solution
```

內置測試包含：轉移表與 fail 鏈逐狀態對拍、700+ 組隨機對拍（二字元 / 三字元字母表、
模式串取自文字真實子串）、空字串、空模式串、`k = 0` 等邊界。

## 應用場景

- 社群平台敏感詞 / 違禁廣告詞過濾（一次掃描命中上萬條規則）
- 防毒軟體與 IDS（Snort）的特徵碼掃描
- DNA 序列中同時搜尋大量探針
- 編輯器多關鍵字高亮、拼寫檢查、斷詞
