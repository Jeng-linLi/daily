# 2-SAT（2-可滿足性）

`solution.py`（Python 3，僅標準庫）／`solution.cpp`（C++17）。

n 個布爾變數、m 個形如 `(a ∨ b)` 的子句，問是否存在一組取值讓全部子句成立，並構造一組解。
核心是把「邏輯」翻譯成「圖論」：子句變蘊含邊，可滿足性變成強連通分量判定。

本篇同時收錄兩個獨立的 SCC 實作（Kosaraju 迭代版 / Tarjan 迭代版）互相對拍，
以及一個真實建模範例：**每個任務兩個候選時段的排程問題**。

## 題意

文字（literal）以非零整數表示：`+(i+1)` 是 `x_i` 為真、`-(i+1)` 是 `x_i` 為假。
每個子句 `(a ∨ b)` 要求兩個文字至少一個為真。輸出：

1. `SATISFIABLE` 或 `UNSATISFIABLE`；
2. 一組滿足的取值（UNSAT 時為空行）；
3. 蘊含圖的 SCC 數量；
4. 每個點所在 SCC 的「最小點號」（正規化表示）。

## 思路

### 為什麼 2-SAT 是多項式時間，3-SAT 卻是 NP-complete

子句 `(a ∨ b)` 等價於兩個蘊含式：

```
¬a → b        （a 不成立，那 b 必須成立）
¬b → a
```

把每個文字當成圖上的一個點（2n 個），每個蘊含式當成一條有向邊，得到**蘊含圖**。
沿邊走代表「被迫成立」。

> **定理**：存在解 ⟺ 沒有任何變數與它自己的否定在同一個強連通分量裡。

若 `x` 與 `¬x` 互通，則 `x ⟹ ¬x` 且 `¬x ⟹ x`，自相矛盾；反之若沒有這種情形，一定構造得出解。

### 構造解：關鍵在「分量的拓撲序」

把蘊含圖縮成 DAG（每個 SCC 縮成一個點），取拓撲序 `rank`（邊一定從小 rank 指向大 rank），令

```
x 為真  ⟺  rank(comp(x)) > rank(comp(¬x))
```

為什麼對？反證：若子句 `(a ∨ b)` 不成立，則 a、b 皆假：

```
rank(comp(a)) ≤ rank(comp(¬a))、rank(comp(b)) ≤ rank(comp(¬b))
```

子句又給出邊 `¬a → b`、`¬b → a`，故

```
rank(comp(¬a)) ≤ rank(comp(b)) ≤ rank(comp(¬b)) ≤ rank(comp(a)) ≤ rank(comp(¬a))
```

全部相等 → 四個文字同一個 SCC → 與「矛盾已被排除」矛盾。∎

### 拓撲序的正規化（本題最關鍵的工程細節）

SCC 的**編號方式**取決於實作細節——Kosaraju 和 Tarjan 給出的編號就不一樣。
若直接拿編號做比較，Python 版與 C++ 版會算出不同的解。因此：

1. 輸出時一律用「所在分量的最小點號」這種**與編號無關**的正規形式；
2. 求拓撲序時用 priority queue，以「分量的最小點號」為鍵。

由於每個分量的最小點號唯一，整個過程與 SCC 編號完全無關，兩個語言必然一致。

### 應用：兩時段排程

每個任務有兩個候選時段（半開區間 `[a₁,b₁)` 與 `[a₂,b₂)`），必須選一個；
不同任務的時段只要重疊就違法。變數 `x_i` = 「任務 i 選第一個時段」。
對任意 `i < j` 與任意時段組合 `(Xᵢ, Yⱼ)`，若兩段重疊就加一個禁止子句：

| 重疊的組合 | 加的子句 |
|---|---|
| `Aᵢ` ∩ `Aⱼ` | `(¬xᵢ ∨ ¬xⱼ)` |
| `Aᵢ` ∩ `Bⱼ` | `(¬xᵢ ∨ xⱼ)` |
| `Bᵢ` ∩ `Aⱼ` | `(xᵢ ∨ ¬xⱼ)` |
| `Bᵢ` ∩ `Bⱼ` | `(xᵢ ∨ xⱼ)` |

`k` 個任務最多 `O(k²)` 個子句，整體仍是 `O(k²)` 多項式時間。

## 複雜度

| 項目 | 時間 | 空間 |
|---|---|---|
| Kosaraju 迭代版 | `O(V + E)` | `O(V + E)` |
| Tarjan 迭代版 | `O(V + E)` | `O(V + E)` |
| 2-SAT 判定 + 構造解 | `O(n + m)` | `O(n + m)` |
| 兩時段排程建模 | `O(k²)` 個子句 | `O(k²)` |
| 暴力枚舉對拍 | `O(2ⁿ · m)`（僅測試用） | — |

## 輸入輸出

輸入（stdin，全部以空白分隔）：

```
n           變數個數
m           子句個數
a_i b_i     接下來 m 對整數，每對一個子句
```

非法文字（0 或絕對值 > n）所在的子句直接忽略；token 不足或非數字則提前結束。

輸出（stdout）：

```
第 1 行   SATISFIABLE 或 UNSATISFIABLE
第 2 行   n 個變數的取值（0/1，空格分隔；UNSAT 時為空行）
第 3 行   蘊含圖的 SCC 數量
第 4 行   2n 個點各自所在 SCC 的最小點號（空格分隔）
```

### 範例 1（唯一解）

輸入：

```
2 3
1 2
-1 2
1 -2
```

輸出：

```
SATISFIABLE
1 1
2
0 1 0 1
```

說明：`(x₀∨x₁) ∧ (¬x₀∨x₁) ∧ (x₀∨¬x₁)` 逼出 `x₀ = x₁ = 1`。
點號 0（`x₀` 真）與 2（`x₁` 真）同一分量、1 與 3 同一分量，故正規化為 `0 1 0 1`。

### 範例 2（無解）

輸入：

```
2 4 1 2 -1 2 1 -2 -1 -2
```

輸出：

```
UNSATISFIABLE

1
0 0 0 0
```

四個子句把 `x₀、¬x₀、x₁、¬x₁` 全擠進同一個分量 → 矛盾。

### 範例 3（單位子句）

輸入：

```
1 1 1 1
```

輸出：

```
SATISFIABLE
1
2
0 1
```

## 怎麼跑

```bash
python solution.py                      # 跑內置斷言，輸出 all tests passed
echo "2 3 1 2 -1 2 1 -2" | python solution.py

g++ -std=c++17 -O2 -Wall solution.cpp -o solution && ./solution
```

內置測試包含：Kosaraju 與 Tarjan 分量正規化對拍（含 300 組隨機圖）、
與 `O(2ⁿ)` 暴力枚舉比對可滿足性、構造解回代驗證全部子句、
400 組兩時段排程對拍、空公式 / 單位子句 / 矛盾對 / 非法文字 / 截斷輸入等邊界。
