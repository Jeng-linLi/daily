# 計算幾何：凸包

`solution.py`（Python 3，僅標準庫）／`solution.cpp`（C++17）。

求出包住所有點的最小凸多邊形，並在凸包上做面積、直徑、點在內部判定。
本篇收錄三種構造法（Andrew / Jarvis / Graham）互相對拍，
**全程整數運算、不使用任何浮點**，所以 Python 與 C++ 的輸出可以逐字節一致。

## 題意

給定平面上 n 個點（可重複、可共線），求：

1. **凸包頂點**：逆時針，從字典序最小的點開始，不含共線的中間點；
2. **面積的兩倍**（整數，鞋帶公式）；
3. **直徑的平方**：凸包上最遠兩點的距離平方（旋轉卡殼，`O(h)`）；
4. **點在凸包內判定**：q 個查詢點，判斷是否在凸包內或邊界上（`O(log h)`）。

## 思路

### 全程整數運算：為什麼開根號是壞習慣

幾何題最常見的坑就是浮點誤差（`0.1 + 0.2 != 0.3`、極限共線時 `acos` 的 NaN）。
本題只做整數運算：叉積、面積的兩倍、距離的平方全是整數，
只需要「比較」而不需要開根號。

### 叉積是幾何的萬能鑰匙

```
cross(o, a, b) = (a.x - o.x)(b.y - o.y) - (a.y - o.y)(b.x - o.x)
```

| 值 | 意義 |
|---|---|
| `> 0` | b 在向量 o→a 的**左側**（逆時針） |
| `= 0` | 三點共線 |
| `< 0` | b 在右側（順時針） |

凸包、面積、點在多邊形內，全部只靠這一個判斷式。

### Andrew's Monotone Chain，`O(n log n)`

先去重再按 `(x, y)` 排序，然後分別構造：

- **下鏈** left → right：維持逆時針轉彎，遇到 `cross ≤ 0` 就彈棧；
- **上鏈** right → left：同理。

兩條鏈去掉各自的尾端接起來就是凸包。
用 `≤ 0` 而不是 `< 0`，效果是**共線的中間點會被彈掉**，只留兩個端點——這讓輸出唯一。

排序 `O(n log n)`，之後每個點最多進棧一次、出棧一次，所以整體 `O(n log n)`。

### 對拍用的另外兩種構造

| 方法 | 複雜度 | 做法 |
|---|---|---|
| **Jarvis march**（禮物包裝） | `O(n·h)` | 每步選「最順時針」的下一個點，共線時取較遠者 |
| **Graham scan** | `O(n log n)` | 以字典序最小點為極點，按極角排序後單調棧 |

Graham 的極角排序**不用 `atan2`**（浮點！），改用叉積比較 + 共線時比距離。
三種構造互相對拍，任一處寫錯都會立刻暴露。

### 旋轉卡殼求直徑，`O(h)`

對每條邊 `pᵢ → pᵢ₊₁`，最遠的頂點 `j` 會**單調前進**（凸包的對蹠點性質），
所以 `j` 全程只往前走，總共 `O(h)`。判斷「要不要再走一步」用三角形面積
（即叉積的絕對值）比較，一樣是整數。

### 點在凸包內（含邊界），`O(log h)`

凸包是凸的 → 從 `p₀` 做扇形三角剖分，`q` 只可能落在其中一個三角形裡：

1. 兩次叉積排除「楔形外」（`q` 必須在 `p₀→p₁` 左側、`p₀→p_{h-1}` 右側）；
2. 對 `p₁..p_{h-1}` **二分**找 `q` 落在哪個扇形；
3. 再一次叉積判定是否在該邊內側。

### 確定性

- 先去重再按 `(x, y)` 排序 → 輸入順序不影響結果；
- 共線中間點一律剔除 → 凸包唯一；
- 起點固定為字典序最小點，方向固定逆時針；
- 面積輸出「兩倍」、距離輸出「平方」，全程整數。

## 複雜度

| 項目 | 時間 | 空間 |
|---|---|---|
| 去重 + 排序 | `O(n log n)` | `O(n)` |
| Andrew 凸包 | `O(n log n)` | `O(n)` |
| Jarvis / Graham | `O(n·h)` / `O(n log n)`（僅對拍） | `O(n)` |
| 面積（鞋帶） | `O(h)` | — |
| 旋轉卡殼直徑 | `O(h)` | — |
| 點在凸包內 | `O(log h)` 每次 | — |

## 輸入輸出

輸入（stdin，全部以空白分隔）：

```
n           點數
x_i y_i     接下來 2n 個整數為各點座標（座標會被截斷到 ±10⁶）
q           查詢點數
x y         接下來 2q 個整數為查詢點
```

token 不足或非數字時提前結束，缺的部分視為不存在。

輸出（stdout）：

```
第 1 行   凸包頂點數 h
第 2 行   凸包頂點（"x,y" 以空格分隔；h = 0 時為空行）
第 3 行   凸包面積的兩倍（整數）
第 4 行   最遠兩點距離的平方（整數）
第 5 行   q 個查詢點的判定（1 = 在凸包內或邊上，0 = 在外部）
```

### 範例 1（正方形 + 內部點）

輸入：

```
7
0 0  10 0  10 10  0 10  5 5  5 0  0 5
0
```

輸出：

```
4
0,0 10,0 10,10 0,10
200
200

```

`(5,5)` 是內部點、`(5,0)` 與 `(0,5)` 是邊上的共線點，全部被剔除。
面積 100 → 兩倍 200；對角線距離平方 200。

### 範例 2（含查詢點）

輸入：

```
4 0 0 10 0 10 10 0 10 3 5 5 20 20 10 10
```

輸出：

```
4
0,0 10,0 10,10 0,10
200
200
1 0 1
```

`(20,20)` 在外部 → 0；`(10,10)` 是頂點（在邊界上）→ 1。

### 範例 3（全部共線）

輸入：

```
4 0 0 1 0 2 0 3 0 2 1 0 5 0
```

輸出：

```
2
0,0 3,0
0
9
1 0
```

退化成線段：面積 0、直徑平方 9。

### 範例 4（三角形）

輸入：

```
3 0 0 3 4 6 0 2 3 4 0 0
```

輸出：

```
3
0,0 6,0 3,4
24
36
1 1
```

面積 `½ · 6 · 4 = 12` → 兩倍 24；最遠邊 `(0,0)-(6,0)` → 距離平方 36。

## 怎麼跑

```bash
python solution.py                              # 跑內置斷言，輸出 all tests passed
echo "3 0 0 3 4 6 0 2 3 4 0 0" | python solution.py

g++ -std=c++17 -O2 -Wall solution.cpp -o solution && ./solution
```

內置測試包含：三種構造法互相對拍（1200+ 組隨機點集，含大量共線與重複點）、
凸包頂點必為原集合子集、嚴格凸性檢查、所有原點必在凸包內、
旋轉卡殼與 `O(h²)` 暴力對拍、`O(log h)` 判定與 `O(h)` 暴力對拍 8000 次。

## 應用場景

- 地理資訊系統（GIS）的圍欄與行政邊界繪製
- 機器人與自駕車的路徑規劃可行區域
- 碰撞檢測（凸包 + SAT 分離軸定理）
- 影像處理的輪廓提取與物體識別
- 統計學的資料範圍（ROC 曲線上凸包）、字型渲染的字形外框
