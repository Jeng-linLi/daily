# Gomory–Hu 樹（等價流樹 / Equivalent Flow Tree）

對一個 `n` 點無向帶權圖，構造一棵 `n-1` 條邊的樹（Gomory–Hu 樹），滿足：
**任意兩點 `s, t` 在原圖的最小割，等於它們在樹上路徑的最小邊權**。
因此只要做 `n-1` 次最小割就能建樹，之後任意點對最小割查詢只要在樹上走路徑取最小值。

## 應用
- **大規模點對最大流查詢**：預先 O(n·maxflow) 建樹，每次查詢降到 O(log n)。
- **網路可靠性分析**、**層次聚類**（把最小割過程表示成樹狀圖）。

## 思路
維護 `parent[i]`（i 在樹上的父節點）。對 `s = 1..n-1`：

1. 令 `t = parent[s]`，在**原圖**上求 `s` 與 `t` 之間的最小割，得到割值 `flow` 與 `s` 側的可達點集合 `side`。
2. 把所有「目前掛在 `t` 下、且落在 `side` 中」的點 `i`（`i > s`）的 `parent` 改掛到 `s`。
3. 記錄邊權 `wpar[s] = flow`。

最後得到一棵樹；查詢 `(s, t)` 時，把兩點提升到同一深度，沿途取最小邊權即為答案。
最小割子程序用 Edmonds-Karp（本題圖規模小，足夠且與 C++ 版好對拍）。

## 複雜度
- 時間：O(n · maxflow) 建樹（n-1 次最小割）；每次查詢 O(log n)。
- 空間：O(n²)（容量矩陣與樹）。

## 輸入輸出格式
```
n m q
u1 v1 w1
...
um vm wm
s1 t1
...
sq tq
```
- `n`：頂點數（0-based）；`m`：無向邊數；`q`：查詢數。
- 之後 `m` 行 `u v w`：無向邊權；再 `q` 行 `s t`：查詢 `s` 與 `t` 的最小割。
- 輸出 `q` 行：每行為該點對最小割值；`s == t` 時輸出 `0`。

### 範例輸入
```
4 5 6
0 1 2
0 2 3
1 2 1
1 3 4
2 3 5
0 1
0 3
1 2
2 3
1 3
0 2
```
### 範例輸出
```
5
5
7
8
7
5
```

## 驗證
`python solution.py`（無 stdin）與 `solution.cpp` 無輸入執行時，建樹後對所有點對與
Edmonds-Karp 逐查詢暴力最小割對拍（120 組固定 + 隨機圖），通過後輸出 `all tests passed`。
