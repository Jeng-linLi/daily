# Stoer–Wagner 全局最小割（Global Minimum Cut）

在一個**無向帶權圖**中，把頂點分成兩堆，使跨越兩堆的邊權和最小。Stoer–Wagner 演算法用
n-1 輪「最大權相鄰生長」反覆合併頂點，時間 O(n³)，是全局最小割的經典解法。

## 應用
- **網路可靠性**：把通訊網路切成兩半所需的最小頻寬，即網路最脆弱環節。
- **影像分割**：像素當頂點、相似度當邊權，最小割給出前景/背景的最佳切分。
- **VLSI / 社群劃分**：把電路或社交網路切成盡量少連線的兩塊。

## 思路
維護一個「仍未被合併的頂點」集合。每一輪：

1. 從集合中做一次最大權相鄰生長：由空集合開始，每次把「到目前已選集合的邊權和最大」的
   頂點加入，直到集合佈滿所有仍活躍頂點，得到加入順序 `v₁, v₂, …, vₖ`。
2. 最後加入的 `t = vₖ` 與倒數第二個 `s = vₖ₋₁` 之間形成一個割，其權值為 `t` 加入時的
   權和 `w[t]`。用 `w[t]` 更新全域最小割答案。
3. 把 `t` 合併進 `s`（`s` 吸收 `t` 到其它頂點的所有邊權），`t` 退出集合。

重複到只剩一個頂點。**關鍵定理**：全域最小割一定會在某一輪以 `(s, t)` 的形式被考量到，
因此 n-1 輪後即得答案。

## 複雜度
- 時間：O(n³)（每輪生長 O(n²)，共 n 輪）。
- 空間：O(n²)（鄰接矩陣）。

## 輸入輸出格式
```
n m
u1 v1 w1
...
um vm wm
```
- `n`：頂點數（0-based 編號 `0..n-1`）；`m`：無向邊數。
- 之後 `m` 行 `u v w`：頂點 `u` 與 `v` 之間權值為 `w` 的無向邊（重邊累加，自環忽略）。
- 輸出一行：最小割的權值和；圖只有 0 或 1 個頂點時輸出 `0`。

### 範例輸入
```
4 5
0 1 2
0 2 3
1 2 1
1 3 4
2 3 5
```
### 範例輸出
```
5
```
