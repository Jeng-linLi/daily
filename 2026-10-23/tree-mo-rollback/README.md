# 樹上莫隊與迴滾莫隊（Mo's algorithm on tree / rollback Mo's）

`solution.py`（Python 3 標準庫）與 `solution.cpp`（C++17）行為完全一致：
有 stdin 走 IO 模式，沒有 stdin 就跑內置斷言並輸出 `all tests passed`。

---

## 題意

給一棵 n 個點的**有根樹**（根為 1 號點），每個點帶一個整數權值。
q 個詢問，每次給 (u, v)，問 u 到 v 的**路徑上**有幾個不同的權值
（路徑含端點；u = v 時路徑就是單一個點）。

## 輸入格式

```
n q                  節點數、詢問數（0 ≤ n, q ≤ 20000）
a_1 a_2 ... a_n      權值（|a_i| ≤ 10^9）
p_2 p_3 ... p_n      點 i（2..n）的父節點（1-based；自環一律當成指向根）
u v                  q 行，每行一個詢問（1-based）
```

## 輸出格式

```
q 行，每行一個整數：路徑 u→v 上不同權值的個數
```

## 輸入輸出示例

輸入：

```
5 6
10 20 30 20 10
1 1 2 2
4 5
3 4
4 4
1 5
2 3
5 3
```

輸出：

```
2
3
1
2
3
3
```

說明（樹形：1 為根，2/3 是 1 的子節點，4/5 是 2 的子節點，權值
`[10, 20, 30, 20, 10]`）：

- (4,5)：路徑 4-2-1-3 → 權值 {20, 10} → **2**
- (3,4)：路徑 3-1-2-4 → 權值 {30, 10, 20} → **3**
- (4,4)：單點 → {20} → **1**
- (1,5)：路徑 1-2-5 → 權值 {10, 20} → **2**
- (2,3)：路徑 2-1-3 → 權值 {20, 10, 30} → **3**
- (5,3)：路徑 5-2-1-3 → 權值 {10, 20, 30} → **3**

## 思路

### 1. 把「路徑查詢」拍平成一維「區間查詢」

對樹做一次 DFS，記錄每個點的**進入時間** `tin` 與**離開時間** `tout`，
得到一條長度 2n 的歐拉序（每個點恰好出現兩次：進入、離開）。
對詢問 (u, v)（不妨設 `tin[u] < tin[v]`），路徑在歐拉序上對應：

- **u 是 v 的祖先**：一段連續區間 `[tin[u], tin[v]]`，路徑上每個點
  在區間裡恰好出現一次，其餘點出現 0 或 2 次；
- **否則**：區間 `[tin[u], tin[v]]` 裡，u 出現兩次（進+出）、
  LCA(u, v) 出現零次，其餘路徑點各一次。
  於是「區間 + 額外翻轉 u 與 LCA」就正好得到整條路徑。

翻轉用 `vis[]` 標記實現：區間裡出現兩次的點來回翻轉兩次等於沒翻，
出現一次的點留在「啟用」狀態——這正是莫隊維護「區間內點集」的標準技巧。

### 2. 迴滾莫隊（rollback Mo）

普通莫隊在區間上移動左右端點，需要「加」與「減」兩種操作；
**迴滾莫隊只保留「加」**：左端點向左移產生的修改全部記在一棵**棧**上，
回答完當前詢問後統一彈棧撤銷。適用於「刪不掉」的資料結構
（例如只支援 insert 的平衡樹、二元組統計等）。

具體結構（塊大小 `B ≈ √m`，m 為歐拉序長度）：

- 詢問按 `(l 所在塊, r)` 排序，同一塊內 r 單調遞增；
- 進入新塊時清空全部狀態，左右端點都停在**塊尾**；
- r 只增不減（只加）；l 從塊尾往左加，記棧；
- 回答完把棧彈回檢查點，l 復原到塊尾，r 保留；
- 若某詢問的 r 落在塊內（整窗在塊中），先整體回滾到空窗，
  再一次性加入 `[l, r]`，答完再回滾——這類「短詢問」代價 O(B)，
  不破壞「只加」的不變式。

本題的「加」= 翻轉一個點（維護每種權值的出現次數 `cnt` 與不同權值數 `d`），
翻轉是自逆操作，棧裡記下被翻轉的點，反序再翻一次即精確撤銷。

### 3. LCA 用倍增法

O(n log n) 預處理、O(log n) 查詢；也可以用歐拉序 + Sparse Table 做到 O(1)，
但莫隊本身是 O(√n) 級別，倍增常數小、好寫，兩語言行為也完全一致。

### 4. 兩語言一致性

- 答案與 DFS 順序無關（路徑點集是樹的固有屬性），歐拉序不同不影響輸出；
- 莫隊的排序鍵 `(l // B, r)` 兩邊一致，平手不影響答案；
- 詢問按輸入順序輸出，與處理順序解耦。

## 複雜度

| 項目 | 複雜度 |
|---|---|
| 預處理（DFS + 倍增） | O(n log n) |
| 單次詢問 | O(√n)（均攤，迴滾莫隊標準複雜度） |
| q 次詢問合計 | O((n + q) √n) |
| 空間 | O(n log n) |

## 驗證方式

- **固定用例**：上表六個詢問、單點樹、空詢問、權值全相同；
- **暴力對拍**：`bf_distinct` 用 BFS 爬樹求 LCA 再走路徑，與主演算法比對；
- **隨機對拍**：四種樹形（隨機樹 / 鏈 / 星 / 雙層）× 兩種值域
  （小值域強制重複、±10^9 大值域），共 400 組；
- **大規模壓力**：1500 點鏈狀樹 150 詢問、2000 點隨機樹 400 詢問。

## 應用場景

- 遊戲 / 社交網路：「共同好友」「幫派勢力範圍」等路徑聚合統計
- 版本控制系統：兩次 commit 之間修改過的檔案種類數（diff 統計）
- 資料庫查詢最佳化：樹形目錄下「某兩節點路徑上的標籤數」
- 離線演算法競賽經典題型：靜態樹路徑第 k 小 / 種類數 / 權值和
