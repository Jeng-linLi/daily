# 线段树（区间和 + 懒标记区间加）

| 语言 | 文件 |
|---|---|
| Python 3 | [`solution.py`](solution.py) |
| C++17 | [`solution.cpp`](solution.cpp) |

## 题意

给定数组 `a`，支持两种操作（下标 **0-based**，区间为闭区间 `[l, r]`）：

- `query(l, r)`：求 `a[l..r]` 的元素和；
- `add(l, r, v)`：把 `a[l..r]` 的每个元素都加上 `v`。

暴力做法单次 O(n)，`q` 次操作就是 O(nq)；线段树把两种操作都降到 O(log n)。

## 思路

线段树是一棵描述「区间」的二叉树：叶子存单个元素，内部节点存左右儿子区间的合并结果（此处为和）。

**区间查询**：把目标区间拆成 O(log n) 个节点——递归时若当前节点区间被目标区间**完全覆盖**，直接返回该节点的 `sum`，不必再往下走。

**区间修改 + 懒标记**：若当前节点区间被修改区间完全覆盖，只更新该节点的 `sum` 并打上懒标记 `lazy`，**不再往下递归**；等到某次查询/修改必须深入其子孙时，再通过 `pushDown` 把标记分给两个儿子并清零。

懒标记的本质是「延迟执行」：只要没人问子区间的细节，就不必真的把修改落到叶子上。这正是区间修改能做到 O(log n) 的原因。

**存储**：堆式数组实现，节点 `p` 的左儿子为 `2p`、右儿子为 `2p+1`，空间开 `4n` 即可容纳整棵树。

## 复杂度

| 操作 | 时间复杂度 | 说明 |
|---|---|---|
| 建树 | O(n) | 自底向上，每个节点访问一次 |
| `query(l, r)` | O(log n) | 拆成 O(log n) 个完全覆盖节点 |
| `add(l, r, v)` | O(log n) | 懒标记避免下推到叶子 |
| 空间 | O(n) | `sum` 与 `lazy` 各开 `4n` |

## 输入输出

```text
输入：            输出：
6 4               15      # query(1,3) = 3+5+7
1 3 5 7 9 11      45      # add(1,3,10) 后 query(1,3)
1 1 3             66      # query(0,5)
2 1 3 10
1 1 3
1 0 5
```

- 第一行 `n q`（数组长度、操作条数）；第二行 `n` 个整数为初始数组。
- 接下来 `q` 行：`1 l r` 表示查询，`2 l r v` 表示区间加 `v`。
- 每个查询操作输出一行区间和。
- Python 与 C++ 版本的输入输出格式完全一致（C++ 用 `long long` 存和，避免溢出）。
- 无 stdin 输入时，两个版本都会运行内置断言测试并输出 `all tests passed`。

## 运行

```bash
python solution.py
g++ -std=c++17 -O2 solution.cpp -o solution && ./solution
```
