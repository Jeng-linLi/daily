# 線段樹（區間和 + 懶標記區間加）

| 語言 | 文件 |
|---|---|
| Python 3 | [`solution.py`](solution.py) |
| C++17 | [`solution.cpp`](solution.cpp) |

## 題意

給定數組 `a`，支持兩種操作（下標 **0-based**，區間爲閉區間 `[l, r]`）：

- `query(l, r)`：求 `a[l..r]` 的元素和；
- `add(l, r, v)`：把 `a[l..r]` 的每個元素都加上 `v`。

暴力做法單次 O(n)，`q` 次操作就是 O(nq)；線段樹把兩種操作都降到 O(log n)。

## 思路

線段樹是一棵描述「區間」的二叉樹：葉子存單個元素，內部節點存左右兒子區間的合併結果（此處爲和）。

**區間查詢**：把目標區間拆成 O(log n) 個節點——遞歸時若當前節點區間被目標區間**完全覆蓋**，直接返回該節點的 `sum`，不必再往下走。

**區間修改 + 懶標記**：若當前節點區間被修改區間完全覆蓋，只更新該節點的 `sum` 並打上懶標記 `lazy`，**不再往下遞歸**；等到某次查詢/修改必須深入其子孫時，再通過 `pushDown` 把標記分給兩個兒子並清零。

懶標記的本質是「延遲執行」：只要沒人問子區間的細節，就不必真的把修改落到葉子上。這正是區間修改能做到 O(log n) 的原因。

**存儲**：堆式數組實現，節點 `p` 的左兒子爲 `2p`、右兒子爲 `2p+1`，空間開 `4n` 即可容納整棵樹。

## 複雜度

| 操作 | 時間複雜度 | 說明 |
|---|---|---|
| 建樹 | O(n) | 自底向上，每個節點訪問一次 |
| `query(l, r)` | O(log n) | 拆成 O(log n) 個完全覆蓋節點 |
| `add(l, r, v)` | O(log n) | 懶標記避免下推到葉子 |
| 空間 | O(n) | `sum` 與 `lazy` 各開 `4n` |

## 輸入輸出

```text
輸入：            輸出：
6 4               15      # query(1,3) = 3+5+7
1 3 5 7 9 11      45      # add(1,3,10) 後 query(1,3)
1 1 3             66      # query(0,5)
2 1 3 10
1 1 3
1 0 5
```

- 第一行 `n q`（數組長度、操作條數）；第二行 `n` 個整數爲初始數組。
- 接下來 `q` 行：`1 l r` 表示查詢，`2 l r v` 表示區間加 `v`。
- 每個查詢操作輸出一行區間和。
- Python 與 C++ 版本的輸入輸出格式完全一致（C++ 用 `long long` 存和，避免溢出）。
- 無 stdin 輸入時，兩個版本都會運行內置斷言測試並輸出 `all tests passed`。

## 運行

```bash
python solution.py
g++ -std=c++17 -O2 solution.cpp -o solution && ./solution
```
