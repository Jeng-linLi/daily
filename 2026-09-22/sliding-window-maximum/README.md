# 滑動窗口最大值（單調隊列 / Monotonic Queue）

| 語言 | 文件 |
|---|---|
| Python 3 | [`solution.py`](solution.py) |
| C++17 | [`solution.cpp`](solution.cpp) |

## 題意

給定數組 `nums`（長度 `n`）和窗口大小 `k`，窗口從左向右每次滑動一格，求**每個**窗口內的最大值，共 `n-k+1` 個結果。

例：`nums = [1,3,-1,-3,5,3,6,7]`，`k = 3` → `[3,3,5,5,6,7]`。

## 思路

樸素做法是每個窗口掃一遍取 `max`，複雜度 O(n·k)，`k` 大時直接超時。做法上真正需要的不是「每個窗口的最大值」，而是「**在窗口滑動過程中，誰能成爲最大值**」。

單調隊列把這件事降到 O(n)：隊列裏存**下標**，並保證對應的值**嚴格遞減**，於是隊首永遠是當前窗口的最大值。每來一個新元素 `nums[i]`：

1. **從隊尾彈出**所有 `<= nums[i]` 的下標 —— 它們既比新元素小、又比新元素更早出窗口，此後永無出頭之日，可以安全丟棄；
2. 把 `i` 入隊；
3. **從隊首彈出**所有已滑出窗口的下標（即 `下標 <= i-k`）；
4. 當 `i >= k-1`（窗口成型）時，`nums[q.front()]` 就是當前窗口答案。

關鍵性質：每個元素**恰好入隊一次、出隊一次**，沒有回退掃描，所以總時間是線性的，與 `k` 無關。

> 邊界值得注意：本實現用「先入隊、再按 `i-k` 清隊首」的順序，等價於先清後入，但寫起來更不容易漏掉 `k == 1` 的情況。

## 複雜度

| 指標 | 值 | 說明 |
|---|---|---|
| 時間複雜度 | O(n) | 每個元素入隊、出隊各一次 |
| 空間複雜度 | O(k) | 隊列最多保存 `k` 個下標（不含輸出） |

對比：樸素 O(n·k)；若改用堆（大根堆 + 延遲刪除）則爲 O(n log n)。

- 第一行 `n k`，第二行 `n` 個整數；輸出一行 `n-k+1` 個整數，空格分隔。
