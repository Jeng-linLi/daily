# 滑动窗口最大值（单调队列 / Monotonic Queue）

| 语言 | 文件 |
|---|---|
| Python 3 | [`solution.py`](solution.py) |
| C++17 | [`solution.cpp`](solution.cpp) |

## 题意

给定数组 `nums`（长度 `n`）和窗口大小 `k`，窗口从左向右每次滑动一格，求**每个**窗口内的最大值，共 `n-k+1` 个结果。

例：`nums = [1,3,-1,-3,5,3,6,7]`，`k = 3` → `[3,3,5,5,6,7]`。

## 思路

朴素做法是每个窗口扫一遍取 `max`，复杂度 O(n·k)，`k` 大时直接超时。做法上真正需要的不是「每个窗口的最大值」，而是「**在窗口滑动过程中，谁能成为最大值**」。

单调队列把这件事降到 O(n)：队列里存**下标**，并保证对应的值**严格递减**，于是队首永远是当前窗口的最大值。每来一个新元素 `nums[i]`：

1. **从队尾弹出**所有 `<= nums[i]` 的下标 —— 它们既比新元素小、又比新元素更早出窗口，此后永无出头之日，可以安全丢弃；
2. 把 `i` 入队；
3. **从队首弹出**所有已滑出窗口的下标（即 `下标 <= i-k`）；
4. 当 `i >= k-1`（窗口成型）时，`nums[q.front()]` 就是当前窗口答案。

关键性质：每个元素**恰好入队一次、出队一次**，没有回退扫描，所以总时间是线性的，与 `k` 无关。

> 边界值得注意：本实现用「先入队、再按 `i-k` 清队首」的顺序，等价于先清后入，但写起来更不容易漏掉 `k == 1` 的情况。

## 复杂度

| 指标 | 值 | 说明 |
|---|---|---|
| 时间复杂度 | O(n) | 每个元素入队、出队各一次 |
| 空间复杂度 | O(k) | 队列最多保存 `k` 个下标（不含输出） |

对比：朴素 O(n·k)；若改用堆（大根堆 + 延迟删除）则为 O(n log n)。

## 输入输出

```text
输入：                       输出：
8 3                          3 3 5 5 6 7
1 3 -1 -3 5 3 6 7
```

- 第一行 `n k`，第二行 `n` 个整数；输出一行 `n-k+1` 个整数，空格分隔。
- Python 与 C++ 版本的输入输出格式完全一致。
- 无 stdin 输入时，两个版本都会运行内置断言测试并输出 `all tests passed`。

## 测试覆盖

固定用例之外，两个版本都用**同一个固定随机种子**（20260922）生成 200 组随机数据，与 O(n·k) 的朴素实现逐一对拍，确保没有边界错误。C++ 侧用同样的 LCG 复刻了 Python 的随机序列，因此两版跑的是同一批用例。
