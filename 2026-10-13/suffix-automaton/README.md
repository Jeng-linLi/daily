# 後綴自動機（Suffix Automaton, SAM）

`solution.py`（Python 3，僅標準庫）／`solution.cpp`（C++17）。

給定字串 `s`，建立它的後綴自動機，再用同一個結構回答五種子串查詢：
不同子串數、子串判定、出現次數、最長公共子串、字典序第 k 小子串。

SAM 用 **O(n)** 個狀態裝下 **O(n²)** 個子串 —— 拿到它之後，幾乎所有「子串」問題都變成在
一張小圖上走路。

## 題意

輸入一個基底字串 `s`、一個查詢字串 `t`、一個整數 `k`，輸出：

| 行 | 內容 |
|---|---|
| 1 | `s` 有多少個**不同**的非空子串 |
| 2 | `t` 是否為 `s` 的子串（`1` / `0`） |
| 3 | `t` 在 `s` 中出現幾次（重疊計入） |
| 4 | `s` 與 `t` 的最長公共子串長度 |
| 5 | 最長公共子串本身 |
| 6 | 所有不同子串中，字典序第 `k` 小的那一個（`k` 越界為空行） |

## 思路

### SAM 是什麼

後綴自動機是**接受 `s` 所有子串的最小確定有限狀態自動機（DFA）**。
狀態數 ≤ `2n-1`、轉移數 ≤ `3n-4`，而且可以在線構造。

每個狀態 `v` 代表一個 **endpos 等價類**：一組在 `s` 中「結束位置集合」完全相同的子串。
狀態上只記兩個量：

- `length[v]`：該等價類中**最長**串的長度；
- `link[v]`（後綴鏈）：指向「這個最長串的最長真後綴」所在的狀態。

於是 `v` 代表的所有子串，長度恰好落在區間 `(length[link[v]], length[v]]`，
所以

```
不同子串數 = Σ_v ( length[v] - length[link[v]] )      （v ≠ 根）
```

### 在線構造：難點只有「克隆」

加入字元 `c` 時新建 `cur`（`length = length[last] + 1`），沿 `last` 的後綴鏈往上走，
把「還沒有 `c` 轉移」的狀態補上 `c → cur`。若撞上一個已有 `c` 轉移的狀態 `p`（轉到 `q`）：

- `length[p] + 1 == length[q]`：一切正常，直接 `link[cur] = q`；
- 否則 `q` 同時代表長短不一的串（短的才是 `cur` 該接的後綴），
  必須**克隆**一個只代表短串的新狀態，並把沿途指向 `q` 的 `c` 轉移改指過去。

克隆是 SAM 唯一不直覺的地方，也正是它能攤還 O(1) 的原因。

### 出現次數：後綴鏈上的計數上傳

構造時每新建一個狀態就 `cnt = 1`（一個結束位置），克隆的 `cnt = 0`。
之後按 `length` **由大到小**掃一次，把 `cnt[v]` 加到 `cnt[link[v]]` 上 ——
因為後綴鏈一定指向 `length` 更小的狀態，這樣一趟就完成拓撲累積。

`cnt[v]` 即為該等價類裡**每一個**子串的出現次數（根的 `cnt` 恰為 `|s|`）。

### 第 k 小子串：在 DAG 上數路徑

從根出發的每一條路徑唯一對應一個子串（自動機是確定的，且路徑標籤必為子串），
所以「不同子串數」=「從根出發的不同路徑數」。定義

```
dp[v] = Σ_c ( 1 + dp[ nxt[v][c] ] )
```

（選 `c` 得到一個長度 1 的串，再加上從下一個狀態繼續走的所有可能），
按 `length` 由大到小算完。找第 k 小就從根往下，對每個狀態**按字元排序**逐個試：
`k ≤ 1 + dp[u]` 就往那走（`k -= 1`），否則 `k -= 1 + dp[u]` 換下一個字元。

這本質上是前綴樹的前序走訪 —— 先輸出自己再遞迴子樹 —— 順序正是字典序。

### 為什麼要限制長度

不同子串數是 `O(n²)`，`n = 3000` 時約 `4.5×10⁶`，兩個語言都用 64 位元整數才安全，
因此本題把 `s`、`t` 都截斷到 **3000 個位元組**（兩個語言一致）。

## 複雜度

| 項目 | 時間 | 空間 |
|---|---|---|
| 在線構造 | `O(n · log α)`（α 為字元集） | `O(n)` |
| 不同子串數 | `O(狀態數)` | — |
| 子串判定 / 出現次數 | `O(\|t\|)` | — |
| 最長公共子串 | `O(\|t\|)` | — |
| 第 k 小子串 | `O(答案長度 · log α)` | — |
| 整體 | — | `O(n)`（狀態 ≤ 2n-1、轉移 ≤ 3n-4） |

## 輸入輸出

輸入（stdin，以空白分隔）：

```
s      基底字串（第 1 個 token；缺失視為空字串）
t      查詢字串（第 2 個 token；缺失視為空字串）
k      整數（第 3 個 token；非數字或缺失視為 0）
```

兩個字串都截斷到前 3000 個位元組。位元組以 latin-1 解碼，任何位元組都合法。

輸出（stdout，6 行）：見上表。

### 範例 1

輸入：

```
aba babab 4
```

輸出：

```
5
0
0
3
aba
b
```

說明：「aba」的不同子串是 `a, b, ab, ba, aba` 共 5 個；`babab` 不是它的子串；
最長公共子串是 `aba`（長度 3，出現在 `babab` 的第 1 個位置起）；
字典序排序為 `a, ab, aba, b, ba`，第 4 個是 `b`。

### 範例 2（token 缺失）

輸入：

```
abc
```

輸出：

```
6
1
3
0


```

說明：`t` 缺失視為空字串 —— 空字串恆為子串（第 2 行 `1`），出現次數定義為 `|s| = 3`，
最長公共子串長度 0（第 5 行為空行）；`k` 缺失視為 `0`，越界所以第 6 行也是空行。

### 範例 3（自己跟自己比）

輸入：

```
abc abc 1
```

輸出：

```
6
1
1
3
abc
a
```

`abc` 出現 1 次，最長公共子串就是 `abc` 本身，第 1 小子串是 `a`。

### 範例 4（重複字元）

輸入：

```
aaaa aa 3
```

輸出：

```
4
1
3
2
aa
aaa
```

`aaaa` 的不同子串只有 4 個（`a, aa, aaa, aaaa`），`aa` 出現 3 次。

## 怎麼跑

```bash
python solution.py                        # 跑內置斷言，輸出 all tests passed
echo "aba babab 4" | python solution.py

g++ -std=c++17 -O2 -Wall solution.cpp -o solution && ./solution
```

內置測試包含：500 組小字串與暴力列舉對拍（不同子串數、子串判定、出現次數、
最長公共子串、第 k 小）、60 組大字串抽樣對拍、3000 位元組的長度上限、
200 個相異位元組的全相異字串（驗證不同子串數 = `L(L+1)/2`）、
以及後綴鏈與狀態數的結構性質（狀態 ≤ 2n、後綴鏈長度嚴格遞減、根 `cnt` = `|s|`）。
「不同子串數」在程式內同時用「後綴鏈長度差」與「DAG 路徑計數」兩種算法算並互相斷言。

## 應用場景

- 生物資訊：基因序列的最長公共子串、重複片段與motif 偵測
- 抄襲與重複內容檢測：兩篇文章的最長公共片段、不同 n-gram 計數
- 搜尋引擎、IDE 的子串索引與拼寫校正候選生成
- 壓縮演算法（LZ 系列）的重複子串查找、資料去重
- 惡意程式碼特徵碼比對、日誌的模板抽取
