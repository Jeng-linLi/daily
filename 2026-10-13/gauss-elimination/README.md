# 高斯消元（GF(p) 線性方程組 + GF(2) XOR 線性基）

`solution.py`（Python 3，僅標準庫）／`solution.cpp`（C++17）。

同一套「高斯消元」思想，在兩個不同的域上各做一次：

- **GF(p)**（模質數的有限域）：解 `A·x ≡ b (mod p)`，順便得到秩、行列式、可逆性；
- **GF(2)**（異或構成的域）：建 XOR 線性基，回答「能組出的最大異或值」與「第 k 小異或值」。

## 題意

輸入 `n×m` 矩陣 `A`、右端向量 `b`、質數模數 `p`、一組非負整數 `X`、整數 `k`，輸出：

| 行 | 內容 |
|---|---|
| 1 | `A` 在模 `p` 下的秩；行列式（僅 `n == m` 時有意義，否則記 `0`） |
| 2 | 解的分類：`0` = 無解、`1` = 唯一解、`2` = 無窮多解，以及自由變數個數 |
| 3 | 一組解（無解時為空行） |
| 4 | `A` 在模 `p` 下是否可逆（`1` / `0`） |
| 5 | `X` 的線性基大小；`X` 能組出的最大異或值 |
| 6 | `X` 能組出的值之中第 `k` 小的（越界為 `-1`） |

## 思路

### 高斯消元在做什麼

線性方程組有三種基本操作不改動解集合：

1. 交換兩列（行列式變號）
2. 一列乘上非零常數
3. 一列加上另一列的倍數

高斯消元就是用它們把矩陣化成**簡化列階梯型（RREF）**：每個主元所在行只有該主元非零，
於是解可以「一眼讀出」（本題再把自由變數一律補 `0`，輸出才唯一）。

### 為什麼用模質數域 GF(p)

在實數上做消元有浮點誤差，Python 與 C++ 的輸出不可能逐位元組一致。
改到**模質數 `p`** 的有限域之後，所有運算都是精確整數：

- 除法 → 乘上乘法逆元；`p` 為質數時費馬小定理給出 `a⁻¹ ≡ a^(p-2) (mod p)`；
- 每個非零元素都可逆，所以主元搜尋只要找「非零」，不存在「`p` 是合數時無逆元」的麻煩。

這讓兩個語言的輸出**必然一致**，也讓秩、行列式、可逆性都有精確定義。
本題會把輸入的 `p` 提升到「不小於它的最小質數」，確保 `GF(p)` 真的是一個域。

### 行列式從消元過程讀出來

記列交換次數 `s` 與每個主元 `pᵢ`（**正規化之前**的值）。
三個操作對行列式的影響分別是 `×(-1)`、`×(1/pᵢ)`、`×1`，最後得到 RREF
（可逆時即單位矩陣，行列式 1），所以

```
det(A) = (-1)^s · Π pᵢ   (mod p)
```

若消元結束時秩 `< n`（方陣不滿秩），行列式為 `0`。

### 解的分類

把增廣矩陣 `[A | b]` 一起消元，比較 `rank(A)` 與 `rank([A|b])`：

- `rank(A) < rank([A|b])` → 出現「`0 = 非零`」的列 → **無解**；
- `rank(A) = m`（未知數個數）→ **唯一解**；
- 否則 → **無窮多解**，自由變數 `m - rank` 個，在 `GF(p)` 上共有 `p^(m-rank)` 組解。

### XOR 線性基 = GF(2) 上的高斯消元

把每個數字看成 63 維的 `GF(2)` 向量，異或就是加法。
`basis[i]` 是「最高位為 `i`」的基底向量；插入時從高位往下消：
`x` 的第 `i` 位是 1，若 `basis[i]` 為空就放進去，否則 `x ^= basis[i]` 繼續往下。
這跟「拿主元去消掉其他列」完全同構。

建好基底後：

- **最大異或值**：從高位貪心，`res = max(res, res ^ basis[i])`；
- **第 k 小**：先把基底**重整**（讓 `basis[i]` 的低位不再含其它基底的最高位），
  再把非零基底由小到大排成 `d`，把 `k-1` 的二進位位元當成選擇向量：`ans ^= d[i]`。
  這恰好是前綴樹的前序走訪，所以順序就是數值的大小順序。

> 注意：可組出的值有 `2^size` 個，**包含 0**，所以第 1 小永遠是 `0`。

## 複雜度

| 項目 | 時間 | 空間 |
|---|---|---|
| RREF 消元（含行列式、解） | `O(n · m · min(n,m))` | `O(n·m)` |
| 矩陣求逆（`[A | I]` 一起消） | `O(n³)` | `O(n²)` |
| 線性基插入 | `O(63)` / 個 | `O(63)` |
| 最大異或值 | `O(63)` | — |
| 第 k 小（含基底重整） | `O(63²)` | — |

本題 `n, m ≤ 40`，`p ≤ 2³¹-1`。

## 輸入輸出

輸入（stdin，全部以空白分隔）：

```
n m p
a_11 ... a_1m        n 列，每列 m 個整數
...
b_1 ... b_n          右端向量
c                   參與線性基的數字個數
x_1 ... x_c
k                   第 k 小異或值（1-indexed）
```

非數字 token 一律視為「輸入到此為止」；讀不滿的那一列 / 那一組直接丟棄。
`n, m, c ≤ 40`；`p` 會被提升到不小於輸入值的最小質數（`p < 2` 時取 `2`）；
線性基的數字先截斷到 63 位元無號。

輸出（stdout，6 行）：見上表。

### 範例 1（唯一解）

輸入：

```
2 2 7 1 2 3 4 5 11 2 3 5 3
```

（`A = [[1,2],[3,4]]`、`b = [5,11]`、`p = 7`、`X = [3,5]`、`k = 3`）

輸出：

```
2 5
1 0
1 2
1
2 6
5
```

`det = 1·4 - 2·3 = -2 ≡ 5 (mod 7)`，滿秩所以唯一解 `x = [1, 2]`：

- `1·1 + 2·2 = 5 ≡ 5 (mod 7)` = `b₀` ✓
- `3·1 + 4·2 = 11 ≡ 4 (mod 7)` = `b₁`（`11 ≡ 4`）✓

`X = [3,5]` 可組出 `{0, 3, 5, 6}`（共 `2² = 4` 個），最大 `6`，第 3 小是 `5`。

### 範例 2（無窮多解）

輸入：

```
2 2 7
1 1
2 2
1 2
2
7 3
2
```

輸出：

```
1 0
2 1
1 0
0
2 7
3
```

第二列是第一列的兩倍，且 `b` 也一致 → 秩 1、自由變數 1 個、`GF(7)` 上共 `7` 組解。
輸出的這組是「自由變數補 0」的那組：`x = [1, 0]`。
`X = [7,3]` 可組出 `{0, 3, 4, 7}`，最大 `7`，第 2 小是 `3`。

### 範例 3（無解）

輸入：

```
2 2 7 1 1 2 2 1 3 1 1 1
```

輸出：

```
1 0
0 1

0
1 1
0
```

`b = [1, 3]` 與「第二列 = 2 × 第一列」矛盾（`2·1 ≠ 3`），所以無解，第 3 行為空行。

### 範例 4（大模數、三階）

輸入：

```
3 3 1000000007 1 2 3 4 5 6 7 8 10 1 2 3 3 6 9 12 2
```

輸出：

```
3 1000000004
1 0
666666671 666666672 0
1
3 15
3
```

`det = -3 ≡ 1000000004 (mod 10⁹+7)`，解唯一；`X = [6,9,12]` 的線性基大小 3
（共 8 個可組出的值），最大 `15`，第 2 小是 `3`。

### 範例 5（退化邊界）

```
0 0 7 0 1      →   0 1 / 1 0 / （空行） / 1 / 0 0 / 0
1 2 7 0 0 5 0 1 →   0 0 / 0 2 / （空行） / 0 / 0 0 / 0
```

前者是 `0×0` 矩陣：秩 0、行列式 1（空乘積）、可逆。
後者是 `0·x₀ + 0·x₁ ≡ 5`，矛盾 → 無解。

## 怎麼跑

```bash
python solution.py                        # 跑內置斷言，輸出 all tests passed
echo "2 2 7 1 2 3 4 5 11 2 3 5 3" | python solution.py

g++ -std=c++17 -O2 -Wall solution.cpp -o solution && ./solution
```

內置測試包含：300 組小矩陣與「枚舉全部 `p^m` 組解」的暴力對拍（解的個數、
唯一解是否與字典序最小解一致、無解時確實 0 組）、150 組方陣行列式與萊布尼茲公式對拍、
120 組中矩陣（另一種主元順序算秩、解的可行性驗算、`A·A⁻¹ = I`）、
200 組線性基與「枚舉所有子集異或值」對拍（基底大小、最大值、每一個第 k 小）、
以及 `0×0` 矩陣、`0 = 5`、63 位元極值等邊界。

## 應用場景

- 電路模擬（SPICE / nodal analysis）與結構力學的線性方程組求解
- 電腦圖學的座標變換與矩陣求逆、機器學習的最小平方迴歸正規方程
- 密碼學：`GF(2)` 上的線性分析、MDS 矩陣、糾刪碼（Reed-Solomon 編碼矩陣）
- 競賽與遊戲：Nim 變體的必勝判定、圖上最大異或路徑、子集異或統計
- 資料去重與特徵壓縮：判斷一組向量的張成空間、求極大線性無關組
