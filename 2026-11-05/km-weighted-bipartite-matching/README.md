# KM 演算法：二分圖最大權完美匹配

## 題意

給定 n × n 的權值矩陣 w[i][j]（可為負），在左部與右部之間找一個**完美匹配**（每個左部點恰好配一個右部點），使匹配邊權值之和最大。

**輸入**：第一行 n；接下來 n 行、每行 n 個整數（權值矩陣）。
**輸出**：一個整數 = 最大權完美匹配的總權值。

**輸入輸出範例**：

```
輸入：              輸出：
4                   28
3 7 2 5
1 4 8 2
6 2 3 9
4 5 1 6
```

最優指派：第 1 行→第 2 列 (7)、第 2 行→第 3 列 (8)、第 3 行→第 4 列 (9)、第 4 行→第 1 列 (4)，總權值 7 + 8 + 9 + 4 = 28。程式內建 200 組隨機矩陣 × O(n·n!) 全排列暴力逐一比對確認。

## 思路

### 1. 頂標（potentials）與相等子圖

給每個左部點 i 維護頂標 u[i]、每個右部點 j 維護頂標 v[j]，始終保持**可行性不變式** u[i] + v[j] >= w[i][j]。只考慮「緊繃邊」w[i][j] == u[i] + v[j] 構成的**相等子圖**；由對偶理論，相等子圖上的完美匹配權值 = Σu + Σv = 全局最優。初始頂標取 u[i] = max_j w[i][j]、v[j] = 0（顯然可行）。

> ⚠️ 方向坑：e-maxx 模板維護的是 u[i] + v[j] **≤** w[i][j]（下界），算出來是**最小**權匹配。求最大權要用課本版初始化 u[i] = max_j w[i][j]、鬆弛量 = u + v − w ≥ 0（等價於對權值取負跑 e-maxx）。

### 2. 逐步增廣 + 頂標調整

為每個左部點 i 嘗試在相等子圖裡找增廣路：

- 找得到：直接增廣（匈牙利算法的部分）；
- 找不到：記錄每個未訪問右部點 j 的最小鬆弛量 minv[j] = min{ u[i0] + v[j] − w[i0][j] }，取全域最小 delta，把已訪問左部點的 u 減 delta、已訪問右部點的 v 加 delta。這一步保證：
  - (a) 原有緊繃邊仍然緊繃（兩端同時動，和不變）；
  - (b) 可行性不破壞：樹上行 × 非樹列的鬆弛量減 delta 後仍 ≥ 0（delta 是它們的最小值）；
  - (c) 至少一條探索過的失敗交錯邊鬆弛量歸零，相等子圖擴大。

調整後繼續找增廣路，直到成功為止。

### 3. 對拍

內建測試用「枚舉所有排列」的 O(n·n!) 暴力（n ≤ 6），覆蓋負權、全零、單點、極端不對稱矩陣與 200 組隨機矩陣，逐一比對。

## 複雜度

- 時間：每個左部點增廣一次，每次增廣最多調整 O(n) 輪頂標，每輪掃描 O(n)，總計 **O(n³)**。
- 空間：O(n²)（存矩陣）。

## 應用場景（Applications）

- **任務指派**：n 個人 / n 個任務的成本或收益矩陣，找總收益最大的指派。
- **供需配對**：倉庫與門市的一對一調撥、廣告位與投放計劃的匹配。
- 線上判題系統「Assignment Problem」的標準解法；無權版匈牙利算法 / Dinic 見本倉庫 2026-10-08。
