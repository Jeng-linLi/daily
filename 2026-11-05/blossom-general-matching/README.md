# 帶花樹 Blossom：一般圖最大匹配

## 題意

給定 n 個點、m 條邊的**無向簡單圖**（可能有奇環，不限二分圖），求**最大匹配**（Maximum Matching）：最多的兩兩不共點的邊集合。

**輸入**：

```
n m
u1 v1
...
um vm
```

**輸出**：第一行匹配數 k；第二行 n 個整數，第 i 個是點 i 的配對點（0 表示未匹配）。

**輸入輸出範例**：

```
輸入：           輸出：
3 3              1
1 2              2 1 0
2 3
3 1

輸入：           輸出：
6 7              3
1 2              2 1 4 3 6 5
2 3
3 1
4 5
5 6
6 4
3 4
```

第二個例子是兩個三角形由邊 (3,4) 相連：每個三角形各取一條匹配邊，再加上跨越兩三角形的 (3,4)，共 3 條。

## 思路

### 1. 二分圖匹配為什麼不夠

匈牙利算法靠「交錯路徑」（交替出現非匹配邊 / 匹配邊）增廣。一般圖裡交錯路徑可能經過**奇環**：奇環上的一點既可以按「內點」也可以按「外點」的規則延伸，二分圖的交替染色在奇環上失效。

### 2. 花與收縮（Edmonds 1965）

把「花（blossom）」定義為：一條從樹根出發的交錯路徑 + 一條閉合奇環的交錯邊。花的關鍵性質：**整朵花可以像一個點一樣對待**——從花上任意一點都能以正確的奇偶性延伸增廣路。

找到花時，把花上所有點收縮成一個新節點（並查集維護 `base`），繼續 BFS；找到增廣路後再「展開」花，沿 parent 回溯翻轉匹配邊。

### 3. 實作要點

- `base[i]`：i 所在花的代表點（並查集，帶路徑壓縮）。
- `p[i]`：交錯森林中 i 的父親（i 是「外點」時有意義）。
- 每輪從某個未匹配點開始 BFS：外點把所有鄰居分類——
  - 未拜訪 → 若鄰居未匹配則找到增廣路，否則鄰居的配偶入隊（內點）；
  - 已拜訪的外點且 base 不同 → 找到花，lca 後整朵收縮。
- 找到增廣路後，倒序翻轉：`match[u] = v, match[v] = u` 沿 parent 鏈。

### 4. 對拍

內建測試用「枚舉邊子集」的暴力（n ≤ 10, m ≤ 15）：子集內每個點度數 ≤ 1 即為合法匹配，取最大值比對。固定用例含三角形（奇環）、雙三角形相連、Petersen 圖（答案 5）、奇環 + 尾巴（經典 blossom 觸發形態）。隨機圖生成用「枚舉全點對 + Fisher-Yates 洗牌取前 m 條」——直接循環抽點在 LCG 低比特周期短時會湊不滿 m 條不重複邊而死循環。

## 複雜度

- 時間：每個未匹配點最多增廣一次；單次找增廣路 O(n²)～O(n³)（含花的 lca），總時間 **O(n³)**。
- 空間：O(n + m)。

## 應用場景（Applications）

- **一般配對問題**：舞伴配對、宿舍分配、導師-學生互選——這些圖天然不是二分圖（人可以互相認識），必須用 Blossom。
- **網路設計**：衛星鏈路冗餘規劃中的邊不相交配對。
- 二分圖場景（如任務指派）用匈牙利算法 / Dinic 建模即可（見本倉庫 2026-10-08）；Blossom 是「圖中存在奇環」時的通用解。

## 運行方式

- Python：`python solution.py`（stdin 為空時跑內建測試，輸出 `all tests passed`；有輸入時走 IO 模式）
- C++：`g++ -std=c++17 -O2 solution.cpp -o blossom && ./blossom`（同上）
