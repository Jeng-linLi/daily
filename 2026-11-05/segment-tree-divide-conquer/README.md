# 線段樹分治 + 可撤銷並查集：離線動態連通性

## 題意

n 個點，T 個時刻（1..T）。m 條邊，第 i 條邊 (u, v) 只在時刻區間 [l_i, r_i] 內存在。q 次詢問 (t, a, b)：問時刻 t 時 a 與 b 是否連通。

**輸入**：

```
n T m q
u1 v1 l1 r1
...
um vm lm rm
t1 a1 b1
...
tq aq bq
```

**輸出**：每個詢問一行 `yes` 或 `no`。

**輸入輸出範例**：

```
輸入：            輸出：
3 4 2 4           no
1 2 1 4           yes
2 3 3 4           yes
1 1 3             no
3 1 3
4 1 3
2 2 3
```

解釋：邊 (1,2) 全程存在；邊 (2,3) 只在時刻 3-4 存在。時刻 1 時 1 與 3 不連通；時刻 3、4 時三點連通；時刻 2 時 2 與 3 不連通。

## 思路

### 1. 為什麼不能一邊加一邊查

支持撤銷的並查集**不能路徑壓縮**（撤銷會破壞壓縮後的父親指標），只能按秩/按大小合併，單次 O(log n)。若逐時刻重算全圖連通性，總代價 O(T·m·log n)，資料一大就爆。

### 2. 線段樹分治（Offline Dynamic Connectivity）

把「時間軸」建成一顆線段樹：每條邊的存活區間 [l, r] 拆成 O(log T) 個線段樹節點掛上去。然後 DFS 整顆樹：

- **進入節點**：把掛在該節點的所有邊並入並查集，記錄撤銷棧深；
- **葉子節點**：此時並查集恰好等於該時刻的活躍邊集，回答掛在此時刻的詢問；
- **離開節點**：按棧回滾到進入前的狀態（只撤銷 merge，不真刪邊）。

這樣每條邊只被真正插入/撤銷 O(log T) 次。

### 3. 可撤銷並查集

按大小合併（size 大的當根），每次改動 `fa[小根]` 與 `size`，用棧記下被改的 (節點, 舊父親)，撤銷時還原。**絕不路徑壓縮**，find 用純路徑迭代，單次 O(log n)。

### 4. 對拍

內建測試用「逐時刻重建活躍邊集 + BFS」的暴力（n, T ≤ 8）比對 200 組隨機資料；固定用例含「邊出現又消失」「直連邊斷掉後繞路鏈接上」等形態。

## 複雜度

- 時間：**O(m log T log n + q log n)**。
- 空間：O(m log T + q)。

## 應用場景（Applications）

- **動態連通性**：社交網路中好友關係時斷時續，查詢某時刻兩人是否在同一圈子；網路鏈路按計畫時段啟停的故障影響分析。
- 同一框架換掉並查集可解「線段樹分治 + 線性基」「區間刪邊最短路」等離線問題。
- 若需要**強制在線**，得改用 LCT（Link-Cut Tree），常數和實現代價都高得多。
