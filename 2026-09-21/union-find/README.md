# 併查集（Union-Find）

維護若干不相交集合，支持「合併兩個集合」和「查詢兩個元素是否同組」。

## 思路

用森林表示集合：每棵樹的根是該集合的代表元。

- **find**：沿parent 一路向上找根
- **union**：把一棵樹的根掛到另一棵樹的根下

裸實現最壞會退化成一條鏈（O(n) 一次操作）。兩個優化必須**同時**用上：

1. **路徑壓縮**：`find` 時把路徑上所有節點直接改指向根，把樹壓扁
2. **按大小（或按秩）合併**：始終把小樹掛到大樹下，控制樹高增長

只用其一無法達到反阿克曼級別；兩者齊備後複雜度爲 `O(α(n))`，α 是反阿克曼函數，實際 ≤ 5，可視爲常數。

## 複雜度

| 操作 | 時間 | 空間 |
|---|---|---|
| find / union / connected | `O(α(n))` ≈ `O(1)` | `O(n)` |
| 建結構 | `O(n)` | `O(n)` |

## 典型應用

- 無向圖連通分量計數、Kruskal 最小生成樹
- 動態連通性問題（每次加一條邊，問兩點是否連通）
- 網格/島嶼計數類問題
