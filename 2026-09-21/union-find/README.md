# 并查集（Union-Find）

维护若干不相交集合，支持「合并两个集合」和「查询两个元素是否同组」。

## 思路

用森林表示集合：每棵树的根是该集合的代表元。

- **find**：沿parent 一路向上找根
- **union**：把一棵树的根挂到另一棵树的根下

裸实现最坏会退化成一条链（O(n) 一次操作）。两个优化必须**同时**用上：

1. **路径压缩**：`find` 时把路径上所有节点直接改指向根，把树压扁
2. **按大小（或按秩）合并**：始终把小树挂到大树下，控制树高增长

只用其一无法达到反阿克曼级别；两者齐备后复杂度为 `O(α(n))`，α 是反阿克曼函数，实际 ≤ 5，可视为常数。

## 复杂度

| 操作 | 时间 | 空间 |
|---|---|---|
| find / union / connected | `O(α(n))` ≈ `O(1)` | `O(n)` |
| 建结构 | `O(n)` | `O(n)` |

## 典型应用

- 无向图连通分量计数、Kruskal 最小生成树
- 动态连通性问题（每次加一条边，问两点是否连通）
- 网格/岛屿计数类问题
