# Dijkstra 單源最短路

求非負權圖中某起點到其餘所有點的最短距離。

## 思路

貪心 + 鬆弛。維護距離數組 `dist`，每輪從「尚未定型的點」中取出 `dist` 最小的 `u`：

- **爲什麼此時 `u` 的距離就是最終值？** 因爲邊權非負，任何經由其他未定型點 `x` 繞到 `u` 的路徑，長度都 ≥ `dist[x]` ≥ `dist[u]`，不可能更短。
- 取出 `u` 後用它的出邊**鬆弛**鄰居：`dist[v] = min(dist[v], dist[u] + w)`。

用二叉堆（優先隊列）維護「當前最小」，`dist` 變小就重新入堆。同一節點可能多次入堆，用 `visited` 跳過過期條目（惰性刪除）——比手寫「堆內減鍵」簡單得多，且不影響複雜度。

## 複雜度

| 版本 | 時間 | 空間 |
|---|---|---|
| 鄰接矩陣 + O(n) 找最小 | `O(n²)` | `O(n)` |
| **鄰接表 + 二叉堆（本實現）** | **`O((n+m) log n)`** | `O(n+m)` |
| 斐波那契堆（理論最優） | `O(n log n + m)` | `O(n+m)` |

`n` = 點數，`m` = 邊數。稀疏圖上堆實現遠優於矩陣實現。

## 注意

- **邊權必須非負**。有負權邊時貪心前提不成立，改用 Bellman-Ford（可檢測負環）或 SPFA。
- 只求單點最短路時，彈出 `target` 即可提前退出。
