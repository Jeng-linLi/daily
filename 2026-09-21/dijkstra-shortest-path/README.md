# Dijkstra 单源最短路

求非负权图中某起点到其余所有点的最短距离。

## 思路

贪心 + 松弛。维护距离数组 `dist`，每轮从「尚未定型的点」中取出 `dist` 最小的 `u`：

- **为什么此时 `u` 的距离就是最终值？** 因为边权非负，任何经由其他未定型点 `x` 绕到 `u` 的路径，长度都 ≥ `dist[x]` ≥ `dist[u]`，不可能更短。
- 取出 `u` 后用它的出边**松弛**邻居：`dist[v] = min(dist[v], dist[u] + w)`。

用二叉堆（优先队列）维护「当前最小」，`dist` 变小就重新入堆。同一节点可能多次入堆，用 `visited` 跳过过期条目（惰性删除）——比手写「堆内减键」简单得多，且不影响复杂度。

## 复杂度

| 版本 | 时间 | 空间 |
|---|---|---|
| 邻接矩阵 + O(n) 找最小 | `O(n²)` | `O(n)` |
| **邻接表 + 二叉堆（本实现）** | **`O((n+m) log n)`** | `O(n+m)` |
| 斐波那契堆（理论最优） | `O(n log n + m)` | `O(n+m)` |

`n` = 点数，`m` = 边数。稀疏图上堆实现远优于矩阵实现。

## 注意

- **边权必须非负**。有负权边时贪心前提不成立，改用 Bellman-Ford（可检测负环）或 SPFA。
- 只求单点最短路时，弹出 `target` 即可提前退出。
