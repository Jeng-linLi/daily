# 基環樹與函數圖（Functional Graph / Pseudo-Forest）

`solution.py`（Python 3 標準庫）與 `solution.cpp`（C++17）行為完全一致：
有 stdin 走 IO 模式，沒有 stdin 就跑內置斷言並輸出 `all tests passed`。

---

## 題意

輸入分兩段。

### A. 有向函數圖

`n` 個點，每個點 `i` 恰有一條出邊 `nxt[i]`（`0 ≤ nxt[i] < n`）。求：

| 量 | 說明 |
|---|---|
| 環列表 | 圖上所有環，每個環**正規化**成「從環上最小點號開始」的順序 |
| `belong[i]` | `i` 沿出邊一直走，最終進入的那個環的代表（環上最小點號） |
| `dist_to_cycle[i]` | `i` 走到環上所需步數（環上點為 0） |
| `cycle_len[i]` | `i` 最終進入的那個環的長度 |
| `jump(i, K)` | 從 `i` 出發走 `K` 步後的落點（`K` 可達 10^18） |

### B. 無向基環樹森林

`n2` 個點、`m2` 條邊，每個連通分量恰有一個環（退化成樹時環長為 0）。
對每個分量輸出 `(最小點號, 環長, 直徑)`，直徑 = 分量內任意兩點最短路徑的最大值。

---

## 輸入格式

```
n                      有向函數圖點數（0 ≤ n ≤ 60）
nxt[0] .. nxt[n-1]     n 個整數；超出 [0, n) 的值一律視為 0
K                      跳躍步數（0 ≤ K ≤ 10^18）
n2 m2                  無向圖點數與邊數（0 ≤ n2 ≤ 30，0 ≤ m2 ≤ 200）
u1 v1                  以下 m2 行（或 m2 對）邊；端點超出範圍的邊直接丟棄
...
```

全部 token 以空白分隔；遇到非整數 token 就當成「輸入到此為止」。

## 輸出格式（共 9 行）

```
1. 環的數量
2. 每個環的 "最小點號:環長"，按最小點號排序
3. belong[0..n-1]
4. dist_to_cycle[0..n-1]
5. cycle_len[0..n-1]
6. jump(0,K) .. jump(n-1,K)
7. 無向圖連通分量數
8. 每個分量的 "最小點號:環長:直徑"，按最小點號排序
9. ok 旗標：1 = 高效演算法與暴力版完全一致，0 = 不一致
```

第 9 行的暴力對照組是**獨立實作**的（模擬走 n 步找環 / 逐步模擬跳躍 /
全點對 BFS 求直徑），不是同一份程式跑兩次。

---

## 思路

### A1. 找環：三色標記，一次 O(n)

函數圖的每個連通分量形狀固定：一個環，上面掛著很多棵「指向環」的內向樹。
用 `0/1/2` 三色（未訪問 / 在當前這條鏈上 / 已處理完）：

- 從未訪問點 `s` 出發一路走，把沿途節點記進 `path` 與 `pos`（節點 → 下標）。
- 撞到**顏色 1** 的點 `v`：`path[pos[v]:]` 就是新找到的環（`v` 在當前鏈上出現兩次）。
  把環旋轉到「最小點號開頭」當正規化順序。
- 撞到**顏色 2** 的點 `v`：這條尾巴接到了別人已經算好的環上。

環上點距離為 0，尾巴上的點沿著 `path` **倒著**傳遞：

```
dist_to_cycle[u] = dist_to_cycle[nxt[u]] + 1
belong[u]        = belong[nxt[u]]
cycle_len[u]     = cycle_len[nxt[u]]
```

倒序保證「兒子先算完」，整段 O(n)。

### A2. 走 K 步：二進制跳躍（倍增）

`up[j][i]` = 從 `i` 出發走 `2^j` 步的落點，`up[0] = nxt`，`up[j][i] = up[j-1][up[j-1][i]]`。
把 `K` 拆成二進位從低位往高位跳，就能在 `O(log K)` 內回答單次查詢。

### B1. 找環：拓撲剝葉（砍掉所有度數 ≤ 1 的點）

把度數 ≤ 1 的點丟進佇列，反覆取出、從圖上刪掉、把鄰居度數減 1，
新產生度數 ≤ 1 的點再入隊。剩下**沒被刪掉的點**就是 2-core；
在基環樹裡它恰好就是那個唯一的環（純樹會被全部刪光 → 環長 0）。

剝葉同時維護樹形 DP：

- `dep[u]`：`u` 往「已被刪掉那一側」的最大深度
- `top1[u]` / `top2[u]`：`u` 各分支深度的前兩大

「完全在掛著的樹裡、且經過 `u` 的最長路徑」= `top1[u] + top2[u]`。

### B2. 基環樹直徑：破環成鏈 + 滑動窗口

設環上按順序為 `c_0..c_{L-1}`，環上點 `c_i` 掛著深度 `val[i] = dep[c_i]` 的樹。
環上兩點距離是 `min(|i-j|, L-|i-j|)`，所以還要考慮

```
max_{i<j}  val[i] + val[j] + min(j-i, L-(j-i))
```

把 `val` 複製一份接在後面，令 `d = j - i`：

- `d ≤ L/2`：式子 = `(val[j] + j) + (val[i] - i)`，對 `val[j] + j` 做窗口 `[i+1, i+L/2]` 的最大值
- `d > L/2`：式子 = `(val[j] - j) + (val[i] + i + L)`，對 `val[j] - j` 做窗口 `[i+L/2+1, i+L-1]` 的最大值

兩個窗口都是固定寬度的滑動窗口最大值 → 單調佇列 O(L)。
分量直徑 = `max(樹內直徑, 穿過環的最長路徑)`。

> 注意：環長 `L = 1`（自環）時環不提供任何距離，候答案只由樹內直徑給出；
> 純環（沒有掛樹）時 `val` 全 0，答案退化成 `⌊L/2⌋`，與環 `C_L` 的直徑一致。

## 複雜度

| 項目 | 時間 | 空間 |
|---|---|---|
| A 找環（三色標記） | O(n) | O(n) |
| A 二進制跳躍 | O(n log K) 預處理，O(log K) / 次 | O(n log K) |
| A 跳躍暴力對照 | O(n · K)，僅在 K ≤ 3000 時執行 | O(n) |
| B 剝葉 + 環上 DP | O(n + m + L)，L 為環長 | O(n + m) |
| B 暴力對照（全點對 BFS） | O(V · (V + E)) | O(V) |

## 應用場景

- **有向函數圖**：置換的循環分解、不斷套用某個映射的收斂行為、
  雜湊碰撞裡的 rho 形路徑（Pollard-Rho 因數分解的形狀本質上就是函數圖）、
  「每個人指向一個人」的關係圖（跟隨關係、委派鏈）
- **二進制跳躍**：置換的 k 次冪、自動機跑 k 步後的狀態、
  連結串列的指標跳躍、與 LCA 倍增、後綴陣列的 rank 跳躍同一套技巧
- **無向基環樹**：n 點 n 邊的圖論題（城市環狀道路 + 支線）、
  「基環樹森林直徑」這類經典題、網路拓撲裡單環骨架的直徑估計、
  帶一個迴路的水管 / 電網的最遠兩點距離

## 輸入輸出示例

輸入：

```
6
1 2 0 1 5 4
1000000000000000000
5 5
0 1
1 2
2 0
0 3
3 4
```

說明：`0→1→2→0` 是一個三元環，`3→1` 是一條尾巴；
`4→5→4` 是另一個二元環。無向部分是三角形 `0-1-2-0`，`0` 上掛著 `3-4`。

輸出：

```
2
0:3 4:2
0 0 0 0 4 4
0 0 0 1 0 0
3 3 3 3 2 2
1 2 0 1 4 5
1
0:3:3
1
```

逐行解讀：

1. 有向圖有 `2` 個環
2. 環 `0` 起長度 3（`0→1→2`）、環 `4` 起長度 2（`4→5`）
3. `belong`：`0,1,2,3` 都進入環 0，`4,5` 在環 4
4. `dist_to_cycle`：只有節點 3 需要走 1 步才進環，其餘為 0
5. `cycle_len`：前四個點所屬環長 3，後兩個為 2
6. `jump(i, 10^18)`：`0→1`、`1→2`、`2→0`、`3→1`、`4→4`、`5→5`
   （10^18 mod 3 = 1，10^18 mod 2 = 0）
7. 無向圖有 `1` 個連通分量
8. 該分量最小點號 0、環長 3、直徑 3（例如 `4→3→0→2`）
9. `1`：所有結果與暴力版一致

再一個純樹的例子（環長應為 0）：

```
0
0
4 3
0 1
1 2
2 3
```

輸出：

```
0




0
1
0:0:3
1
```

（`n = 0` 時第 3–6 行都是空行；無向部分是鏈 `0-1-2-3`，環長 0、直徑 3。）

## 驗證方式

兩個檔案都內建了：

- 固定用例（三元環 / 帶尾巴的環 / 空圖 / 單點自環 / 純 50 元環的跳躍等價於模運算）
- 環上 DP 的滑動窗口版 vs O(L²) 暴力，隨機 300 組
- 隨機對拍 400 組：隨機函數圖（n ≤ 20）+ 隨機基環樹森林（n2 ≤ 10），
  全部與暴力版逐項比對
- 2000 點長鏈只跑線性演算法（確保不會退化）

跑法：

```bash
python solution.py                 # 無 stdin → all tests passed
g++ -std=c++17 -O2 solution.cpp -o a.exe && ./a.exe
```
