# Hopcroft–Karp 二分圖最大匹配

## 題意

給定二分圖（左部 nL 點、右部 nR 點、m 條邊），求：

1. **最大匹配**：最多的邊，使得任一點最多被一條邊覆蓋。
2. **一組最大匹配方案**（輸出匹配對 `u-v`）。
3. **最小點覆蓋**：最少個點，使得每條邊至少有一個端點被選中（Kőnig 定理：其大小等於最大匹配數）。

輸入可含多筆測資直到 EOF。每筆格式：`nL nR m` 後接 m 行 `u v`（0-based）。

## 思路

Kuhn 演算法每次找一條增廣路，最壞 O(VE)。Hopcroft–Karp 的關鍵是
**一次 BFS 分層後，用 DFS 同時找出所有「極大不相交的最短增廣路集合」**：

1. `bfs()`：從所有未匹配左點出發交錯遍歷（左→未匹配邊→右→匹配邊→左），
   記錄每個左點的層距 `dist`。遇到未匹配右點即表示存在增廣路。
2. `dfs(u)`：只沿 `dist[pu] == dist[u]+1` 的層前進，找到增廣路就更新 `pairU/pairV`。
   失敗時把 `dist[u]` 設為無限大，避免後續重複搜尋。
3. 重複直到 BFS 找不到增廣路。

每輪至少增加一條增廣路，且單輪可找出多條，總複雜度 O(E·√V)。

**最小點覆蓋（Kőnig 構造）**：從所有未匹配左點出發交錯 BFS，標記可達點集合 Z，
則最小點覆蓋 = (左部 \ Z) ∪ (右部 ∩ Z)。

## 複雜度

| 項目 | 時間 | 空間 |
|---|---|---|
| 最大匹配 | O(E·√V) | O(V + E) |
| 最小點覆蓋 | O(V + E) | O(V) |

## 輸入輸出範例

輸入：
```
3 3 5
0 1
0 0
1 0
2 2
2 2
```

輸出：
```
3
0-1 1-0 2-2
3
L0 L1 L2
```

說明：點 0 連到 {0,1}、點 1 連到 {0}、點 2 連到 {2}；最大匹配數 3，
一組方案是 0-1 / 1-0 / 2-2；最小點覆蓋就是全部三個左點。

## 驗證

內建對拍：匹配數與 Kuhn O(VE) 比較，最小點覆蓋與 2^n 暴力枚舉比較，
並驗證 Kőnig 等式（覆蓋大小 == 匹配數）與覆蓋確實蓋住每條邊。
Python 與 C++ 的 stdin/stdout 逐位元組一致。

## 應用

任務指派（工人 ↔ 工作）、配對大學錄取、相異代表元系統等經典問題。
