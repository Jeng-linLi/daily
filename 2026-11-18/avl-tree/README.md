# AVL 樹（自平衡二元搜尋樹）與順序統計

## 題意

維護一個可重複插入/刪除的有序多重集合，支援：

| 操作 | 語法 | 輸出 |
|---|---|---|
| 插入 | `i x` | 插入後元素總數 |
| 刪除一個 | `e x` | 刪除後元素總數 |
| 存在性 | `f x` | `1` / `0` |
| 排名 | `r x` | 嚴格小於 x 的元素個數 |
| 第 k 小 | `k x` | 第 x 小（1-based），越界 `-1` |
| 前驅 | `p x` | 嚴格小於 x 的最大者，無則 `-1` |
| 後繼 | `s x` | 嚴格大於 x 的最小者，無則 `-1` |
| 中序 | `o` | 全部元素（含重複），空白分隔；空則 `-` |

第一行是操作數 n，之後 n 個操作。這是資料庫索引 / ordered map 的核心結構。

## 思路

AVL 樹在每個節點維護 `height` 與 `size`（子樹元素總數，含 `cnt` 重複），
在每次插入/刪除後沿回溯路徑重新計算，並檢查平衡因子 `bf = h(left) - h(right)`：

- `bf > 1`：左重。若左子樹右重（`h(ll) < h(lr)`）先對左子樹左旋，再對本節點右旋（LR）。
- `bf < -1`：右重。對稱處理（RL / RR）。

插入 / 刪除 / 旋轉後 `size` 與 `height` 一律重新拉取（`pull`），因此
`rank`（小於 x 的個數）與 `kth`（第 k 小）可沿單一路徑 O(log n) 完成。
刪除時若節點有兩個孩子，用右子樹最小節點（inorder successor）的 key 頂替，
再刪除該後繼節點。

## 複雜度

| 操作 | 時間 | 空間 |
|---|---|---|
| insert / erase / find | O(log n) | — |
| rank / kth / pred / succ | O(log n) | — |
| 中序輸出 | O(n) | O(n) |
| 整體 | — | O(n) |

## 驗證

內建測試與「排序陣列 + `bisect`」參考實作逐操作對拍，每一步檢查
BST 順序、平衡因子 `|lh-rh| ≤ 1`、`height`、`size` 不變量；另有
400 次單調插入/刪除壓力測試。Python 與 C++ 的 stdin/stdout 逐位元組一致。
