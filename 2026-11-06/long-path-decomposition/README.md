# 長鏈剖分（Long-Path Decomposition）：O(1) 求 k 級祖先

## 題意

給定一棵 `n` 個節點的有根樹（根為 0，保證父節點編號小於子節點），
支援查詢：

1. `1 u k` — `u` 的 `k` 級祖先（不存在輸出 `-1`）；
2. `2 u` — `dep[u]`（到根的邊數）；
3. `3 u` — `len[u]`（`u` 到子樹最深葉子的邊數）；
4. `4 u` — `u` 所在長鏈的鏈頂編號。

## 思路

每個節點往「子樹深度最深的兒子」（**長兒子**）延伸一條長鏈，
把整棵樹剖成若干條互不相交的鏈（鏈長合計恰為 `n`）。
對每條鏈的鏈頂 `top` 預處理兩個陣列：

- `down[top][i]`：沿鏈向下走 `i` 步的節點（`0..L`，`L` 為鏈長）；
- `up[top][j]`：`top` 的 `j` 級祖先（`j = 0..min(L, dep[top])`）。

查詢 `u` 的 `k` 級祖先，記 `d = dep[u] - dep[top[u]]`：

- `k <= d`：答案在鏈內 → `down[top[u]][d - k]`，O(1)；
- `d < k <= len[u]`：答案在鏈頂上方 → `up[top[u]][k - d]`，O(1)；
- `k > len[u]`：退化到倍增表（O(log n)）。

## 複雜度

- 時間：建圖 O(n)；`k <= len[u]` 的查詢 O(1)，其餘 O(log n)。
- 空間：O(n)（`down`/`up` 陣列總長不超過 `2n`）。

## 輸入 / 輸出格式

- 第一行 `n q`（n ≤ 2e5）；第二行 `p_1 ... p_{n-1}`（節點 `1..n-1` 的父節點，`p_i < i`）。
- 接下來 `q` 行查詢（格式如上）。
- 每行輸出一個整數。
- 無 stdin 時執行內建斷言（與沿父指標爬的暴力逐節點逐 k 對拍），輸出 `all tests passed`。

## 示例

輸入：

```
6 9
0 0 1 3 1
1 4 2
1 5 3
1 2 1
2 4
3 4
3 1
4 4
4 2
1 0 0
```

輸出：

```
1
-1
0
3
0
2
0
2
0
```

說明：樹為 `0 → {1, 2}`、`1 → {3, 5}`、`3 → 4`。
節點 4 的兩級祖先是 1；節點 5 深度只有 2，故三級祖先不存在（-1）；
`len[1] = 2`（1 → 3 → 4）；根 0 的長兒子是 1，故長鏈為 `0-1-3-4`，
節點 4 與節點 2（自成單節點鏈）的鏈頂分別為 0 與 2。
