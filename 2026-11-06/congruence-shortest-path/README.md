# 同餘最短路（Congruence Shortest Path）

## 題意

給定 `n` 個正整數 `b_1 .. b_n` 與 `q` 個查詢 `x`，對每個查詢求
**最小的 `y >= x`** 使得 `y` 可以表示成 `b_i` 的非負整係數和
（`y = a_1*b_1 + ... + a_n*b_n`，`a_i >= 0`）。
若該數永遠湊不出（例如所有 `b_i` 的 gcd 不整除任何可行值）輸出 `-1`。

## 思路

記 `m = min(b_i)`。把每個非負整數按 `mod m` 分類，建圖：

- 節點為剩餘類 `0 .. m-1`；
- 邊 `r -> (r + b_i) mod m`，邊權 `+b_i`。

從 `0` 跑 Dijkstra，`dist[r]` 即「湊得出且 `≡ r (mod m)` 的最小值」。
注意 `m` 本身是某個 `b_i`，故同餘類 `r` 內的可湊值恰為 `{dist[r] + t*m}`。

查詢 `y >= x` **不要求** `y` 與 `x` 同餘，所以答案要對全部 `m` 個剩餘類取 min：
對每個 `dist[r]` 有限的類，該類中首個 `>= x` 的可湊值為

- `dist[r]`（當 `dist[r] >= x`）；
- `dist[r] + ceil((x - dist[r]) / m) * m`（否則）。

## 複雜度

- 時間：`O(n * m * log m + q * m)`（Dijkstra 建圖 `n*m` 條邊；每個查詢掃 `m` 個類）。
- 空間：`O(m)`。

## 輸入 / 輸出格式

- 第一行 `n`（1 ≤ n ≤ 20，`m = min(b) ≤ 2000`）；第二行 `n` 個正整數。
- 第三行 `q`（q ≤ 200）；第四行 `q` 個查詢 `x`（x ≤ 1e9）。
- 輸出 `q` 行，每行一個答案。
- 無 stdin 時執行內建斷言（與完全背包式可達性暴力對拍），輸出 `all tests passed`。

## 示例

輸入：

```
3
3 5 6
5
1 4 7 12 16
```

輸出：

```
3
5
8
12
16
```

說明：`b = {3,5,6}` 可湊出的數為 0, 3, 5, 6, 8, 9, 10, 11, 12, ...。
查詢 `x = 7` 時答案為 8（7 本身湊不出，`3+5=8` 是首個 ≥ 7 的可湊值）；
`x = 12` 時 12 = 3+3+3+3 可直接湊出。
