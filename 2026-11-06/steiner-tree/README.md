# 斯坦納樹 Steiner Tree（狀壓 DP + Dijkstra）

## 題意

給定一張帶非負邊權的無向圖（`n` 點 `m` 邊）與 `k` 個「終端節點」，
求一棵連通子圖（樹），使所有終端都被連通且**總邊權和最小**。
子圖可以包含非終端的 Steiner 點，以換取更小的權重。
若終端不連通輸出 `-1`。

## 思路

把 `k` 個終端編號 `0..k-1`，定義

```
dp[mask][v] = 連通「mask 所指終端集合」、且經過頂點 v 的最小權值
```

1. **初始化**：`dp[1<<i][term[i]] = 0`（終端自身即可連通自己）。
2. **枚舉 mask**（由小到大）：
   - **子樹合併**：在頂點 `v` 把兩個互不相交的子集合併
     `dp[mask][v] = min_sub dp[sub][v] + dp[mask^sub][v]`（`sub` 為 `mask` 的真子集）；
   - **邊鬆弛**：以 `dp[mask][·]` 為初始距離跑一遍 Dijkstra，
     沿邊 `(v, u, w)` 更新 `dp[mask][u] = min(dp[mask][u], dp[mask][v] + w)`。
3. **答案** = `min_v dp[(1<<k)-1][v]`；全為無窮則不連通，回傳 `-1`。

## 複雜度

- 時間：`O(3^k · n + 2^k · m · log n)`（子集枚舉 3^k、每個 mask 一次 Dijkstra）。
- 空間：`O(2^k · n)`。

## 輸入 / 輸出格式

- 第一行 `n m k`（k ≤ 12）；接下來 `m` 行 `u v w`（0-based 無向邊）；
  最後一行 `k` 個終端頂點。
- 輸出最小總權值；不可連通輸出 `-1`。
- 無 stdin 時執行內建斷言（與枚舉邊子集 + DFS 檢查連通的指數暴力對拍），輸出 `all tests passed`。

## 示例

輸入：

```
5 6 3
0 1 2
1 2 3
2 3 1
1 3 4
0 4 10
2 4 2
0 3 4
```

輸出：

```
8
```

說明：終端為 `{0, 3, 4}`。最優子圖取邊 `0-1(2)、1-2(3)、2-3(1)、2-4(2)`，
經過中繼點 1 與 2，總權 2+3+1+2 = 8；直接用邊 `0-4(10)` 反而更貴。
