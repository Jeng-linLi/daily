# 莫比烏斯反演（Möbius Inversion）：求 gcd 恰好為 g 的數對數量

`solution.py`（Python 3 標準庫）與 `solution.cpp`（C++17）行為完全一致：
有 stdin 走 IO 模式，沒有 stdin 就跑內置斷言並輸出 `all tests passed`。

---

## 題意

給定 `n` 個正整數 `a[1..n]` 與 `q` 個查詢 `g_1..g_q`。

對每個查詢 `g`，求有多少個**無序數對** `(i, j)`（`1 ≤ i < j ≤ n`）
滿足 `gcd(a[i], a[j]) == g`。

限制：`1 ≤ n, q ≤ 100000`，`1 ≤ a[i] ≤ 100000`，`1 ≤ g ≤ 100000`。

## 輸入格式

```
n q
a_1 a_2 ... a_n
g_1 g_2 ... g_q
```

## 輸出格式

輸出 `q` 行，第 `i` 行是查詢 `g_i` 的答案。

任何結構性錯誤（`n`/`q` 越界、元素或查詢值超界、輸入缺 token、
非整數）輸出 `error`。

## 輸入輸出示例

### 示例一

輸入：

```
4 3
12 18 24 30
1 2 6
```

輸出：

```
0
0
5
```

驗算（共 `C(4,2) = 6` 對）：

| 數對 | gcd |
|---|---|
| (12, 18) | 6 |
| (12, 24) | 12 |
| (12, 30) | 6 |
| (18, 24) | 6 |
| (18, 30) | 6 |
| (24, 30) | 6 |

所以 gcd 為 `1` 的有 0 對、為 `2` 的有 0 對、為 `6` 的有 **5** 對。

### 示例二

輸入：

```
5 4
2 4 8 16 32
1 2 4 8
```

輸出：

```
0
4
3
2
```

這題所有數都是 2 的冪次，gcd 就是「較小的那個數」：

- gcd = 2：有 `(2,4) (2,8) (2,16) (2,32)` → **4**
- gcd = 4：有 `(4,8) (4,16) (4,32)` → **3**
- gcd = 8：有 `(8,16) (8,32)` → **2**

## 思路

### 1. 從容斥講起

設 `cnt[d] = 滿足 d | a[i] 的元素個數`。

則「兩個數都是 `d` 的倍數」的數對數是

```
C(cnt[d], 2) = cnt[d] * (cnt[d] - 1) / 2
```

我們要的卻是 gcd **恰好等於** `g`，而不是「`g` 是它們的公因數」。
帶權容斥的做法是：

```
答案(g) = Σ_{k≥1} μ(k) * C(cnt[g*k], 2)
```

其中 `μ` 是莫比烏斯函數：

```
μ(1) = 1
μ(n) = 0       若 n 含平方因子
μ(n) = (-1)^k  若 n 是 k 個相異質數的乘積
```

這個式子的直觀意義是「對『g 是公因數』做帶權容斥」，權重就是 `μ`。

### 2. 莫比烏斯反演定理

反演定理有兩種方向：

```
若 f(n) = Σ_{d|n} g(d)，則 g(n) = Σ_{d|n} μ(d) * f(n/d)
若 g(n) = Σ_{d|n} f(d)，則 f(n) = Σ_{d|n} μ(d) * g(n/d)
```

套到本題：

- `f(g) = #{數對 : gcd 恰好為 g}`
- `g(d) = C(cnt[d], 2) = #{數對 : d 同時整除兩數}`

因為「gcd 是 `d` 的倍數」等價於「`d` 同時整除兩數」，所以 `g(d) = C(cnt[d], 2)`，
再套第二個方向的反演就得到

```
f(g) = Σ_{d|g} μ(d) * g(g/d)
```

令 `k = g/d`，即 `f(g) = Σ_{k≥1} μ(k) * C(cnt[g*k], 2)` —— 正是上面的容斥式。

### 3. 怎麼算 `cnt[d]`

直接對每個 `d` 去數有幾個 `a[i]` 是 `d` 的倍數，`O(n · maxA)` 太慢。

用「倍數列舉（倒數篩）」：對每個 `d` 從 `1` 到 `M`，

```
cnt[d] = freq[d] + freq[2d] + freq[3d] + ...
```

其中 `freq[v] = 值 v 出現的次數`。總運算量是 `Σ_{d=1}^{M} M/d = O(M log M)`。

### 4. 預先算好所有 g 的答案

對固定 `g`，反演式裡 `k` 的範圍是 `1..M/g`，樸素是 `O(M/g)`。
若對每個查詢各算一次，總共 `O(qM/g)`，最壞 10¹⁰，太慢。

關鍵改法：**對每個 `g`（`1..最大查詢值`）都預先算好**，
總運算量變成 `Σ_{g=1}^{M} (M/g) = O(M log M)` —— 這已經夠快了。
有了 `ans[1..M]` 之後，每個查詢 **O(1)** 回應。

另外還有個剪枝：隨著 `k` 增大，`g*k` 增大，`cnt[g*k]` 單調不增，
而 `C(cnt, 2)` 在 `cnt ≤ 1` 時恆為 0，所以尾段可以直接砍掉。

### 5. 邊界處理

`cnt[d]` 可能為 `0` 或 `1`，此時 `C(cnt, 2)` = 0（沒有數對）。
雖然 `C(0,2) = 0*(-1)/2 = 0` 在整數除法下剛好也是 0，
但保險起見先判 `cnt >= 2` 再算，避免負數中間值。

莫比烏斯函數用**線性篩**求出，`O(M)`。

## 複雜度

| 項目 | 複雜度 |
|---|---|
| 線性篩求 `μ` | 時間 `O(M)` |
| 倍數列舉求 `cnt[]` | 時間 `O(M log M)` |
| 對所有 `g` 求 `ans[]` | 時間 `O(M log M)` |
| 每個查詢 | 時間 `O(1)` |
| 總計 | 時間 `O(M log M + n + q)` |
| 空間 | `O(M + n)` |

`M = max(max(a[i]), 最大查詢值) ≤ 100000`。

## 驗證方式

- **固定用例**：12 組，含單元素、空數列、全相同值、2 的冪次鏈、
  大值域邊界（`100000` / `99999`）、相鄰整數（含一組 gcd 為 2 的反例）；
- **莫比烏斯函數本身**：`μ(1..100)` 的逐點值，並驗證恆等式
  `Σ_{d|n} μ(d) = [n == 1]`；
- **隨機對拍**：200 組小值域 + 80 組大值域，
  每一個 `g` 都與「枚舉所有數對算 gcd」的 `O(n² log V)` 參考實作比對；
- **退化場景對拍**：60 組全相同值（壓 `cnt` 很大的分支）
  + 40 組同底數倍數（壓 `cnt` 分層的分支），並檢查
  `Σ_g ans[g] == C(n, 2)` 的總數守恆；
- **Python ↔ C++ 對拍**：stdin/stdout 逐位元組一致（含空輸入、
  越界值、非整數 token、缺 token 等邊界）。

> 教訓：固定用例的期望值一律**先跑一遍程式拿到真實輸出**再寫死。
> 本題第一次手算就錯了三處（`gcd(6,10)` 誤當成 1、
> `[2,4,8]` 漏了 gcd 為 4 的那一對、`[8,9,10,11]` 漏了 gcd 為 2 的那一對）。

## 應用場景（Applications）

- **數論題的批量求解**：一次反演算出所有 `g` 的答案，之後查詢 O(1)，
  是「先算後問」型題目的標準套路；
- **資訊安全**：RSA 的 `φ(n)` 計算、互質數對統計（金鑰生成前的共模檢查）；
- **生物統計**：族群中「親緣關係恰為某值」的配對數量；
- **資料清洗 / 推薦系統**：找出兩筆記錄「共同特徵恰好為某類」的配對數；
- **競賽題型**：數位反演、歐拉函數求和、`Divisor Sum` 的各種變體
  （`Σ φ(i)`、`Σ μ(i)`、`Σ d(n)` 等幾乎都能用同一套框架推出來）。
