# 二元堆與優先佇列（堆排序 / Top-K / 合併 K 個有序陣列）

| 項目 | 內容 |
|---|---|
| 主題 | 堆 · 優先佇列 |
| 語言 | Python 3（`solution.py`）/ C++17（`solution.cpp`） |
| 核心考點 | 陣列存完全二元樹、sift_up / sift_down、自底向上 heapify O(n)、Top-K 用反向堆、多路歸併 |
| 複雜度 | push / pop O(log n)，top O(1)，heapify O(n)；堆排序 O(n log n)，Top-K O(n log k)，合併 O(N log K) |

## 題意

輸入一個無序陣列 `a`（長度 `n`）、一個整數 `k`、以及 `m` 個**已排序**的陣列，輸出：

1. `a` 的堆排序結果（升序）；
2. `a` 中最小的 `k` 個元素（升序；`k <= 0` 輸出空行，`k >= n` 輸出全部）；
3. 合併 `m` 個有序陣列後的結果（升序）。

## 思路

二元堆是一棵用**陣列**存的完全二元樹：下標 `i` 的父節點是 `(i-1)//2`，
左右孩子是 `2i+1`、`2i+2`。完全二元樹的高度是 `floor(log2 n)`，所以上浮 / 下沉
最多走 `log n` 層 —— 這就是 push / pop 都是 O(log n) 的來源，而 top 是 O(1)。

堆只維護**偏序**（父節點優於兩個孩子），不維護全序。只取最大 / 最小值時，
沒有必要把整個集合排好，這是它比有序陣列便宜得多的原因。

| 操作 | 做法 |
|---|---|
| `sift_up`（上浮） | 新元素放在末尾，若比父節點更優就上移，直到恢復堆性質 |
| `sift_down`（下沉） | 彈出堆頂後把末尾元素搬到堆頂，再與「更優的那個孩子」交換 |
| `heapify`（建堆） | 從最後一個非葉節點 `(n-2)//2` 往前逐個下沉 |

> **heapify 是 O(n) 而不是 O(n log n)**：絕大多數節點深度很淺，
> 把所有節點的深度求和後級數收斂到 2n。逐個 `push` 建堆才會是 O(n log n)。

### 應用 1：堆排序

建堆後反覆彈出堆頂。用最小堆彈出的順序天然升序（額外空間 O(n)）；
原地版本則是建**最大堆**、把堆頂換到末尾再下沉，額外空間 O(1)。
堆排序**不是穩定排序**，但它是少數幾個「最壞情況也是 O(n log n) 且幾乎不佔額外空間」的排序法
（快排最壞會退化到 O(n²)）。

### 應用 2：Top-K 最小

維護一個**大小不超過 k 的最大堆**：堆頂是當前 k 個候選裏最大的那個。
來了新元素，只要它比堆頂小就擠掉堆頂。時間 O(n log k)、空間 O(k) ——
n 很大而 k 很小時遠快於排序的 O(n log n)，這正是搜尋引擎取 Top-K 結果的標準做法。

### 應用 3：合併 K 個有序陣列

把每個陣列的**當前頭元素**放進最小堆，彈出最小的那個，再把該陣列的下一個元素補進去。
時間 O(N log K)（N 爲總元素數），空間 O(K)。

### 彩蛋：雙堆維護數據流中位數

`MedianMaintainer` 用一個最大堆存較小的一半、一個最小堆存較大的一半，
並保持兩堆大小差不超過 1：插入 O(log n)，查詢中位數 O(1)。
這是「即時中位數」類題目（LeetCode 295）的標準解法。

## 複雜度

| 操作 / 應用 | 時間 | 空間 |
|---|---|---|
| `heapify` 建堆 | O(n) | O(n) |
| `push` / `pop` | O(log n) | — |
| `top` | O(1) | — |
| 堆排序 | O(n log n) | O(n)（原地版 O(1)） |
| Top-K 最小 | O(n log k) | O(k) |
| 合併 K 個有序陣列 | O(N log K) | O(K) |
| 中位數維護器 | 插入 O(log n)，查詢 O(1) | O(n) |

## 輸入輸出

輸入（空白分隔即可）：

```
n k
a1 a2 ... an            # n = 0 時這行省略
m                       # 接下來有多少個有序陣列
L1 x1 x2 ... x_L1       # 第 1 個有序陣列；重複 m 行；m = 0 時全部省略
L2 ...
```

輸出：

```
第 1 行：a 的堆排序結果（升序，空格分隔）
第 2 行：a 中最小的 k 個元素（升序）
第 3 行：合併後的結果（升序）
```

### 示例

輸入：

```
5 3
5 3 8 1 4
2
3 1 4 7
3 2 3 9
```

輸出：

```
1 3 4 5 8
1 3 4
1 2 3 4 7 9
```

解釋：`[5,3,8,1,4]` 排序後是 `[1,3,4,5,8]`，最小的 3 個是 `[1,3,4]`；
後兩個有序陣列 `[1,4,7]` 與 `[2,3,9]` 歸併後是 `[1,2,3,4,7,9]`。

## 應用場景

- **任務調度 / 定時器**：作業系統的優先佇列、`std::priority_queue`、Dijkstra 的選點步驟
  （見 [`2026-09-21/dijkstra-shortest-path`](../../2026-09-21/dijkstra-shortest-path)）；
- **外部排序與多路歸併**：大檔案放不進內存時，先分塊排序再歸併，資料庫的 sort-merge join 同理；
- **即時指標**：滑動窗口中位數 / 百分位數（P99 延遲監控）就是雙堆技巧的直接應用；
- **事件驅動模擬**：離散事件模擬裏「下一個最早發生的事件」永遠從堆頂取。
