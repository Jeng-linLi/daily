# FWT 快速沃爾什變換：XOR / OR / AND 三種位運算卷積

`solution.py`（Python 3 標準庫）與 `solution.cpp`（C++17）行為完全一致：
有 stdin 走 IO 模式，沒有 stdin 就跑內置斷言並輸出 `all tests passed`。

---

## 題意

給定整數 k（0 ≤ k ≤ 16）與兩個長度為 2^k 的序列 A、B，
以及一個運算 `op ∈ {XOR, OR, AND}`，求它們的**位運算卷積**：

```
XOR 卷積   C[t] = Σ_{i^j = t} A[i]·B[j]
OR  卷積   C[t] = Σ_{i|j = t} A[i]·B[j]
AND 卷積   C[t] = Σ_{i&j = t} A[i]·B[j]
```

所有計算對 `MOD = 998244353` 取模；輸入的負數先化歸到 `[0, MOD)`。
輸出長度 2^k 的序列 C（空格分隔）。

## 輸入格式

```
k
A_0 A_1 ... A_{2^k-1}
B_0 B_1 ... B_{2^k-1}
op
```

## 輸出格式

```
C_0 C_1 ... C_{2^k-1}
```

任何結構性錯誤（k 越界、序列長度不足、op 非法、非整數）輸出 `error`。

## 輸入輸出示例

輸入：

```
1
1 2
3 4
XOR
```

輸出：

```
11 10
```

驗算：`C[0] = A[0]B[0] + A[1]B[1] = 3 + 8 = 11`；
`C[1] = A[0]B[1] + A[1]B[0] = 4 + 6 = 10`。

同組 A、B 換 OR / AND：

```
OR  → 3 18      （i|j=0: 1·3=3；i|j=1: 1·4+2·3+2·4=18）
AND → 13 8      （i&j=0: 1·3+1·4+2·3=13；i&j=1: 2·4=8）
```

## 思路

### 1. 位運算卷積 = 布爾格上的多項式乘法

把 A、B 看成「以布爾格 {0,1}^k 為下標、以逐位元運算為乘法」的多項式。
三種運算各對應一個交換半群，卷積就是這個半群上的多項式乘法 ——
直接雙重循環是 O(4^k)。

### 2. FWT：把卷積變成逐點乘

每種位運算都有一個對應的線性變換（zeta 變換），把序列送到「下標和」的域，
卷積退化為**逐點相乘**，再逆變換回來：

| 運算 | zeta 蝶形 | 逆變換 |
|---|---|---|
| XOR | `(a, b) → (a+b, a−b)` | 同形，最後乘 2^(−k) |
| OR | `(a, b) → (a, a+b)` | `(a, b) → (a, b−a)` |
| AND | `(a, b) → (a+b, b)` | `(a, b) → (a−b, b)` |

三種變換都是「按位長度倍增」的原地蝶形，總複雜度 O(k·2^k)。

### 3. 為什麼 OR 與 AND 的 zeta 方向看起來是「反的」

OR 的 zeta 是「把低位併進高位」`(a, b) → (a, a+b)`：`s = i|j` 涵蓋所有
`i ⊆ s`。AND 則是「把高位併進低位」`(a, b) → (a+b, b)`：`s = i&j` 涵蓋
所有 `s ⊆ i`。兩者互為對偶（把 0/1 互換、下標取反即可互相轉化），
寫反是最常見的 bug，所以測試裡對兩種方向都做暴力對拍。

### 4. 模運算

`MOD = 998244353` 是質數，`2^(−k)` 用費馬小定理求逆元。
負數輸入先化歸到 `[0, MOD)`，兩種語言用同一條規則
`((v % MOD) + MOD) % MOD`。C++ 的 `%` 對負數返回負值，
因此減法統一走 `submod` 歸一化 —— 這是兩語言輸出字節級一致的關鍵細節。

## 複雜度

| 項目 | 複雜度 |
|---|---|
| 三次變換 + 逐點乘 | 時間 O(k·n)，n = 2^k |
| 暴力卷積（對拍用） | O(n²) |
| 空間 | O(n) |

## 驗證方式

- **固定用例**：k = 1 三種運算（手工驗算）、k = 0、MOD−1 邊界
  （`(−1)·(−1) = 1`）、負數輸入、全零、全相同；
- **變換往返**：隨機 30 組 × 三種運算，`inverse(transform(x)) == x`；
- **隨機對拍**：120 組（k ≤ 7）× 三種運算，與 O(n²) 暴力卷積逐項比對；
- **稀疏壓力**：20 組 k = 8 稀疏陣列（大量 0 + 少量大值）；
- **Python ↔ C++ 對拍**：145 組輸入（120 隨機 + 25 邊界：k 越界、
  序列缺長度、op 非法、大小寫不符、非整數、空輸入、純空白、
  k = 12 大規模），stdin/stdout 字節級一致。

## 應用場景

- **多項式乘法**：OR / AND 卷積是「按位受限」的多項式乘法，
  集合冪級數（set power series）的基礎運算；
- **子集計數**：統計「兩組條件的 OR/AND 恰好等於某掩碼」的方案數，
  如特徵組合、權限位彙總；
- **期望與機率**：擲骰子 / 抽卡模型中用 XOR 卷積快速求分佈的卷積
  （k 個 bit 的狀態轉移）；
- **圖論**：傳遞閉包的布爾版（OR 卷積 + 重複平方法）可加速某些
  位元矩陣運算；
- **競賽常青題**：BZOJ 4263 / CF 1119F 一類的 FWT 入門題。
