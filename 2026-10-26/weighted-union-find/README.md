# 帶權併查集：關係推斷（奇偶性 / 食物鏈）與擴展域建模

`solution.py`（Python 3 標準庫）與 `solution.cpp`（C++17）行為完全一致：
有 stdin 走 IO 模式，沒有 stdin 就跑內置斷言並輸出 `all tests passed`。

---

## 題意

n 個元素之間的關係是一個**模 d 的循環群**：

- `d = 2`：`0` = 同類，`1` = 不同類；
- `d = 3`：`0` = 同類，`1` = x 吃 y，`2` = x 被 y 吃。

關係可傳遞：已知 `rel(a,b)` 與 `rel(b,c)` 就能推出

```
rel(a,c) = (rel(a,b) + rel(b,c)) mod d
```

依序給出 m 條陳述 `(x, y, r)`，表示「`rel(x,y) = r`」。
與已知資訊矛盾的陳述稱為**假話**；假話不會被記錄，不影響後續推斷。
統計假話的數量。

限制：d ∈ {2, 3}，1 ≤ n, m ≤ 100000，1 ≤ x, y ≤ n，0 ≤ r < d。

## 輸入格式

```
d
n m
x y r        m 行，每行一條陳述
```

## 輸出格式

```
一個整數：假話的數量
```

任何結構性錯誤（d 非法、n/m 越界、token 缺失、x/y/r 越界）輸出 `error`。

## 輸入輸出示例

輸入（d = 3 的食物鏈）：

```
3
3 6
1 2 1
2 3 1
3 1 2
1 1 0
1 1 1
1 3 2
```

輸出：

```
2
```

說明：

- `1 吃 2`、`2 吃 3` 為真，由此推出 `rel(1,3) = 2`（3 吃 1）；
- `3 1 2` 聲稱 `rel(3,1) = 2` 即「1 吃 3」，與已知矛盾 → **假話**；
- `1 1 0`（1 與自己同類）為真；
- `1 1 1`（1 吃自己）違反 `rel(x,x) = 0` → **假話**；
- `1 3 2` 與已推出的 `rel(1,3) = 2` 一致 → 真。

共 2 條假話。

輸入（d = 2 的奇偶判斷）：

```
2
4 6
1 2 1
2 3 1
1 3 0
1 4 1
4 2 1
3 4 1
```

輸出：

```
1
```

說明：`1-2 異、2-3 異` 推出 `1-3 同`（第 3 條為真）；`1-4 異` 為真；
`4 2 1` 聲稱 4 與 2 不同，但由 `4-1 異、1-2 異` 應得 4 與 2 **同** → 假話；
`3 4 1`：3 與 1 同、1 與 4 異 ⟹ 3 與 4 異，為真。共 1 條假話。

## 思路

### 1. 關係的代數結構

把每個元素看成一個「種類值」`k[i] ∈ Z_d`，定義

```
rel(x, y) = (k[x] - k[y]) mod d
```

於是 `rel(a,c) = rel(a,b) + rel(b,c)` 自動成立 —— **傳遞性免費得到**。
一條陳述 `(x, y, r)` 本質上是對兩個元素的種類差給出一個約束；
矛盾 ⟺ 兩個約束給出了不同的差。

### 2. 帶權併查集（主實作）

併查集的每個節點附一個權重 `rel[x] = rel(x, parent[x])`。

- **查找**：路徑壓縮的同時把權重累加成「相對於根」：
  `rel(x, root) = rel(x, parent) + rel(parent, root)`；
- **合併**：根據要維護的 `rel(x, y) = r` 解出新邊權重
  （ry 掛到 rx 下時）`rel(ry, rx) = (rel[x] - rel[y] - r) mod d`；
- **判定**：x, y 已連通時直接比較 `(rel[x] - rel[y]) mod d` 與 r。

按大小合併 + 路徑壓縮，每次操作接近 O(α(n))。

### 3. 擴展域併查集（第二實作，測試對拍用）

另一個經典建模：把每個元素複製成 d 個「域節點」`(i, t)`，
表示「元素 i 的種類是 t」。陳述 `(x, y, r)` 等價於

```
對所有 u：union(x + u·n, y + ((u - r) mod d)·n)
```

假話判定也變得很直接 —— `rel(x,y) = t` 已知 ⟺
`find(x + t·n) == find(y)`，所以只要存在 `t ≠ r` 使得
`find(x + t·n) == find(y)`，就是假話。
`x == y` 且 `r ≠ 0` 的假話也會被正確抓到（此時 `t = 0` 就會命中）。
域節點之間永不矛盾，正是「種類唯一」的編碼。

### 4. 三套實作互相對拍

測試裡同時跑 **帶權併查集 / 擴展域併查集 / 樸素傳遞閉包**（O(n³)），
隨機數據三方結果必須一致。關係取模的邊界（C++ 負數取模、x == y、
跨合併才暴露的矛盾）極易寫錯，多一套實作就多一道保險。

## 複雜度

| 項目 | 複雜度 |
|---|---|
| 帶權併查集（主實作） | 每次操作接近 O(α(n)) |
| 擴展域併查集 | 每次操作 O(d·α(n))，此處 d ≤ 3 |
| 樸素閉包（僅測試用） | O(n³) 預處理 + O(n²) 每條陳述 |

## 驗證方式

- **固定用例**：食物鏈六條陳述（2 條假話）、奇偶六條（1 條假話）、
  奇環、`x == x` 各種情形、跨合併才暴露的矛盾、空語句；
- **三方隨機對拍**：300 組（d ∈ {2,3}、n ≤ 10、m ≤ 40），
  帶權 / 擴展域 / 樸素閉包結果必須一致；
- **大規模壓力**：3000 元素 6000 條陳述，帶權 vs 擴展域一致；
- **Python ↔ C++ 對拍**：170 組輸入（150 隨機 + 20 邊界：非法 d、
  n/m 越界、缺 token、r 越界、非整數、上限 n、全假情形），
  stdin/stdout 字節級一致。

## 應用場景

- **食物鏈推斷**（NOI2001 經典題）：根據觀察記錄判定哪些記錄是假的；
- **奇偶性 / 二分圖判定**：d = 2 就是「同色 / 異色」，離線判斷圖是否
  二分圖、找出破壞二分性的矛盾邊；
- **種類合一（unification）**：Prolog / 類型推導裡「變數相等或不等」
  的約束求解，關係群從 Z_d 推廣到更一般的置換群；
- **版本相容性**：模組 A 與 B 相容、B 與 C 不相容……傳遞推斷衝突組合；
- **密碼學份額**：Shamir 份額之間「同組 / 不同組」關係的批量校驗。
