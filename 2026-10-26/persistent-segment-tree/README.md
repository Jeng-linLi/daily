# 可持久化線段樹（主席樹）：靜態區間第 k 小 / 前驅 / 後繼

`solution.py`（Python 3 標準庫）與 `solution.cpp`（C++17）行為完全一致：
有 stdin 走 IO 模式，沒有 stdin 就跑內置斷言並輸出 `all tests passed`。

---

## 題意

給定一個**靜態陣列** `a[1..n]`，回答 m 個詢問：

| 詢問 | 含義 |
|---|---|
| `K l r k` | `a[l..r]` 中第 k 小的值（1 ≤ k ≤ r-l+1） |
| `L l r x` | `a[l..r]` 中**小於 x 的最大值**（不存在輸出 `none`） |
| `R l r x` | `a[l..r]` 中**大於 x 的最小值**（不存在輸出 `none`） |

限制：1 ≤ n, m ≤ 30000，|a_i|, |x| ≤ 10^9。陣列不會被修改。

## 輸入格式

```
n m
a_1 a_2 ... a_n
<m 行詢問，每行 4 個 token：類型 l r (k 或 x)>
```

## 輸出格式

每個詢問輸出一行：一個整數，或 `none`，或 `error`（詢問本身非法時）。

## 輸入輸出示例

輸入：

```
5 6
3 1 3 2 1
K 1 5 3
L 1 5 3
R 1 5 3
K 2 4 2
L 2 4 3
R 2 4 1
```

輸出：

```
2
2
none
2
2
2
```

說明（`a[1..5] = [3,1,3,2,1]`，排序後 `[1,1,2,3,3]`；`a[2..4]` 排序後 `[1,2,3]`）：

- `K 1 5 3`：全域第 3 小 = **2**
- `L 1 5 3`：小於 3 的最大值 = **2**
- `R 1 5 3`：大於 3 的值不存在 → **none**
- `K 2 4 2`：子區間第 2 小 = **2**
- `L 2 4 3`：小於 3 的最大值 = **2**
- `R 2 4 1`：大於 1 的最小值 = **2**

## 思路

### 1. 值域離散化 + 前綴版本（主席樹）

先把所有值離散化到值域 `1..M`。對每個前綴 `a[1..i]` 維護一棵**權值線段樹**
`T_i`：`T_i` 在離散值 p 上的計數 = 前 i 個元素中等於 p 的個數。
`T_i` 與 `T_{i-1}` 只差一次單點 +1，用**函數式（持久化）**寫法每次只新建
O(log M) 個節點、其餘與舊版本共用 —— 這就是「主席樹」。
n 個版本合計只佔 O(n log M) 個節點。

### 2. 區間查詢 = 兩個前綴版本相減

區間 `[l, r]` 的權值樹就是 `T_r` **減去** `T_{l-1}`。查第 k 小時在兩個版本上
同步下降：左子樹的計數差

```
cnt = S[left[T_r]] - S[left[T_{l-1}]]
```

即區間裡落在左半值域的元素個數。`cnt >= k` 往左走；否則往右走並把 k 換成
`k - cnt`。每次詢問 O(log M)。

### 3. 前驅 / 後驅

- 小於 x 的個數 `cnt_lt`：在值域 `[1, bisect_left(x))` 上做「版本相減」求和；
  `cnt_lt > 0` 時前驅就是第 `cnt_lt` 小。
- 大於 x 的最小值：數出 ≤ x 的個數 `cnt_le`，若 `cnt_le < r-l+1`，
  後驅就是第 `cnt_le+1` 小。

三種詢問最後都歸結到同一個 `_kth`。

### 4. 空節點 0 的技巧

節點池下標 0 當作空節點：`S[0] = L[0] = R[0] = 0`。版本 0（空前綴）直接就是
空節點，`update` 從空節點長出第一層，不需要顯式建一棵滿零樹，
節點數從 O(M) 降回 O(修改次數·log M)。

### 5. 兩語言一致性

- 值域離散化用「排序去重」，與語言無關；
- 輸出是離散值還原後的原始整數，兩種語言逐位元組一致；
- 非法詢問（l > r、k 越界、x 越界、未知類型）統一輸出 `error`，
  token 流解析規則兩邊相同（每個詢問一律消費 4 個 token）。

## 複雜度

| 項目 | 複雜度 |
|---|---|
| 建樹（n 個版本） | 時間 O(n log M)，空間 O(n log M) 個節點 |
| 單次詢問 | O(log M) |
| 空間合計 | O(n log M) |

## 驗證方式

- **固定用例**：單元素、重複值、負值、全相同、非法詢問，全部手工驗算；
- **隨機對拍**：120 組小數據（n ≤ 14）+ 1 組 800 元素 / 800 詢問，
  與「每次排序後線性掃」的樸素實作逐項比對；
- **Python ↔ C++ 對拍**：167 組輸入（150 隨機 + 17 邊界：空輸入、非法
  header、缺 token、非整數、越界、上限 n、尾部多餘 token、全空白），
  stdin/stdout 字節級一致。

## 應用場景

- **OLAP / 資料倉儲**：靜態事實表上反覆出現的「區間分位數」「區間第 k 大」
  報表，預處理一次，線上 O(log n) 回答；
- **遊戲排行榜**：靜態戰力榜上查某戰力區間的第 k 名、緊鄰的上/下一名；
- **價格系統**：靜態歷史報價序列上查「某時段內第 k 便宜/貴的成交價」；
- **可持久化陣列**：把同樣的「路徑複製」技巧用在**下標域**，即得支援歷史
  版本單點修改 / 查詢的可持久化陣列（思路直接遷移）；
- **二維推廣**：值域再套一維結構（樹套樹 / 平衡樹）即可回答子矩陣第 k 小。
