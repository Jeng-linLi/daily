# Tarjan 強連通分量（SCC 分解 / 縮點 DAG / 最少加邊數）

| 項目 | 內容 |
|---|---|
| 主題 | 有向圖強連通分量：Tarjan（一次 DFS）、Kosaraju 對拍、縮點、源/匯點統計 |
| 語言 | Python 3（標準庫）、C++17 |
| 複雜度 | 時間 `O(n + m)`（每個點進棧出棧各一次、每條邊只看一次）；空間 `O(n + m)` |

## 題意

給定一張 `n` 個點、`m` 條邊的有向圖，要求：

1. 求出所有**強連通分量**（SCC：分量內任意兩點互相可達）；
2. 輸出每個點所屬的分量編號（按分量內最小點號遞增重新編號，保證輸出唯一）；
3. 統計「縮點」後 DAG 的邊數（兩點間重複邊只算一次）；
4. 最大的強連通分量有多少個點；
5. 縮點 DAG 的源點數 / 匯點數，以及**最少再加幾條有向邊能讓整張圖強連通**。

## 思路

強連通分量把有向圖「壓縮」成一棵 DAG：**分量內互相可達，分量之間單向連通**。
這是很多圖論題的預處理步驟——縮點之後，帶環的問題往往就退化成 DAG 上的問題
（可以在 DAG 上做 DP、拓撲排序、最長路……）。

### Tarjan 算法

做一次 DFS，給每個點記兩個量：

- `dfn[v]`：第一次訪問到 `v` 的時間戳；
- `low[v]`：從 `v` 出發，沿著**樹邊**往下走、**最多再走一條回邊 / 橫叉邊**，
  能到達的節點中最小的 `dfn`。

遞迴（或本實作的迭代）過程中把訪問到的點壓進一個棧。
當某點 `v` 滿足 `low[v] == dfn[v]` 時，說明 `v` 的子樹裡沒有任何邊能連回 `v` 的**祖先**
（否則 `low[v]` 會被拉得更小），於是以 `v` 為根的子樹中「還留在棧裡」的點
剛好構成一個 SCC，把它們全部彈出。

與 Kosaraju（兩次 DFS、需要反圖）相比，Tarjan 只要一次 DFS、不需要反圖，常數更小。
本實作把 Tarjan 寫成**迭代版**（顯式棧，元素為「當前節點 + 下一條待處理邊的下標」），
避免圖退化成一條鏈時遞迴深度過深；Python 與 C++ 用同一套寫法，輸出完全一致。

### 最少加邊數

縮點 DAG 上有 `src` 個入度為 0 的點、`snk` 個出度為 0 的點時，
最少需要加 `max(src, snk)` 條邊（若只有一個分量則為 `0`）——
每加一條邊最多能把一個源點和一個匯點「接上」，所以下界是 `max(src, snk)`，
而把源點與匯點交錯配對連成一圈就能達到這個下界。

## 輸入格式

```
n m
u1 v1
u2 v2
…… （共 m 行，1 ≤ u, v ≤ n）
```

所有數字按空白分隔即可；越界的邊會被忽略；token 不足時缺項忽略。

## 輸出格式

```
第 1 行：強連通分量個數 k
第 2 行：n 個數，第 i 個是點 i 所屬的分量編號（0 … k-1），空格分隔（n = 0 時空行）
第 3 行：縮點後 DAG 的邊數（去重）
第 4 行：最大分量包含的點數（k = 0 時為 0）
第 5 行：源點數 匯點數 最少加邊數（三個數字，空格分隔）
```

## 範例

輸入：

```
5 4
1 2
2 3
3 1
3 5
```

輸出：

```
3
0 0 0 1 2
1
3
2 2 2
```

說明：

- 三個 SCC：`{1,2,3}`（1→2→3→1 成環）、`{4}`（孤立點）、`{5}`；
- 縮點後只有一條邊：`3→5` 即分量 `0 → 2`；
- 最大分量是 `{1,2,3}`，含 3 個點；
- 源點（入度 0）是分量 `0` 與 `1`，匯點（出度 0）是分量 `1` 與 `2`，
  因此讓整張圖強連通最少要加 `max(2, 2) = 2` 條邊（例如 `5→4` 與 `4→1`）。

## 怎麼跑

```bash
python solution.py                                          # 無 stdin → 跑內置斷言
printf '5 4\n1 2\n2 3\n3 1\n3 5\n' | python solution.py
```

## 內置測試覆蓋

- **Tarjan vs Kosaraju**：500 組隨機圖上分量個數、分割完全一致；
- **Tarjan vs 暴力 BFS**：兩點同屬一個分量 ⟺ 互相可達（`O(n·(n+m))` 枚舉驗證）；
- 重編號後兩個演算法給出**完全相同**的分量陣列，且編號按「分量內最小點號」嚴格遞增；
- 縮點 DAG：驗證最大分量大小、邊數上界 `k(k-1)`、以及 `k ≥ 1` 時源點與匯點都至少有一個（DAG 性質）；
- 邊界：空圖（`n = 0`）、單點無邊、整張圖強連通、一條鏈。
