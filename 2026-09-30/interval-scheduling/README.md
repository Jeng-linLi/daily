# 區間問題與貪心（最多不重疊 / 最少移除 / 最少會議室 / 合併區間 / 引爆氣球）

| 項目 | 內容 |
|---|---|
| 主題 | 區間調度貪心：排序 + 一次線性掃描；附 O(n²) 動態規劃與掃描線兩種交叉驗證 |
| 語言 | Python 3（標準庫）、C++17 |
| 複雜度 | 五問全部 `O(n log n)`（瓶頸在排序）/ 空間 `O(n)`（合併結果與堆） |

## 題意

給定 `n` 個區間，依次輸出五個經典貪心問題的答案：

1. 最多能選出多少個**互不重疊**的區間（區間調度，LeetCode 435 系列）；
2. 最少移除多少個區間才能使剩下區間互不重疊（LeetCode 435）；
3. 同時安排所有區間最少需要幾個「會議室」（LeetCode 253）；
4. 合併所有重疊區間後的區間個數與合併結果（LeetCode 56）；
5. 引爆所有「氣球」最少需要幾支箭（LeetCode 452）。

## 思路

這五問的共同前提是**排序**：區間題 90% 的第一步都是「按左端點或右端點排序」，
排序之後區間之間的關係變成單調的，可以一次線性掃描解決。

### 1. 最多不重疊區間 —— 按右端點升序貪心

每次都選**結束最早**的那個，給後面留下的空間最大。
交換論證：若某個最優解的第一個區間不是結束最早的那個，
用結束最早的那個替換它，不會與任何後續區間衝突（因為它結束得更早），解的規模不變。
反覆替換即可把任意最優解改造成貪心解。

### 2. 最少移除 = n − 最多保留

同一個貪心的另一種問法：能保留的越多，要移除的就越少。

### 3. 最少會議室 —— 小根堆（或掃描線）

按左端點升序掃描，用小根堆維護「目前正在使用的會議室的結束時間」：
遇到新區間時，先把所有 `end ≤ l` 的房間釋放（堆頂最小，彈完即止），
再壓入新區間的結束時間；**堆的最大容量**就是答案。
另一種寫法是掃描線：每個區間貢獻 `(l, +1)` 與 `(r, −1)` 兩個事件，
同一座標先處理 `−1` 再處理 `+1`，過程中的最大前綴和即答案。兩種寫法在測試裡互相對拍。

### 4. 合併區間 —— 按左端點升序掃描

若下一個區間的 `l ≤` 當前區間的 `r` 就合併（`r` 取較大者），否則開一個新段。

### 5. 引爆氣球 —— 按右端點升序，但判定更嚴格

箭射在區間右端點 `x` 處時，所有滿足 `l ≤ x ≤ r` 的氣球都會爆（閉區間）；
所以只有當下一個氣球的 `l > x` 時才需要補一支新箭。

### ⚠️ 端點相接算不算重疊？（區間題第一大坑）

本題統一約定如下，兩份程式碼嚴格遵守：

| 問題 | 區間語義 | 判定條件 |
|---|---|---|
| 最多不重疊 / 最少移除 | 半開 `[l, r)`，端點相接**不算**衝突 | `l ≥ last_end` |
| 最少會議室 | 半開 `[l, r)`，端點相接**不算**衝突 | `end ≤ l` 即釋放 |
| 合併區間 | 閉 `[l, r]`，端點相接**算**重疊 | `l ≤ cur_r` 即合併 |
| 引爆氣球 | 閉 `[l, r]`，箭落在端點也算擊中 | `l > x` 才補新箭 |

也因此「空區間」`l == r` 在半開語義下長度為 0，不佔用會議室；
而閉區間語義下它是實實在在的一個點，需要一支箭才能打掉。

## 輸入格式

```
n
l1 r1
l2 r2
…… （共 n 行；n = 0 時無後續行）
```

所有數字按空白分隔即可；若 `l > r` 會自動交換；token 不足時缺項忽略。

## 輸出格式

```
第 1 行：最多互不重疊區間數
第 2 行：最少移除區間數
第 3 行：最少會議室數
第 4 行：合併後的區間數
第 5 行：合併後的區間，按 `l1 r1 l2 r2 …` 空格分隔（無區間時輸出空行）
第 6 行：引爆所有氣球最少需要的箭數
```

## 範例

輸入：

```
4
1 2
2 3
3 4
1 3
```

輸出：

```
3
1
2
1
1 4
2
```

說明：

- 最多不重疊：`[1,2] [2,3] [3,4]` 共 3 個（端點相接不算衝突），所以最少移除 `4 − 3 = 1` 個；
- 最少會議室：`[1,2]` 與 `[1,3]` 同時進行，需要 2 間；
- 合併：四個閉區間首尾相連，合併成 `[1, 4]` 一段；
- 引爆氣球：一箭射在 `x = 2` 打掉 `[1,2] [2,3] [1,3]`，再一箭射在 `x = 4` 打掉 `[3,4]`，共 2 支。

## 怎麼跑

```bash
python solution.py                                   # 無 stdin → 跑內置斷言
printf '4\n1 2\n2 3\n3 4\n1 3\n' | python solution.py

g++ -std=c++17 -O2 -Wall solution.cpp -o solution && ./solution
```

通過時兩個版本都輸出 `all tests passed`。

## 內置測試覆蓋

- 貪心的「最多不重疊」與 `O(n²)` 動態規劃對拍 600 組隨機用例；
- 「最少會議室」的小根堆版與掃描線版互相對拍；
- 合併結果驗證：有序、兩兩之間有空隙、且在 `-1 … 14` 每個座標上的覆蓋情況與原區間完全一致；
- 引爆氣球：貪心答案與**子集枚舉的最優解**對拍（證明最優性），並驗證貪心構造出的箭位置確實打掉全部氣球；
- 邊界：空輸入、`l == r` 的單點區間、`l > r` 的交換。
