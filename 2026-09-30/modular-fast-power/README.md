# 快速冪與模運算（二進制冪 / 矩陣快速冪 / 乘法逆元）

| 項目 | 內容 |
|---|---|
| 主題 | 快速冪（`mod_pow`）、矩陣快速冪求 Fibonacci、擴展歐幾裡得 / 費馬小定理求逆元 |
| 語言 | Python 3（標準庫）、C++17 |
| 複雜度 | 快速冪 `O(log b)` / 空間 `O(1)`；矩陣快速冪 `O(2^3 · log n) = O(log n)` / 空間 `O(1)`；逆元 `O(log min(a,m))` |

## 題意

給定若干組詢問，要求高效算出：

1. `a^b mod m` —— 樸素做法做 `b` 次乘法，`b = 10^9` 時直接超時；
2. `F(n) mod 1000000007` —— 第 `n` 個 Fibonacci 數（`F(0)=0, F(1)=1`），把線性遞推從 `O(n)` 降到 `O(log n)`；
3. `x` 在模 `p` 下的**乘法逆元**，即滿足 `x · inv ≡ 1 (mod p)` 的數（不存在時輸出 `-1`）。

## 思路

### 1. 二進制冪（Binary Exponentiation）

把指數 `b` 拆成二進位：`b = Σ b_k · 2^k`，於是

```
a^b = Π (a^(2^k))^(b_k)
```

演算法一邊讓底數反覆平方（`a → a^2 → a^4 → …`），一邊在 `b` 當前位爲 1 時把底數乘進答案：

```python
while b:
    if b & 1: res = res * a % mod
    a = a * a % mod
    b >>= 1
```

乘法的次數從 `b` 次降到 `⌊log₂ b⌋ + 1` 次，這是一切「冪 / 遞推加速」題的地基。
模數接近 `10^18` 時 `a * a` 會溢位，C++ 版統一用 `__int128` 中轉（`mulMod`）。

### 2. 矩陣快速冪

一階線性遞推可以寫成向量乘矩陣：

```
[F(n), F(n-1)]ᵀ = [[1,1],[1,0]] · [F(n-1), F(n-2)]ᵀ
```

所以 `M^n = [[F(n+1), F(n)], [F(n), F(n-1)]]`，取 `[0][1]` 就是 `F(n)`。
把上面的快速冪裡的「數」換成「矩陣」即可，複雜度 `O(log n)`。
任何 `k` 階線性遞推（Tribonacci、`a_n = 3a_{n-1} - 2a_{n-3}` …）都能照搬這個寫法，
只要把轉移矩陣換掉、矩陣維度從 2 換成 `k`。

### 3. 乘法逆元

- **擴展歐幾裡得**：解 `x·a + y·m = gcd(a, m)`，當 `gcd = 1` 時 `x mod m` 就是 `a` 的逆元。
  不要求模數是質數，只要 `a` 與 `m` 互質。
- **費馬小定理**：`m` 爲質數時 `a^(m-2) ≡ a^(-1) (mod m)`，一行快速冪搞定，
  但**合數模數下會給出錯誤答案**，只能用擴歐版。

測試裡兩個版本互相對拍（質數模數），並對合數模數驗證「`gcd != 1` 時正確回傳 `-1`」。

## 輸入格式

```
n q k
a1 b1 m1
a2 b2 m2
…… （共 q 行，每行一次快速冪詢問）
p
x1 x2 ... xk         （要求逆元的 k 個數，模數統一爲 p）
```

所有數字按空白分隔即可；token 不足時缺項按 `0` 處理（模數缺項按 `1` 處理，其結果恆爲 `0`）。

## 輸出格式

```
第 1 行      ：F(n) mod 1000000007
第 2 … q+1 行：每組詢問的 a^b mod m
最後 1 行    ：k 個逆元，空格分隔；逆元不存在輸出 -1（k = 0 時輸出空行）
```

## 範例

輸入：

```
10 3 3
2 10 1000
3 5 7
0 0 1
11
3 5 7
```

輸出：

```
55
24
5
0
4 9 8
```

說明：`F(10) = 55`；`2^10 = 1024 ≡ 24 (mod 1000)`；`3^5 = 243 ≡ 5 (mod 7)`；
`0^0 = 1 ≡ 0 (mod 1)`；模 11 下 `3·4 = 12 ≡ 1`、`5·9 = 45 ≡ 1`、`7·8 = 56 ≡ 1`。

## 怎麼跑

```bash
python solution.py                                     # 無 stdin → 跑內置斷言
printf '10 3 3\n2 10 1000\n3 5 7\n0 0 1\n11\n3 5 7\n' | python solution.py

g++ -std=c++17 -O2 -Wall solution.cpp -o solution && ./solution
```

通過時兩個版本都輸出 `all tests passed`。

## 內置測試覆蓋

- 快速冪與 Python 內建 `pow(a, b, m)` 對拍 3000 組隨機用例；指數 ≤ 60 時再與 `O(b)` 樸素版對拍；
- `2^(10^9) mod (10^9+7) = 140625001`（超大指數，只有快速冪能秒出）；
- Fibonacci 與迭代版對拍 0…90 項（在 `10^9+7` / `1000` / `1000003` 三個模數下），並驗證遞推自洽；
- 逆元：驗證 `x · inv ≡ 1 (mod p)`、費馬版與擴歐版一致、非互質時回傳 `-1`。
