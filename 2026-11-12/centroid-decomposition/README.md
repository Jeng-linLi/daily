# 點分治 Centroid Decomposition：樹上「邊數恰為 k」的點對計數

## 題意

給一棵 `n` 個點的無根樹（`n-1` 條無向邊，1-based）與整數 `k`，
統計無序點對 `(u, v)` 的個數，使得 `u` 到 `v` 的路徑邊數**恰好**為 `k`。

## 思路（重心分治）

1. 在當前連通分量裡找**重心**：刪去它後每棵剩餘子樹的大小都不超過分量的一半
   （BFS 求 subtree size，再不斷走向「超過一半」的重孩子，收斂點即重心；
   上方那部分的大小 `tot - size[c]` 必然不超過一半，因此只需檢查孩子方向）。
2. 統計「經過重心的路徑」中長度恰為 `k` 的點對（有序對容斥）：
   `through = Σ_d cnt_all[d]·cnt_all[k-d] − Σ_子樹 Σ_d cnt_s[d]·cnt_s[k-d]`
   其中 `cnt_all[d]` 是分量內距重心 `d` 的點數、`cnt_s[d]` 是某一棵子樹內的點數。
   `k ≥ 1` 時 `through` 必為偶數（每個無序對恰被計兩次），除以 2 即無序對數。
3. 刪掉重心，對每個剩餘子分量**遞迴**（分量每輪至少減半，遞迴深度 O(log n)）。

正確性關鍵：任意點對 `(u, v)` 的路徑，在「兩端首次被分開」的那一層
恰好經過該層的重心，且只被統計一次——分層天然不重不漏。

## 複雜度

- 每層分治對總點數只做一次線性掃描（BFS + 距離桶），共 O(log n) 層。
- 時間 **O(n log n)**，空間 **O(n)**。

## 輸入輸出格式（IO 模式，從 stdin 讀入）

```
paths n k u1 v1 u2 v2 ...
```
每行一條命令，輸出詢問結果一行一個整數。

stdin 無內容時跑內建斷言測試（固定小例 + 200 組與 O(n²) 暴力對拍 +
400 點鏈），輸出 `all tests passed`。

## 示例

輸入：

```
paths 6 3 1 2 2 3 3 4 2 5 5 6
paths 6 1 1 2 2 3 3 4 2 5 5 6
```

輸出（Python 與 C++ 逐位元組一致）：

```
4
5
```

第一問：樹為 1-2-3-4、2-5-6，距離恰為 3 的點對是
`(1,4)`、`(1,6)`、`(3,6)`、`(4,5)`，共 4 對；第二問距離為 1 的點對即 5 條邊。
