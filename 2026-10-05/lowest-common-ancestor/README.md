# LCA 最近公共祖先（Lowest Common Ancestor）

| 項目 | 內容 |
|---|---|
| 目錄 | `2026-10-05/lowest-common-ancestor` |
| 語言 | Python 3（標準庫） / C++17 |
| 考點 | 倍增（binary lifting）、歐拉序 + Sparse Table RMQ、樹上距離、k 級祖先、DFS 進出時間 |
| 複雜度 | 預處理 **O(n log n)**；倍增查詢 **O(log n)**、RMQ 查詢 **O(1)**；空間 **O(n log n)** |

## 題意

給定一棵 `n` 個節點的無根樹（邊表，0-indexed），以 0 號點為根，在線回答：

1. `lca(u, v)` —— u 與 v 的最近公共祖先；
2. `dist(u, v)` —— u 到 v 的樹上距離（邊數）；
3. `kth_ancestor(v, k)` —— v 向上走 k 步到達的祖先（超過根則為 -1）；
4. `is_ancestor(u, v)` —— u 是否為 v 的祖先（含 `u == v`）。

程式提供**兩條完全不同的路線**互相對拍：

- 倍增（binary lifting）：預處理 O(n log n)、查詢 O(log n)；
- 歐拉序 + Sparse Table：預處理 O(n log n)、查詢 **O(1)**。

外加一個 O(n) 逐層爬 parent 的樸素版當基準。

## 思路

### 倍增（binary lifting）

`up[k][v]` = v 的第 `2^k` 級祖先（不存在則 -1），遞推式：

```
up[0][v] = parent[v]
up[k][v] = up[k-1][ up[k-1][v] ]
```

它利用的是**二進制拆分**：任何跳數都能拆成若干個 2 的冪。

1. **對齊深度**：把較深的點往上拉 `diff = depth[u] − depth[v]` 步，
   只需對 `diff` 的每個為 1 的位跳一次；
2. **一起往上跳**：從大到小枚舉 `k`，若 `up[k][u] != up[k][v]` 就同時跳。
   相等代表「跳上去會跳過頭（或已經是同一個點）」，**不能跳**；
3. 最後 `up[0][u]` 就是 LCA。

### 歐拉序 + RMQ（另一條路線）

對樹做 DFS：**進入**節點時記一次，每訪問完一個子節點**返回父節點**時再記一次，
得到長度 `2n − 1` 的歐拉序列。

u 與 v 的 LCA，就是歐拉序中 `[first[u], first[v]]` 區間內 **depth 最小**的那個節點。
區間最小值用 Sparse Table 預處理 → O(1) 查詢。

這條路線**不需要對齊深度**，是 LCA 的另一種經典解法，兩者結果必然一致，正好互相對拍。

| 路線 | 預處理 | 單次查詢 | 需要對齊深度 |
|---|---|---|---|
| 倍增 | O(n log n) | O(log n) | 是 |
| 歐拉序 + ST | O(n log n) | **O(1)** | 否 |

### 樹上距離

```
dist(u, v) = depth[u] + depth[v] − 2 · depth[lca(u, v)]
```

### 祖先判定

DFS 進出時間 `tin / tout`：

```
u 是 v 的祖先  ⟺  tin[u] ≤ tin[v]  且  tout[v] ≤ tout[u]
```

這是處理「子樹區間」問題的標準技巧，配合 DFS 序可以把整棵子樹攤平成一段連續區間。

## 輸入格式

```
n
n-1 行：u v        ← 無向邊；n == 1 時沒有邊
q
q 行：lca u v  |  anc v k
```

## 輸出格式

```
每個查詢一行：
  `lca u v` -> `<lca> <dist>`
  `anc v k` -> `<ancestor>`（不存在為 -1）
```

節點編號越界、或該點不在根 0 所在的連通分量內時，輸出 `-1 -1` / `-1`。

## 示例

輸入（樹：`0-1, 0-2, 1-3, 1-4, 2-5, 2-6`）：

```
7
0 1
0 2
1 3
1 4
2 5
2 6
5
lca 3 4
lca 3 5
lca 5 6
anc 3 2
anc 3 3
```

輸出：

```
1 2
0 4
2 2
0
-1
```

解釋：

- `lca(3, 4) = 1`，距離 `2`（3 → 1 → 4）；
- `lca(3, 5) = 0`，距離 `4`（3 → 1 → 0 → 2 → 5）；
- `lca(5, 6) = 2`，距離 `2`；
- `anc(3, 2)`：3 的第 2 級祖先 = `0`（3 → 1 → 0）；
- `anc(3, 3)`：要往上走 3 步，但 3 的深度只有 2，超過根 → `-1`。

## 實作備註

- DFS 一律用**迭代版顯式棧**（避免深鏈遞歸爆棧），且鄰接表先排序，
  保證 Python 與 C++ 的遍歷順序完全一致；
- C++ 的顯式棧用 `stk.back()[...]` 當場存取，**不持有** `back()` 的引用 ——
  `push_back` 可能讓 vector 重新配置，持有引用會變成未定義行為。
