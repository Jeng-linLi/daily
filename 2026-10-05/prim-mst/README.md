# Prim 最小生成樹（Prim's Minimum Spanning Tree）

| 項目 | 內容 |
|---|---|
| 目錄 | `2026-10-05/prim-mst` |
| 語言 | Python 3（標準庫） / C++17 |
| 考點 | 貪心（cut property）、Prim 樸素 O(V²) / 堆優化 O(E log V)、並查集 Kruskal 對拍、最小生成森林 |
| 複雜度 | 樸素版 **O(V²)**；堆優化版 **O(E log V)**；Kruskal **O(E log E)**；空間 **O(V²)** / **O(V+E)** |

## 題意

給定一張無向帶權圖（可能不連通），求：

1. MST 的總權重；
2. 圖是否連通（不連通則不存在生成樹）；
3. MST 具體選了哪些邊（輸出時 `u < v`，按 `(u, v)` 排序）；
4. 若不連通：連通分量個數，以及**最小生成森林**的總權重。

同時提供三種互相獨立的實現彼此對拍：

- `prim_naive`：鄰接矩陣 + 每輪線性掃描，O(V²)，稠密圖最優；
- `prim_heap`：鄰接表 + 二元堆（懶刪除），O(E log V)，稀疏圖最優；
- `kruskal`：並查集 + 邊排序，O(E log E)，作為第三方基準。

## 思路

### 貪心原理（cut property）

維護已選點集 `S`。對任意跨越 `S` 與 `V−S` 的邊（**割邊**），權重最小的那條必定屬於某棵 MST。
Prim 每輪就是取這條最小割邊、把對應的新點併入 `S`，共做 `V−1` 輪。

形式與 Dijkstra 非常像 —— 都是「每次取當前距離最小的未確定點」，
差別在於 `dist` 的意義：

| 算法 | `dist[v]` 的意義 | 鬆弛式 |
|---|---|---|
| Dijkstra | 到**起點**的路徑總長 | `dist[u] + w < dist[v]` |
| Prim | 到**當前樹**的單邊權 | `w < dist[v]` |

### 兩個版本怎麼選

| 版本 | 每輪代價 | 總複雜度 | 適合 |
|---|---|---|---|
| 樸素（鄰接矩陣） | O(V) 掃描 + O(V) 更新 | **O(V²)** | 稠密圖 `E ≈ V²`（與邊數無關） |
| 堆優化（鄰接表） | O(log V) 出堆 | **O(E log V)** | 稀疏圖 `E ≈ V` |

### 為什麼兩個版本的輸出能逐字節一致

兩者採用同一套確定性平手規則：

- **選點**：先比 `dist`，相同則比**點編號**（小者優先）；
- **鬆弛**：只有嚴格 `w < dist[v]` 才更新 `parent`（先來先佔）。

堆版以 `(w, v)` 為鍵彈出、並跳過已訪問的點（懶刪除），
等價於「每次在未訪問且 `dist` 有限的點中取 `(dist, 編號)` 最小者」，因此與樸素版逐步等價。

### 不連通圖

Prim 從 0 號點出發只能覆蓋一個連通分量，偵測方式是「最終選中的點數 `< V`」。
最小生成森林則是對每個未訪問的點各跑一次 Prim，把各分量的 MST 權重加總。

### 負權邊

Prim 與 Kruskal **都能處理負權邊**（MST 只關心邊權總和，沒有「負環」這種麻煩）——
這是它們與最短路算法的關鍵差別。

## 輸入格式

```
n m
m 行：u v w      ← 無向邊，0-indexed，w 可為負
```

## 輸出格式

```
第 1 行：是否連通（1 / 0）
第 2 行：prim_naive 的 MST 總權重（不連通為 -1）
第 3 行：prim_heap  的 MST 總權重（不連通為 -1）
第 4 行：kruskal    的 MST 總權重（不連通為 -1）
第 5 行：最小生成森林的總權重（各分量 MST 權重之和）
第 6 行：連通分量個數
第 7 行：MST 邊數
第 8 行起：每條 MST 邊一行 `u v w`（u < v，按 (u, v) 排序）
```

## 示例

輸入：

```
5 7
0 1 2
0 3 6
1 2 3
1 3 8
1 4 5
2 4 7
3 4 9
```

輸出：

```
1
16
16
16
16
1
4
0 1 2
0 3 6
1 2 3
1 4 5
```

解釋：三種獨立實現都得到 **16**，選中的邊是 `0-1(2)`、`0-3(6)`、`1-2(3)`、`1-4(5)`。

不連通的範例（兩個三角形 `{0,1,2}` 與 `{3,4,5}`）：

```
6 6
0 1 1
1 2 1
0 2 5
3 4 2
4 5 2
3 5 9
```

輸出：

```
0
-1
-1
-1
6
2
0
```

三個 `-1` 代表不存在生成樹；最小生成森林權重 = `(1+1) + (2+2) = 6`；分量數 = 2。
