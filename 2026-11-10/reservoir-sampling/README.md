# 蓄水池抽樣 Reservoir Sampling（Algorithm R）

## 題意

`sample n k seed`：對 1..n 的元素流做**單遍均勻抽樣**，隨機決策由自製 LCG 產生，
輸出被選中的 k 個編號（升序）。

**應用場景**（隨機算法在工程中的典型用法）：

- A/B 測試均勻分組；
- 海量日誌流 / 大數據集的單遍子採樣；
- 流長度 n **事先未知**時仍保證每個元素被選中概率恰為 k/n，只需 O(k) 內存。

例：`sample 10 3 1` → 某個 3-子集如 `2 6 9`。

## 思路：Algorithm R

```text
前 k 個元素直接入池；
第 i 個元素（i > k）以 k/i 的概率替換池中隨機一個位置。
```

**歸納證明均勻性**：處理完前 i 個元素時，任一元素在池中的概率為 k/i。
第 i+1 個元素以 k/(i+1) 入池；池中既有元素被替換的概率 = k/(i+1) × 1/k = 1/(i+1)，
留存概率 = 1 − 1/(i+1) = i/(i+1)，於是存活概率 = (k/i) × (i/(i+1)) = k/(i+1)。歸納成立。

隨機數用自製 LCG（`state = state×1103515245 + 12345 mod 2^31`）：
`nextRand(i) < k` 判定入選、`nextRand(k)` 選替換位置——兩語言的決策序列逐位一致，
同一 seed 給出完全相同的抽樣結果。

## 複雜度

- 時間：O(n)（單遍掃描）；
- 空間：O(k)（與流長無關——這是它相對「先存全量再洗牌」的核心優勢）。
