# 插頭 DP：骨牌完全覆蓋計數（輪廓線 DP）

## 題意

`count n m`：輸出 n×m 棋盤被 1×2 骨牌**完全覆蓋**的方案數（n, m ≤ 12）。

例：`count 2 3` → `3`；`count 8 8` → `12988816`；`count 7 5` → `0`（35 格為奇數，必為 0）。

## 思路：輪廓線 / 插頭 DP（逐格掃描）

狀態是一個長度 m 的 bitmask，表示**輪廓線**上每個位置的插頭。進入格子 `(i, j)` 時：

- `bit k (k < j)`：第 i 行第 k 列已處理完，bit k = 該格向下伸的插頭（伸給 i+1 行）；
- `bit k (k ≥ j)`：上方伸下來的插頭——`(i-1, k)` 豎放下伸（= `(i,k)` 的上插頭），
  或 `(i, k-1)` 橫放右伸（= `(i,k)` 的左插頭），編碼在同一個 bit 上。

**為什麼單 bit 就夠**：骨牌每格恰好度數 2，一個格子不可能同時被上方骨牌和左側骨牌佔住，
所以同一輪廓位至多一個插頭。（插頭 DP 的完全體——哈密爾頓回路——需要括號序列編碼
記錄插頭間的**連通性**，本題是它的入門形態。）

**轉移**（對每個 mask）：

1. 輪廓位 j 已有插頭 → `(i,j)` 已被左鄰/上鄰的骨牌覆蓋：**消費**該插頭（bit j 清零），無其他動作；
2. 無插頭 → `(i,j)` 必須被覆蓋，兩選一：
   - **豎放** `(i,j)-(i+1,j)`：置 bit j = 1（伸向下一行），需 `i+1 < n`；
   - **橫放** `(i,j)-(i,j+1)`：置 bit j+1 = 1（交給右鄰消費），需 `j+1 < m` 且 bit j+1 為 0。

最後一格 `(n-1, m-1)` 豎放/橫放皆不可用時，該狀態轉移數自然為空（死亡）。
終態要求 `mask == 0`：任何殘留插頭都意味著骨牌伸出棋盤外，被自動過濾。

## 複雜度

- 時間：O(n·m·2^m)——每格對每個輪廓狀態 O(1) 轉移；
- 空間：O(2^m)。
- 12×12 方案數 53,060,477,521,960,000，在 unsigned long long / Python int 範圍內。

## 示例

```text
輸入：
count 2 3
count 3 2
count 8 8

輸出：
3
3
12988816
```

## 驗證

兩語言各自內建斷言（無 stdin 時自動執行，輸出 `all tests passed`）：

1. 已知數列：1×m（偶 1 / 奇 0）、2×n = Fib(n+1)、3×2k = 3, 11, 41, 153, 571；
2. 對稱性 count(n,m) = count(m,n)；
3. 格數為奇數必為 0；
4. 與暴力 DFS 填格計數對拍（n·m ≤ 14 的隨機小棋盤 60 組）；
5. 大值固定回歸：8×8 = 12,988,816、10×10 = 258,584,046,368、12×12 = 53,060,477,521,960,000
   （對照 OEIS A004003 n×n 骨牌鋪法數）。

跨語言 IO 對拍：50 組用例（邊界 + 12 以內隨機），Python 與 C++ 輸出逐字節一致，0 mismatch。
