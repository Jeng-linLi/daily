# Dilworth 定理：最小鏈覆蓋 = 最長反鏈

## 題意

`chain n x1 y1 ... xn yn`：給定平面上 n 個點，定義支配序
`(a, b) ≼ (c, d) ⟺ a ≤ c 且 b ≤ d`。輸出兩個數：

- **最小鏈覆蓋**：把點集劃分成最少條鏈（鏈 = 兩兩可比的點集）；
- **最長反鏈**：最大的兩兩互不支配的點集大小。

依 Dilworth 定理，這兩個數**恆相等**。例：

```text
輸入：chain 4 1 1 1 3 2 2 3 4
輸出：2 2        # 反鏈 {(1,3),(2,2)}；覆蓋 {(1,1),(1,3),(3,4)} + {(2,2)}
```

## 思路

### 最長反鏈：LDS（O(n²)）

去重（相同點互相支配，可合併）後按 a 升序排序，此時 a 嚴格遞增。
兩點互不支配 ⟺ a 小者 b 嚴格大 → **反鏈 = b 的最長嚴格遞減子序列**，
經典 O(n²) DP 直接求解。

### 最小鏈覆蓋：DAG 最小路徑覆蓋（n − 最大匹配）

排序後邊 `i → j` 存在當 `i < j 且 b_i ≤ b_j`（此時 i 支配 j，可同鏈）。
把每個點拆成「出 / 入」兩側建二分圖，**最小鏈覆蓋 = n − 最大匹配**（點鏈版本
的最小路徑覆蓋定理）。最大匹配用匈牙利算法（DFS 增廣）求得。

### 定理的構造性驗證

LDS 與匹配是**兩個完全獨立的算法**：前者算反鏈，後者算覆蓋。
對隨機點集斷言兩者輸出相等，即為 Dilworth 定理「最小鏈覆蓋 = 最長反鏈」的
程序化驗證——任何一方寫錯都會導致斷言失敗。

## 複雜度

| 部分 | 時間 |
|---|---|
| 去重排序 | O(n log n) |
| 最長反鏈（LDS） | O(n²) |
| 最小鏈覆蓋（匈牙利） | O(n·E)，E ≤ n²/2 |

n ≤ 100 內均可秒出。
